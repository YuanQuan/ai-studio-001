# 百鬼夜市核心场景 Demo｜性能预算与测量口径

版本：v0.1｜任务：TECH-PERF-DEMO-001｜状态：待专业评审与用户审批

## 1. 范围与判定层级

本预算只适用于已批准的 DEMO-001 v0.1 单机客户端：竖屏等距 TileMap、独立地标 Prefab、一次修复、一名店长与固定路径顾客。**主流中高端手机 60 FPS 是优化与验证目标**，不承诺所有机型稳定 60 FPS。产品硬性验收仍是完整地图不露空白、可操作相机、修复与店长、至少一名顾客完整路线和最简 UI；性能未达目标时必须报告实测结果和原因，不得用 Web 指标宣称手机通过。

本文件区分：A）核心功能硬门槛；B）目标手机性能目标；C）观察/调优门槛。没有指定手机时，性能结论为待测，不能把估算值写成已通过。

## 2. 代表设备与记录

本版先批准代表设备的选择规则，**正式手机性能测试前**指定至少一台可运行竖屏触控 Web 构建的中高端手机，并在测试计划或执行记录中落盘厂商、型号、芯片、RAM、操作系统及版本、浏览器/运行容器版本、物理分辨率、DPR、屏幕刷新率和画质档。现阶段没有具体型号，不阻止文档审批或客户端工程准备，但不得提前作出手机性能通过结论。优先选当前团队可反复访问、刷新率至少 60 Hz、能稳定运行目标构建的真实设备；仅模拟器或桌面 Web 不满足手机性能验证。若后续需要微信/抖音容器结论，应另记录该平台构建并分别测试，浏览器结果不能直接外推。

每次采样记录 Creator 版本、构建模式/哈希、资产版本、设备电量与省电/高性能设置、是否充电、屏幕亮度档、温度或明显发热状态、竖屏视口和相机位置。首次进入加载与二次进入缓存加载分别记录，不能混为一个数字。不同设备、画质档或构建之间不得合并平均值。

## 3. 负载和采样方法

每个场景在相同构建、设备、镜头与顾客生成参数下重复 **3 次**。进入场景后等待资源加载完成和运行稳定，再采样连续 **60 秒**；拖拽场景录制实际操作 60 秒并保留手势视频。覆盖：初态默认镜头、修复后默认镜头、最远和最近倍率、持续客流达到 Client 预先锁定的正常活跃上限，以及持续客流同时拖拽/缩放。记录每轮的平均 FPS、帧时间 p50/p95/p99、超过 33.3 ms 与 50 ms 的帧数及发生时间；同时记录 DrawCall、纹理内存、活跃顾客峰值。加载耗时从启动 Demo 场景请求到首帧可操作且目标摊位、道路、桥和 UI 齐备，重复 3 次并分别记录冷/热缓存。

测量工具须注明来源与采样精度。若浏览器或 Creator 工具无法直接给出可靠纹理 GPU 内存，记录可得的纹理资源估算值、来源及局限，不能把 JS 堆内存冒充纹理内存。保留原始时间序列或导出文件，单一 FPS 数字不足以判断卡顿。

## 4. 指标预算

| 指标 | 目标手机的本版口径 | 判定性质 |
|---|---|---|
| 运行帧率 | 60 Hz 目标设备上，稳定负载各轮平均 FPS 争取 ≥55；帧时间 p95 争取 ≤20 ms | 优化目标；未达须分析，不单独覆盖产品功能结论 |
| 明显卡顿 | 单帧 >50 ms 记为明显卡顿；单帧 >33.3 ms 也计数，定位加载、池化或透明绘制峰值 | 观察门槛；任何可复现操作卡死、输入无响应或路线跳变按功能缺陷处理 |
| DrawCall | 各负载记录平均/峰值；若修复后或近景较初态增幅 >30%，或随顾客数量持续无界增长，触发合批/节点泄漏分析 | 调优门槛；暂不设跨设备硬数值 |
| 纹理内存 | 记录贴图总量及运行峰值；若修复或循环客流后持续增长且回收不回落，触发资源/池化检查 | 调优门槛；无设备与生产资产基线时不设 MB 硬值 |
| 活跃顾客数 | 记录 Client 锁定的正常上限与实测峰值；长时间循环不应突破上限，至少可观察两名顾客依次走完全路 | 上限约束和产品可观察结果；具体 N 由 Client 在开工校准门槛确定 |
| 加载耗时 | 分冷/热缓存记录 3 次结果、首帧可操作时间与最大值；如出现超过 5 秒的冷启动，进入资源拆分/压缩分析 | 观察/调优门槛；5 秒非用户批准的发布硬指标 |

平均 FPS ≥55 与 p95 ≤20 ms 是当前可操作的**候选验证目标**，应在目标手机和生产资产确定后复核。若设备刷新率非 60 Hz，报告实际刷新率和目标适用性，不用 120 Hz 的原始 FPS 与 60 Hz 口径直接比较。正式 TEST_REPORT 同时给数值、证据和是否达目标；性能目标失败不能写成“全部通过”。

## 5. Web 与降级边界

本地 Web 用于发现卡顿来源、资源泄漏、DrawCall 增长和输入问题；桌面机器结果不能替代手机结论。低性能设备可减少装饰动画/粒子、顾客同时显示数量、远处动画频率与远景纹理分辨率；仍需保持一张连续地图、可见桥和主通道、拖拽缩放、一次修复后的店长，以及至少一名顾客从入口到出口的连贯路径。不能在画面中直接回收顾客，也不能让降级后摊位难以点击。

目标设备、运行参数或资源规格变更时，Client 更新实施记录与采样条件，QA 复测受影响场景。本预算不修改正式产品玩法、项目级架构或平台发布承诺。
