# CP-UNIT-MENU-SCOPE-001｜以七项新菜单样例替代旧九菜单任务

状态：`PROPOSED`；2026-10-02。Master 提案。用户明确提出七项新菜单内容，逐项原文语义见 [范围输入](../unit_tests/UNIT_MENU_SCOPE_INPUT_v0.1.md)。旧 `UNIT-SAMPLES-001` 已取消并保留历史文件；新实现不能复用旧图片、Prefab、UI 图稿或程序形体充当正式产物。

## 拟议变更

1. 菜单改为七个顶层样例：空背景与镜头、奶茶店、角色（孟桃店长/幽灵顾客子项）、可切换场景元素、UI、孟桃对话、组合场景。公共菜单导航不是第八个样例。
2. 第七项从第一项的空场景逐项装配前六项中适用的对象，复用同一正式资产、状态、UI、VFX与资源 ID，以便验证遮挡和改源后一致性；不能另做一张合成背景代替。
3. 现有 `UNIT-PILOT-PRODUCT-001 v0.1` 与已批准孟桃概念只覆盖奶茶店/孟桃试点；幽灵顾客的平视角左右移动（一方向骨骼资源经水平翻转复用）、多状态动作、可坐街边板凳、可切换树木/花草/灯笼及孟桃对话属于新增产品与资产范围。四份新专业 v0.1 仍在 `USER_REVIEW`，受本提案影响时须出修订版本或附加规格，经用户另行批准。
4. `CP-UNIT-REUSE-001` 的独立可打磨、演示与主体同源、一骨骼对象一贴图和出图前 Art/Tech 联合签认约束继续作为待批准的工程提案；技术形态由 Tech Lead 评审，不能因本菜单提案单方锁定。
