# CP-UNIT-FINAL-ASSET-FLIPBOOK-002｜单元正式资源与幽灵序列帧

日期：2026-10-02。状态：`USER_DIRECTION_ACCEPTED / PRODUCT_REVISION_REQUIRED`。Master 记录用户最新明确指令，逐字输入见 [修订输入](../unit_tests/UNIT_MENU_PRODUCTION_INPUT_v0.2.md)。范围限本游戏七项菜单单元与未来主体同源使用，不改变 Studio 通用规则。

## 变更

1. 单元样例的实际交付资源必须是未来主体游戏直接引用的正式资源。演示控制可只在 Lab，但视觉源、Prefab/动画、UI/VFX 共用部分不能另造“演示版”并在主体重新制作。
2. 幽灵顾客由骨骼动画改为单方向原创序列帧，另一方向水平翻转。循环动作以约 4–6 帧为预算起点，按首尾无缝、动作辨识、透明边、图集/合批及目标设备结果验收。五状态、两方向、座点/遮挡要求不减。
3. 孟桃、店铺动态件和其他决定动态的场景元素仍按骨骼规则；“每骨骼对象一页”不再应用于幽灵。幽灵的帧图可共享图集，实际贴图页数、材质与打包由 Art/Tech 出图前共同签认。
