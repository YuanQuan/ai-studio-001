# CP-UNIT-MENU-VISUAL-FIDELITY-001｜七菜单正式资源视觉一致性修订

状态：`PROPOSED`；日期：2026-10-03；发起：Master Agent。触发：用户退回 `STREET_BASE_01 v0.1` 与 `UG_GHOST_01/BENCH_01 v0.1`，指出它们与此前展示的 `UNIT-MENU-ART-DESIGN-001/v0.1` 差距很大。本提案不把旧概念图裁切、描摹或重新标记为已批准生产资产。

## 对照事实与根因

| 对象 | 旧概念展示 | 本次资源输出 | 本次漏检 |
|---|---|---|---|
| 空背景 | `v0.1/scenes/empty-scene-concept.png`：2172×724，深蓝多层山雾、近中远景光感、石桥两坡接街、石地与河面笔触有体积层次 | `UNIT-MENU-BASE-ASSET-001/v0.1/preview/empty_scene.png`：3072×1024，模块化 SVG 形状与重复纹理；山云、地面、河面、桥体的明暗和细节趋于平面，桥的侧立面成为视觉主体 | 审查重点放在桥洞、分层、alpha、纹理面积和镜头无漏边，没有以同等构图/显示尺度并排核验插画层次、材质、桥的体量和光感 |
| 幽灵与板凳 | `v0.1/characters/ghost-customer-concept.png`：明显右向移动/跑动姿态，身体前倾、双柔尾、厚实轮廓与冷色体积阴影；板凳为矮而简洁的无靠背座板 | `UNIT-MENU-GHOST-ASSET-001/v0.1/preview/contact_sheet.png`：近正面直立身体，短波浪下缘和头顶卷饰；移动/跑动差异小；板凳增加靠背并改变结构比例 | 评审验证了帧数、哈希、循环、翻转、图集与座点，却没有把侧向剪影、运动幅度、情绪姿势和板凳轮廓与概念逐项比对 |

`Art v0.1` 整版被退回的直接原因是其幽灵骨骼方案及概念板不符合后来批准的“最终正式资源、幽灵序列帧”要求；当时的审批记录明确允许**非冲突视觉方向作新版参考**。`Art v0.2` 正确禁止从概念板裁图，但只保留了“可爱、非像素、冷蓝暖橙”等抽象词，没有将可继承的视觉特征写成可检查的目标。随后两批任务的验收也以资源结构和技术可复验性为主，使用“风格一致”这一笼统条款。制作时选择了以少量 SVG 几何和重复模块快速生成可编辑源，导致正式画面与概念插画的形体、材质和光感偏离。Art/Tech/Master 在现有 Review 中把“空景简化”和“移动差异较轻”标成 MINOR，Master 仍同意送审；这是评审判断失误，不是用户要求降低美术质量。

不能把差距归因于序列帧、单页图集、左右翻转、资源复用或版权审查：这些约束要求可编辑、可拆层、独立原创和可测性能，并未要求把角色改成正面造型、把矮凳改成靠背凳，或把背景画成平面几何风。概念图本身是生成的展示稿，含生产不可用的软晕且参考权利仍须审查；新稿应原创重绘、保留经用户确认的视觉语言，不能直接裁图或机械描边。

## 修订门禁提案

1. Art 在新版本出图前提交**概念—正式源逐项对应表**，至少覆盖空背景的远中近景、山雾/云、石地/水/桥材质、桥两坡/拱洞、画面冷暖层次；幽灵的右向侧视剪影、跑/走幅度、两柔尾、五态表情和矮凳形制。只列可以安全继承的设计特征，不复制概念图具体像素或现有 IP 表达。
2. 将背景分层/复用和幽灵画布/图集先做**一段代表性高质量样张**：背景选桥口与相邻街/水，角色选移动/跑动/坐姿及空凳。同画幅、同显示尺度并排比较概念与新原创样张；Art 先签视觉，Tech 再依据真实样张核贴图、内存、合批和设备假设。不得用预算草排迫使已选视觉退化；若预算冲突，提交量化影响和备选方案给用户决定。
3. 正式输出评审分开记录**视觉符合度**和**技术有效性**。视觉符合度未通过时，即使哈希、透明边、分页、帧数、脚点全部通过，仍不得将该版本送 `USER_REVIEW` 为可批准资源。用户对这两批 v0.1 已明确退回，保留历史证据，后续新版本重新走 Art/Tech/Master Review 与用户审批。
4. Creator 和目标机检验继续独立保留 `NOT_TESTED`，不得把静态并排图当运行验收。新画面要按手机实际可见尺度检查幽灵两向、状态区分、桥行走与遮挡；同源资源身份与未来主体复用仍遵循已批 v0.2。

## 影响

Art 需重做两批正式可编辑源及导出，不复用退稿 PNG 作为正式图；Tech 重新签认实际图层/逐帧贴图尺寸与图集预算；Master 修订两 Task 的视觉验收并复核新评审；Producer 保留 v0.1 退回与版本历史，Client/QA 继续不接入这两批未批准资源。Product 的七菜单功能、幽灵 4–6 帧预算、单方向翻转、店长/店铺骨骼和七入口范围不变。
