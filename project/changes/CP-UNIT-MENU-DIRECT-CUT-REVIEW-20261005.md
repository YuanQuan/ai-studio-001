# 单元示例1切图效果直接交用户审核

日期：2026-10-05。用户最新指令取消切图效果的专业复审和额外预览环境前置环节：由本组织切图时，只需呈具体结果，由用户审核。当前四层 PSD 与输出 PNG 已由用户提供，按同一路径处理。

当前资源制作方案 Gate1 已批准；四张全画布层 PNG、同尺度重组图、来源与版本清单已存在。Master 应直接呈这些实际结果供用户 Gate2 审核，Producer 记录用户对具体版本的决定。此前 v0.1 Art／Tech／Master `CHANGES_REQUESTED` 和 v0.2 Art 浏览器视觉审查保留为历史证据，不作为本次用户审核的前置门禁，也不追认用户批准。

用户批准 Gate2 后，Client 才把该版本正式接入 Creator；Tech、Client、QA 在运行阶段核竖屏、视差、缩放、边界、纹理和设备表现。若发现必须改动 PSD 或 PNG，先说明图层、位置、原因和视觉差异，取得用户决定后再修改。已批准产品验收 S09 中的“Art/Tech 切图及同尺度重组 Review”在当前图组改为“文件与重组核对、用户直接审核”，其他 S01–S08 的运行验收不变。
