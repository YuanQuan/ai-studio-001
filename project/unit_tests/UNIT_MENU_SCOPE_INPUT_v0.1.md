# 新菜单单元样例｜用户范围输入 v0.1

日期：2026-10-02。来源：用户本轮明确列出的七项菜单样例。此文件逐项保存需求输入，供 Product 编制正式 PRD 与受影响专业评审；不以本文件替代产品、技术、美术、UI、VFX、Client、QA 的审批版本。

| 菜单编号 | 用户要求的验证内容 | 需在正式规格中明确的边界 |
|---|---|---|
| 1 空场景与镜头 | 没有店铺和精灵，只有背景；左右拖拽移动场景，放大缩小控制镜头 | 背景基底与后续可开关对象分离；输入方式、边界、缩放范围待 Tech/Client 定稿 |
| 2 店铺效果 | 先只做孟桃奶茶店，包含动效、光影；未来能切换其他店铺 | 当前仅一店，不提前制作其他店；静态店身与动态件独立，正式效果需 Art/Tech 签认 |
| 3 角色效果 | 店长通过骨骼动画渲染，当前只做孟桃，未来可切换其他店长；幽灵顾客可切换移动、跑动、高兴、沮丧、坐在街边板凳等效果 | 店长与顾客各自独立入口或同菜单子项由 Product 明确；平视角顾客仅左右两方向，制作一方向骨骼资源，另一方向水平翻转复用，翻转后的文字、挂件、手势、挂点与坐姿仍须正确 |
| 4 场景其他元素 | 树木、花草、灯笼等带特效元素可切换显示 | 每种对象独立源与开关；支持动态者采用骨骼动画，实际资产与性能范围需 Art/Tech 评审 |
| 5 UI 界面 | 独立查看 UI 效果 | 公共 UI 与 Lab 专有控制分离，避免与主体表现分叉；具体页面/组件由 Product/UI 定义 |
| 6 店长与玩家对话 | 展示孟桃与玩家对话界面，带示例文字 | 只做孟桃；示例文字须标注演示性质，不自动确立主线剧情或经营规则 |
| 7 组合场景 | 基于第1项空场景动态添加前述元素和精灵，检查遮挡关系 | 使用前面单元同一源对象/状态/UI/VFX，不能另造组合专用副本；需观察层级、脚点与前后遮挡 |

菜单是七个顶层项；第3项的店长和顾客分别可选、各自验证，Product 可在不改变七项结构的前提下设计子入口。公共返回/重置/状态说明属于菜单基础能力，不额外算一个样例。

已批准的 `UNIT-PILOT-PRODUCT-001 v0.1` 只定义孟桃奶茶店首个试点，不自动覆盖新增幽灵顾客、场景元素或对话内容。四份 `UNIT-PILOT-TECH-DESIGN/ART-SOURCE-PREFLIGHT/UI-SPEC/VFX-SPEC v0.1` 仍处于 `USER_REVIEW`；新菜单规格应评估其受影响范围，但不能把它们当作已获批下游输入。旧 `UNIT-SAMPLES-001` 九菜单任务已取消、原文件留档，不直接复制旧图或程序占位内容作为新产物。
