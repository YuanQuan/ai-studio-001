# 百鬼夜市可切换单元样例｜v0.1

状态：实现样例，待正式专业评审及用户验收。2026-10-01 用户要求把资源清单中的**全部九个单元**做成可切换样例；公共菜单不计入九个单元。

## 运行入口

1. 用 **Cocos Creator 3.8.8** 打开 `apps/client/`。
2. 双击 `assets/UnitSamples.scene`，点击编辑器顶部的当前场景预览。
3. 在菜单选择 U01–U09；每个入口有“返回菜单”和“重置”。

若要从命令行制作 Web Mobile 包，指定 `UnitSamples.scene.meta` 中的 UUID 为 `startScene`。旧 `DemoScene.scene` 保留为历史资料，仍可单独打开。

## 样例与操作

| 单元 | 本版可操作内容 | 本版边界 |
|---|---|---|
| U01 瓦片地图 | 点击 7×7 等距地图，读取行列、地表和边界 | 小图验证坐标；原 17×17 TMX 保留为旧资料，未作为此单元的运行地图 |
| U02 镜头与手势 | 单指/鼠标拖拽；双指、滚轮或 ± 按钮缩放；倍率限制 0.7–2.0 | 手机双指触控尚未在实机确认 |
| U03 建筑占格 | 五类建筑同屏；红格阻挡；按钮或方向键移动鬼客；两座桥的中央格可走 | 占格是本样例的显式数据，后续需逐资产校准到正式瓦片坐标 |
| U04 建筑四方向 | 切换摊位、桥、阎罗殿、灯笼、岸树及北东南西；摊位破败/修复切换 | 现有源图只有单向。右侧四方向房形为**程序占位**，不代表正式四方向美术已交付 |
| U05 精灵四方向 | 店长及三类顾客选择；四方向脸部形体、脚点、移动和阻挡 | 程序形体为占位；现有顾客只提供单方向两帧行走图，正式四方向角色资产待制作 |
| U06 层级遮挡 | 移动顾客，观察脚点排序和独立紫色屋檐前景层 | 紫色屋檐为程序占位；原建筑图尚未拆分正式屋檐/桥栏图层 |
| U07 场景轻特效 | 独立开关灯笼光晕及地面反光、水波、树叶微动 | 程序示意，不是物理灯光或正式 VFX；需在手机上测性能与观感 |
| U08 UI 与交互 | 按钮按下态、修复确认/取消、摊位修复状态、返回和重置 | 无经济扣费；720×1280 设计画面采用完整显示策略 |
| U09 密度与性能 | 20–200 个角色逐级增减，显示样本 FPS | 桌面 Web FPS 仅用于发现明显问题；需指定目标手机、记录帧时间与 DrawCall 才能形成性能结论 |

U03、U05、U06 可使用方向键或 WASD，也可点击画面下方方向按钮。`Esc` 返回菜单。

## 技术边界

- 每个单元进入时重新创建独立节点，返回菜单时销毁当前节点；旧静态场景根节点在本场景中关闭。
- 运行中的 PNG 继续引用 `assets/demo/` 的原 21 张 SpriteFrame，不复制资源。
- U04/U05 的四方向形体仅验证朝向状态、脚点和切换接口；正式四方向图需要 Art 单独制作和审批。
- U06 用独立程序图层验证遮挡顺序；正式分层 PNG 仍是后续资产任务。
- 本版没有声称手机 60 FPS。U09 读数应配合真机持续采样再定性能预算。
