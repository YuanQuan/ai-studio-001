# 七菜单正式资源与幽灵序列帧修订输入

日期：2026-10-02。来源：用户在审阅七菜单 Tech、Art、UI、VFX 四份 v0.1 后明确表示：

> 批准，需要确认的是在单元示例当中的输出资源也是最终正式资源，其中顾客部分使用序列帧动画，不需要采用骨骼动画，序列帧数量在4-6帧左右能达到首位循环就行。

Master 按上下文把“首位循环”理解为动画首尾能自然循环；这是对实现目标的低风险语义解释，不改变用户给出的约 4–6 帧量级。实际状态逐帧数量、播放速率、过渡与循环缝由 Product/Art/Tech/QA 在正式版本中定义和验证。

## 对现行范围的明确覆盖

- 七菜单的单元成果应是后续主体游戏使用的正式同源资源和可运行功能；概念图、SVG 示意、旧 Demo 资源及一次性占位图不得冒充最终交付。正式资源须提供可编辑母版、来源和许可、合批与目标设备验证，独立入口、组合入口、主体入口引用同一版本。
- **幽灵顾客是动态骨骼规则的明确例外**：使用原创单方向序列帧，另一个左右朝向水平翻转同源帧；五类状态仍覆盖移动、跑动、高兴、沮丧、坐姿及左右×五状态的验收。可循环状态以约 4–6 帧为首选预算，须实际检查首尾衔接、形体跳变、透明边、动作辨识、左右翻转和板凳接触。不能把五种状态强行压成总共 4–6 帧而损失状态区分。
- 孟桃、店铺可动件及选定动态树花灯等仍按已批准的骨骼原则制作；每骨骼对象单页要求继续有效。幽灵改为序列帧后按共享图集/材质的实际排布和运行批次确认，不再套用“幽灵骨骼一页”的旧条款。
- 本修订不增加店铺、顾客种类、玩法、付费、剧情或资源数量。若测试表明约 4–6 帧不能达到可辨动作与自然循环，应由 Art/Tech 提出可审阅调整，不静默增加大量帧或退回骨骼。

旧 Product v0.1、Tech/Art/VFX v0.1 中写有“幽灵骨骼”的条款保留为历史，不作为新正式资源生产输入。UI v0.1 只批准结构/交互规格；SVG 仍是审阅示意，正式 UI 资源另走生产与版权门禁。
