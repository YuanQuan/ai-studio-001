## 2. 对象、母版与单页候选

可编辑母版在仓库根 `art-source/units/<对象ID>/`，保留分层、骨骼工程、导出预设与来源/授权记录；运行资源统一放 `apps/client/assets/units/<对象目录>/`，由Creator产生并保留`.meta` UUID。各Lab与组合场景只引用运行资源，不复制导出PNG。禁止从已选长街/概念关系图裁切生产资源；底板、店体、骨骼、光影、字与特效分层重作。

| 对象ID | 分层/动画与单页要求 | 草排起点（非批准上限） |
|---|---|---|
| `STREET_BASE_01` | 静态天空远景、地/水、桥和栏杆的前后分片；它**不是骨骼对象**，可按镜头覆盖和装载策略分纹理 | 长幅概念2172×724不是最终生产纹理；各分层尺寸待镜头实测 |
| `MT_SHOP_01` + `MT_SHOP_MOTION_01` | 店体静态前/后层，动态帘等归一骨骼对象一页；灯亮部/邻近材料暗部与投影为可比较独立表现 | 动帘512²一页候选；店身静态图另排，不把光晕烘进店体 |
| `MT_CHAR_01` | 孟桃单实际视角 idle/work 及替换手/杯/腰牌等附件，骨骼对象一页；腰牌仅“孟” | 1024²一页候选 |
| `UG_GHOST_01` | 一个原创方向的左右五态所需**全部**附件一页；另一向只翻视觉根，不多绘镜像页 | 1024²一页候选；坐姿最大扩展与手势占用待量 |
| `BENCH_01` | 独立静态前后片和座点，不打包进幽灵骨骼 | 尺寸待双方向坐姿与手机投影核验 |
| `UE_TREE_01` | 若轻摆为动态，树骨骼所有附件一页，静态树根/地影可独立层 | 1024²一页候选 |
| `UE_GRASS_01` | 动态草花骨骼附件一页，静态土/盆独立 | 512²一页候选 |
| `UE_LANTERN_01` | 动态灯笼骨骼附件一页，独立暖光/VFX与世界阴影 | 512²一页候选 |
| 身份UI/对话UI/VFX | 正式UI组件共用资源与字体；Lab导航独立。若VFX决定使用骨骼，其**每个骨骼对象**同样一页，若使用非骨骼表现则由正式VFX规格解释 | 不为未批准效果预占具体图集尺寸 |

RGBA8未压缩基础估算：512²约1MiB、1024²约4MiB、2048²约16MiB；仅为单张GPU基础像素量，未包含mipmap、拷贝、压缩/回退、帧缓冲或其他资源。PNG文件大小不能代替显存。若草排放不进一页，先精简透明边界、复核真实屏幕投影与必需附件，再提Art/Tech重评；不得自动改成两页或把反向专属图藏进静态图。可考虑2048²作为重新评审候选，但要以目标机最大纹理、冷启动、压缩与显存测量为依据，绝非默认放行。

## 3. 每次正式出图前的 Art/Tech 双签字段

每一对象每一版建立独立记录：对象ID与场景用途；对应已批准Product/Art版本；参考来源、相似性检查及图片/字形/字体的使用、修改、嵌入、分发许可；原始分层母版和骨骼工程路径；制作人、作者工具席位/许可与精确版本；Creator及目标平台；实际全部附件清单和包围盒、极限姿态、换装/表情/坐姿所需替换件；骨骼slot、世界脚点/座点/挂点、翻转后非镜像节点；一页打包预览、实际宽高、有效面积/留白、padding/bleed、alpha模式与过滤；材质/混合/裁剪/前后插层；预计基础纹理量、压缩/回退候选和合批断点；720×1280及目标机远近镜头可读性；Art与Tech签名、日期、结论和重签触发条件。出图后核对真实atlas页数、尺寸和哈希与签认一致；改变附件、工具版本、页尺寸、镜像方案、平台或材质必须重新预检。

作者工具路径：在已登记合法许可的工作站用与仓库`spine-3.8`运行时兼容的实际Spine版本制作；提交可编辑工程、`json/skel`、atlas描述、唯一纹理PNG和导出设置；在真实Creator 3.8.8导入、预览、构建并留日志。当前机器有限路径未见Spine编辑器，也无许可证证据，故还不能实际生产骨骼。官方[Cocos Spine资源说明](https://docs.cocos.com/creator/3.8/manual/en/asset/spine.html)、[Spine版本指南](https://esotericsoftware.com/spine-versioning)和[Spine许可条款](https://esotericsoftware.com/spine-editor-license)为版本/许可检查依据。

## 4. 合批与可见性验证

“每动态骨骼对象一页”只限制该对象的附件纹理页数，不等于一对象一DrawCall，更不等于所有动态对象共一批。不同骨骼数据、材质、混合模式、裁剪、插入的店前柜/栏杆Sprite、UI/VFX层都可能断批。先用 Creator真实Profiler记录店+孟桃、幽灵双向五态、树花灯全开、组合峰值的DrawCall，再评估`sp.Skeleton.enableBatch`等选项；不能只看开关名。[Cocos 3.8 `sp.Skeleton` API](https://docs.cocos.com/creator/3.8/api/en/class/sp.Skeleton)供实现核对。带字牌匾、孟桃腰牌与对话UI不跟幽灵视觉根翻转；暖光/阴影不因角色镜像反向。alpha边缘、半透明叠层和小屏文字在目标设备实际截图复核。
