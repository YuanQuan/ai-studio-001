# 空背景与幽灵正式资源视觉差距：Tech Lead 内部评估

日期：2026-10-03　性质：只读成因评估与下轮技术建议；不构成资源批准、规格变更或出图许可。

## 依据与结论

对照用户指出的[空景概念](../../../art/UNIT-MENU-ART-DESIGN-001/v0.1/scenes/empty-scene-concept.png)、[幽灵概念](../../../art/UNIT-MENU-ART-DESIGN-001/v0.1/characters/ghost-customer-concept.png)，以及被退回的[空景输出](../../../art/UNIT-MENU-BASE-ASSET-001/v0.1/preview/empty_scene.png)和[幽灵接触表](../../../art/UNIT-MENU-GHOST-ASSET-001/v0.1/preview/contact_sheet.png)：前者有明确的近中远景、石材与水面受光、山雾层次、桥两坡接街；幽灵有右向前倾的身体、两条向后飘的柔尾和较明显的走跑差异。正式资源则主要使用平直 SVG 几何和重复材质；桥侧立面压过桥面；幽灵轮廓近正面直立、短波浪下缘，板凳另加靠背。这是造型、绘制与视觉验收的差距，**不是已批准技术约束的必然结果**。

旧概念是视觉参考，不是可裁切的正式资源，其来源与具体表达仍需独立做权利审查。下一轮应以原创可编辑母版重绘所需的视觉特征，不能描摹或转用旧图像素。

| 被质疑的技术条件 | 实际约束 | 对本次退化的判断 |
|---|---|---|
| 顾客序列帧、单方向水平翻转 | 左右共用一个原创朝向；走、跑各约 4–6 帧循环 | 更适合先画清晰侧向剪影。帧数限制时间采样，不限制单帧明暗、双柔尾、前倾或动作跨度。需校验镜像后的光向与非对称饰件。 |
| `1024×512` 单页图集 | 当前 23 帧打包后的实测结果，RGBA8 基础量 2 MiB；[已批 Tech v0.2](../../UNIT-MENU-TECH-DESIGN-001/v0.2/ASSET_PIPELINE.md)没有把它定为幽灵硬上限 | 此尺寸可解释当前 `160×192` 逻辑画布的清晰度上限，不能解释造型被改成正面。先确定目标屏幕尺寸和新原画，再按真实包围盒、padding 与设备限额重排页数。不能为保一页损坏画质。 |
| 可编辑源、资源复用、背景分层 | 源必须可编辑；桥、水、路及前后遮挡片可独立，复用要控制内存 | 多层绘制、渐变、笔触及材质变体都能保留可编辑性。当前 16 张贴图、42 处放置、约 8.4375 MiB RGBA8 是 v0.1 签认的实现方案，不等于所有后续版本的固定上限。相同尺寸的贴图可以承载更丰富的笔触；只是复制同一瓦片会带来可见重复。 |
| `720×1280` 平视相机 | 世界 `3072×1024`；缩放下界约 `1.25`，初始约 `1.35`，对应世界可见宽度约 `576`/`533` | 横幅全景并不能代表竖屏首镜头。当前中心镜头几乎只见桥，放大了桥侧立面造型问题；需在实际镜头和全景两种尺度评审，不能通过降低画面层次来适配窄视窗。 |

此前技术 Review 对尺寸、哈希、透明度、图集、接缝和静态镜头覆盖有证据，也注明 Creator/目标机未测；但没有将侧向剪影、桥体体量和插画明暗层次设为硬视觉门槛。静态技术合格不代表画风合格。Tech 下轮应在 Art 视觉通过后才把技术通过作为送审依据。

## 下一轮可执行技术路径

1. **先锁视觉样张目标。**背景取桥口、两侧接街、支流水面，并带一段远山与月光，以能看出桥上行走坡度、洞内透水和材质厚度；幽灵取右向走/跑的关键姿态、坐姿与独立空板凳。Art 用原创分层母版绘制完整光色、体积和轮廓，不从概念板裁图。代表样张先于整套复制，避免把不达标的模块扩成 42 处放置。
2. **保持运行时结构，放宽错误的制作假设。**空景仍拆天空/远景/街面/河/桥后片/桥前片，桥洞保持真实透明，顾客与板凳独立；但源可采用分层绘画或更复杂的矢量路径、蒙版和纹理笔触，不要求用少量代码生成的基础形状。固定天空、山雾、月光、石材受光可烘入各自静态层；独立可切换的树、灯笼、顾客和动态光仍须单独资源。地面与河面采用可平铺底材加有限原创变体，统计新贴图数、接缝和可见重复。
3. **按屏幕像素选幽灵尺寸，再排图集。**先在 `720×1280` 的初始、近、远镜头中确定顾客投影高度与可辨表情/双柔尾的最小像素，再给每帧统一逻辑画布、脚点、座点、透明安全边和极限姿态包围盒。逐帧源可共享设定与绘画图层，但走跑帧需有可见的前倾、尾部摆动和步态变化。输出 4–6 帧循环时并排检查首尾；若预算内达不到自然循环，量化更高帧数的贴图/内存影响并走变更，不暗增帧数。板凳维持独立前后片、座点和无遮挡的可坐结构，并核左右翻转接触。
4. **以实图草排性能。**记录每帧非透明包围盒、trim/pivot、padding、各 atlas 页尺寸与占用率、基础 RGBA8 字节和目标设备纹理上限；多页及材质/前后景插层分别估算 DrawCall 风险。背景比较“原尺寸更丰富内容”和“新增材质变体”两种方案的贴图量及屏幕收益。最终内存、帧时间、Creator 3.8.8 导入和目标机合批仍为 `NOT_TESTED`，直到真实工程和设备记录出现。

## 代表样张出图前与复核门槛

代表样张是图片产出，仍需遵守已批准的每次出图前 Art/Tech 双签：**文字视觉目标及原创/许可记录 → Art/Tech 样张预案签认 → 原创样张出图 → Art 同尺度视觉 Review → Tech 对实际像素与排图 Review → 定版完整资源再次按变更点复签并导出**。若样张显示必须改图集页数、帧画布、背景贴图拆分或镜头覆盖，先更新预案再签，不能沿用旧 v0.1 的数字自动放行。

下轮检查应在同一张对照表逐项留证：

- **视觉**：空景的远中近景、雾、月光冷暖、石/水不重复的体积笔触、桥两坡可走与洞内水连续；幽灵明确朝右的头身剪影、前倾和双柔尾、走跑姿态差、五态表情/姿势、无靠背矮凳形制。用概念图对照特征，不进行像素描摹。
- **尺寸/镜头**：全景及 `720×1280` 西/中/东首镜头；缩放边界 `1.25`、`1.35` 和拟定放大端；检查不露白、可见路面/桥坡/河流比例、角色在街与座位的实际屏幕尺寸。`1.25` 为竖向刚好覆盖的解析值，正式机型要检查滤波边缘，不能视为已实测余量。
- **资源**：桥洞 alpha、桥前后片和顾客/凳腿遮挡、河道透水、tile 接缝与重复、帧首尾闭环/脚点/座点、镜像光向、页数与内存、来源/工具/字体许可、母版和导出哈希。
- **独立门禁**：Art 明确记录视觉 `PASS/REVISE`；Tech 明确记录静态资源 `PASS/REVISE` 与 Creator/设备 `NOT_TESTED/PASS`。任一必要项为 `REVISE` 时不得以另一项通过代替。

对 Master 的[分阶段提案](../../../../project/changes/CP-UNIT-MENU-VISUAL-FIDELITY-001.md)评估：**可供用户审阅，技术上可行**。代表样张先行能在大量资源重制前发现风格和尺寸冲突；建议把上述“样张首次出图也须预签”及同镜头尺度、实图预算、两道独立 Review 明写入执行版。此评估不更改已批准的 Tech v0.2、两批 Task 或 Producer 状态。
