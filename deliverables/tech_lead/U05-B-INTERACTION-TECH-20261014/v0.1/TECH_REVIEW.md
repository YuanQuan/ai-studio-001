## 现有实现事实

`milk_tea_state.ts` 的 `submitCup(run, nowMs)` 先按原 deadline 判到期，再检查三类齐备及配方，并同步清空选择、推进订单或标记赢；`settleWin` 用 `settled` 防重复发奖励。`milk_tea_lab.ts` 当前 `renderGame()` 直接把 `run.selected` 显示在工作杯；`update()` 仅在 `playing` 时按秒更新及判到期，`render()` 重建页面子节点。新增动画若直接绑在这些每次重建的临时 Node 上会被销毁，须让视觉事务状态独立于业务 `Run` 并在 render 重建后可恢复/重放当前相位。

## 建议的业务与视觉分界

1. 选料阶段只在台面显示三类已选配料，工作杯整体隐藏，不更新 `CUP_TEA/MILK/TOP` 内容。UI 同版三槽分别 `[345,1150,90,84]`、`[467,1150,90,84]`、`[589,1150,90,84]`，是无热区的纯视觉槽；对象 ID 来自现有12项配置与获批素材，按 90×84 框 contain 居中，同类重选替换、撤销最近有效选择。台面摆放不遮十二格或底部按钮；1024×1536 源图坐标随整图 contain 缩放。Art 已只读发现 `STATIC_BARE` 窗口幽灵轮廓/气泡尖和台面杯残影，须从当前 PSD 仅对对应遮罩内局部净底，并经既有制作与资源审批；不能以新层掩盖。
2. 点击「确认」在同一个单调时间 `nowMs` 对 `submitCup` 判定**一次**，先复制不可变快照 `{orderIndex, recipeId, selected三ID, result, submittedAtMs}`，然后锁住选料/撤销/确认的再入，视觉播放短时台面→杯内三层合成。动画只回放快照，不在末帧再次调用 `submitCup` 或重新读当前选择。未齐备仍走原提示，不启动合成。错杯清空选择后，失落表情结束仍留同一顾客与同一订单供重做；不得变成失败结算。
3. 提交判定可能已经把业务状态推进到下一单/赢，但绘制层需持有旧客、旧订单及快照，直至反馈/进出完成。UI 同版安排合成 `0–650ms`，非末杯开心 `650–950ms`、完整出场 `950–1400ms`、下一客完整入场 `1400–1850ms`；到时才呈现下一单并解锁，整体目标≤2.2s。非末杯正确后的动画中倒计时继续；deadline 到时应中止下一单队列，转超时失落 `0–300ms`、完整离场 `300–750ms`、失败。最后一杯若在 deadline 前已判 `won` 且一次结算，后续表现跨截止不得反判失败。`update()` 只对 `playing` 判到期可维持最终杯原则，但 UI 相位队列须在到期时取消。
4. 退出确认时计时仍推进，超时优先按现有规则失败；退出本局只结清视觉队列、不发经验。页面关闭/重试/返回菜单/组件销毁均取消 pending tween/timer、使回调 epoch 失效并释放持有节点，不允许旧动画晚到后改写新一局。加载失败与重复点击只显示原错误态，不创建第二份合成事务。

## Cocos 3.8.8 与资源预算

现有杯层为获批 `CUP_*` 183×233 透明统一画布；继续 `sprite.trim=false`，台面→杯内用 Node 位移/淡入和现有杯内容 Sprite，合成完成恢复稳定杯画面。顾客身体与脸部挂在同一移动节点，窗体裁剪 `Mask.Type.GRAPHICS_RECT` 作为**固定父节点**；订单气泡和目标杯不进 Mask，而在入场完成后显、出场起点先收，避免气泡被裁或与人分离。本机 Creator 3.8.8 `cocos/2d/components/mask.ts` 有矩形图形遮罩，尺寸取父节点 `UITransform.contentSize`，可裁子节点；工程路线可行。同版 UI/Art 统一采用保守内窗源矩形 `[260,278,490,505]`（右 x750、下 y783），冻结角色停靠框 `[309,484,332,301]`；最末 2 源像素由柜台前沿遮挡。完整藏出左边界的通式为 `offscreenLeft=windowLeft-332`，即左上 x=-72，相对停靠 x309 的位移 -381 源像素。代表样片仍须验证窗框/柜台遮挡与停靠脸，若需调整边界须同版修订，不能静默把候选当实测切线。不得以淡出掩盖半身未移出。表情用同源四脸 `neutral/blink/happy/disappointed`：反馈起始 `0–80ms` 压眼、`80–150ms` 闭眼、`150–300ms` 展开到开心或失落，再按同版反馈时序留窗或离场；不能用整身晃动冒充脸动画。运动中计时不变，目标机掉帧不得推迟逻辑判定。

气泡 `[467,288,375,235]` 不动，订单杯按中心 `(653,416)` 整组乘 0.78，目标约 `[594,346,118,140]`；同一 183×233 内容画布及杯壁/吸管同比缩，不单缩内容造成漂移。360×640 视窗约 41×49 CSS px，三类内容辨识性必须由 Art 同尺度实图与 Client 运行检查。优先保留同源切片；Art 只计划同一角色最多四个局部脸状态、窗口幽灵轮廓与气泡白尖净底、台面杯残影净底及必要遮挡。Art 两段制作活动上限共 75 分钟，同一问题最多 2 轮；当前实际生成调用 0。Gate1 方案为确定性编辑优先，若局部融合无法恢复，申请全批最多 3 次局部 imagegen 调用（窗口/气泡尖、台面、脸关键姿态各代表区），须在用户批准具体方案、首图前 Art/Tech 同批预签下执行；预算上限不等于现已授权调用。具体资源 Gate2 批准后才接入。
