# PATCH-03 片区复用只读技术意见

**结论：可作为用户待决方案评估，当前不预签、不制作。** 三个建议矩形合计 141,452 源像素，虽只改 `STATIC_BARE` 底层并能保持框外原像素，整体复制 donor 会改变框内自然夜景、木纹和光照，不等于只清旧物。旧用户批准的精细局部净底和已耗尽的两轮自动加一次手工候选，不能自动授权这项整体片区替换或新的第 3 轮。

接缝风险有实数依据：杯沿框顶部 185/185 个边缘像素与原底图不同，73 点跨边界梯度增加超过 8、14 点超过 16，硬贴最易出现一条矩形边；窗口和玻璃框边也分别有 1,022/1,396 与 310/484 个不同点。部分旧杯或幽灵的半透明轮廓可能越过现有框，旧杯独立层 alpha bbox `[415,1090,604,1328)` 已宽于杯沿框 `[418,1090,603,1130)`。因此即使框内 donor 无旧物，仍可能在框外留下残影或在柜台、夜街、木纹及透明原料杯后出现突变。仅实际合成后的全画幅、源尺度局部和 360×640 contain 对照才能判定；不能靠框外零差异或源 donor 单图提前宣称通过。

方案正确区分独立语义层：标签文字像素不与片区交叠；窗口与顾客、柜台、订单气泡等叠层交叠，玻璃区与工作杯及 12 个原料杯变体叠层交叠。若获用户批准，也只能替换底层，保留独立 PNG/alpha/层序及其 SHA，并检查透明处可见底色变化。若旧影或接缝仍在，应停止，不自动扩框或柔化边界规避框外零差要求。
