# 桥上方栏杆局部去边：技术切图意见 v0.1

本批只处理 `bridge_front_l`、`bridge_front_r` 的已确认①②③外缘。两张输出继续使用透明 RGBA PNG，各为 **225×177 px**；保留原裁切框、位置、支点、图层顺序和遮挡关系，不扩展画布或 alpha 外包围盒来容纳新像素。当前正式工程文件只作为只读来源，新版本在 Art 交付目录输出，待具体 PNG 获用户 Gate2 批准后再讨论接入。

工作母版沿用 `deliverables/art/EXAMPLE-REVISION-ART-20261015/v0.1/source/scene_sakura_revision_master.psd` 的 **3072×1024 px、48 层**。`bridge_front_l` 与 `bridge_front_r` 分别对应原清单中索引 18、21（零基）；其余 46 层直接复用，逐文件 SHA-256 核身份。修订层的全画布坐标、图层顺序及两张导出图的局部坐标须沿用原图映射，避免引入重组位移和接缝。对两片原图分别核修改区以外的可见 RGB 与 alpha 零差异；对石栏、灯体、灯内暖光等主体像素也须保持原值。圆圈矩形只是定位，不应整框删像素。

图片候选最多每侧一次、合计两次；只用来判断局部 alpha 轮廓。最终主体纹理由原像素与显式遮罩产生，不接纳生成式重画。若候选不稳定，按获准范围在原层做一次确定性遮罩修正；仍不能守住主体或必须扩区时记录差异并停止。输出原/新灰白深底同尺度对照、当前 PSD 实际导出重组和逐区域差异统计；比较需固定解码、alpha 与合成背景设置。

本批复用现有两张贴图尺寸，不增加贴图面积、图页、动画或外部依赖。上述是静态资源预算约束，图集装箱、压缩后的占用、DrawCall、Creator 导入、实际视窗与目标机性能均为 `NOT_TESTED`；不能据 225×177 尺寸宣称运行通过。自产切图连同映射和重组直接交用户 Gate2，不增设成品视觉专业复审；获批前不修改 `apps/client`。
