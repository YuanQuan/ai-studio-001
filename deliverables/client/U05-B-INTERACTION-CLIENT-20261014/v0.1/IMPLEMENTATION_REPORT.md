# U05 台面选料与顾客反馈客户端实现报告

状态：实现前概要通过 Tech Review；独立客户端代码与状态检查已产出。当前因 Art 新资源 Gate2 未批准，按 Task 明确边界停止于静态/状态验证，等待 Gate2 与 Master 后续构建授权。当前任务应为 BLOCKED，不是可试玩版本。

实现保留 milk_tea_state.ts 为唯一业务判定来源，未修改三维配置、截止时间、奖励、存档或结算规则。确认处理在业务状态变更前复制订单索引和原料 ID 快照，取得同一个单调 nowMs 后只调用一次 submitCup。动画不再次判定或读取清空后的选择；窗口超时、错杯、赢杯及退出均通过独立 presentation transaction 表现，不向 Run 添加表现字段。状态层 SHA256 与上一已复核版本一致。

游戏选料期间仅显示茶/奶/小料三件原料及原有类别格点，工作杯隐藏；撤销和同类替换继续调用旧选择状态函数。确认后复用已有原料/杯层资源生成动态台面至杯内过渡。错误表现留同一客/同一订单，正确非末杯完整移出后再完整移入下一位，最后杯胜利不会因动画越过 deadline 再判超时。deadline 中断非胜利事务并开始超时离窗；主动退出将当前客中性离窗，再回难度选择，且不调用奖励结算。初次开局新增450ms入场事务，deadline 仍从创建 Run 时原点开始计算。

表现控制器与业务 Run 分离，使用绝对 elapsed 和 epoch 令重试/退出/销毁后的旧事务失效。稳定节点只在提交、交互边界或阶段改变时构建；活动事务的每帧工作只修改已存在的节点位置、透明度和活动状态，不逐帧重建整个 root，不创建粒子或引入第三方依赖。订单杯统一父组围绕原中心缩放0.78；顾客组采用固定矩形 Mask 与完整 x=309→-72 位移。沿用 setExitHandler(handler) 与 onExit 两种既有 API。

本轮未引用、复制或导入尚未 Gate2 的脸部、辅助 FACE_SQUASH、窗口/台面净底资源。状态采样器保存 neutral/blink/happy/disappointed 与补间进度，实际脸图绑定留待准确 Gate2 清单；届时每张 332×301 稀疏脸图必须保留全画布并设置 `Sprite.trim = false`，防止自动裁边后局部拉伸。超时中断客人离窗时从当前采样 X 连续离开；客人已在 -72 时直接完成，不召回。末杯胜利的订单气泡保持隐藏。现有 STATIC_BARE 残影也未用程序遮罩冒充净底。因此新表情、静态残影清理、Mask/遮挡及实际新视觉运行均未验证。验证记录在 evidence/STATE_CHECK.md；TypeScript 检查及纯状态用例通过，Creator 新构建、真实浏览器、性能和 QA 均未执行。BUILD_IDENTITY 明确标记未构建，不引用 U05 旧版 8876 产物作为本轮身份。
