# U05 B 前端落地概要设计 v0.1

## 1. 目标与范围

在既有 U05 独立前端 Lab 中消费已批准的 12 种原料、174 个配方、五档难度和十阶段配置；更新三类原料合成、阶段选择、存档/验证状态与结算逻辑。工作杯、目标杯和选料项按同一配置 ID 映射，杯内显示实际选择的茶底、奶类和小料。按钮文案为「确认」。

实现可复用九宫格背景与 BMFont 字图集组件接口及接入检查，但具体新版切片 Gate2 获批前，不把新版 PNG/FNT 导入客户端正式资源目录。已有图片仅按 Producer 对每个 PNG 的精确 SHA 保留清单使用；文字相关待修订图不接入。保留旧逻辑可回归的 legacy generator。仅前端示例，不新增服务端、玩法数值、配置字段语义或正式游戏入口。

## 2. 现有能力复用

- `apps/client/assets/labs/u05/milk_tea_state.ts` 已有存档规范化、解锁、阶段选择、计时、订单、撤销、结算与隔离验证设置；本次改其配置维度模型，并保留原逻辑作为 legacy 路径，防止旧规则回归能力丢失。
- `apps/client/assets/labs/u05/milk_tea_lab.ts` 复用独立 Canvas Lab、触摸/鼠标输入、生命周期资源释放和本地存档入口；替换纯色杯内容表现为原料图层组件，补充新版状态和数量展示。
- `tooling/config/milk_tea_config_generator.py` 复用现有工作簿读取、字段/引用校验、散列与输出流程，新增三类/174 配方生成路径并保留旧版生成模式。仅按授权将 201 行状态设为 `READY`、`export_enabled=true`；业务数字不改。
- Art 已获准的 PNG 以 `RETAINED_ASSETS.json` 的逐项 SHA 清单为唯一复制依据；新九宫格/BMFont 运行接口依据 `deliverables/tech_lead/U05-B-COMPONENT-TECH-20261014/v0.1/TECH_DESIGN.md`，待 Gate2 后再绑定实际资源。

## 3. 结构设计

- 配置层：稳定源表及归档、字段说明、索引、配置生成器与客户端 JSON 保持单向生成；校验原料维度数量为茶 3、奶 3、小料 6，配方 174，难度 5 档、每档 2 阶段。
- 状态层：新版 `milk_tea_state` 仅使用 TEA/MILK/TOPPING 三维，覆盖选料、撤销、订单目标、阶段/难度、计时与结算；存档保留现有 key/兼容读取，验证设置单独隔离。
- 表现层：`milk_tea_lab` 按配置 ID 组合目标杯与工作杯图层，订单、原料选项和杯体映射同源。构建九宫格与 BMFont 可复用组件，资源仍为待批准引用；文字缺失或资源未批准时明确显示可读的系统 Label，不伪称新字图集已运行。
- 不改 `UnitSampleGallery.ts`、`package.json` 或其他线程文件；仅触碰本 Task、授权 Lab、配置生成器及获准发布需要的配置路径。

## 4. 协议与平台影响

无后端、网络/API 或跨端协议变化。示例使用 Creator 3.8.8 现有 API 和本地 `sys.localStorage`。同工程可能有其他 Creator 任务运行，构建前检查占用；必要时在隔离副本构建，保留来源 commit/工作树与输入散列。

## 5. 性能影响

- 不新增每帧轮询；计时仅在进行中按秒刷新，输入仍由触摸/鼠标事件驱动。
- 复用/缓存配置 ID 到资源帧的映射，避免每次渲染反复扫描配方；杯层只随选料状态重绘，不产生持续 Tween 或粒子。
- 资产沿用获准纹理，实际 atlas/DrawCall 尚待 Creator 构建与运行观测；新九宫格和 BMFont 资源导入后再核尺寸、图集批次及内存。
- 组件销毁时解绑事件、释放配置引用；不新增大型依赖、对象池或后台任务。

## 6. 日志与调试

复用 U05 隔离 Lab 和独立 `u05.milk-tea.lab.v1` 存档键；保留验证设置独立键，不能污染正常存档。错误提示使用中文，资源 ID、配置字段和模块标识保持稳定。提供配置/状态证据及构建身份记录。

## 7. 测试与验证

- 配置生成器检查：源表字段及引用、201 行状态、三类数量、174 配方、五难度十阶段、导出 JSON 与 SHA；对比确认数字字段未变。
- 状态检查：三维选择/撤销/错误配方/订单完成/阶段计时与结算；存档合法化和损坏恢复；验证设置不写入正式进度；逐难度核对两个阶段的选项数量与配方覆盖。
- 组件检查：无新版资源时验证布局组件接口与显式降级；Gate2 批准后再验证九宫格 inset 18/18/12/12、BMFont FNT/PNG 配对和动态字符串覆盖。
- 按 Creator 3.8.8 CLI 执行隔离构建并核实际输出；通过本地 HTTP 与 Codex 内置浏览器检查真实 Web Canvas、输入、存档和杯层。缺少新图时明确记录 `NOT_TESTED`，不回退整图烘焙交互。

## 8. 风险与 Tech Lead Review

- 旧状态模型含茶/奶/小料/甜度/冰量五维，若只调整 UI 会残留旧 generator、选项池或存档误读；实现需明确 legacy 与新版入口及配置版本兼容。
- 三类十二原料和 174 配方来自批准源表，不能依据旧 JSON 自行推断或改值；机械 READY 发布及正式生成按配置合同留档、校验。
- Creator 3.8.8 对 BMFont 动态字符集、Sprite 九宫格 border 与本地脚本组件资源引用需以实际导入/构建验证；Gate2 未批前只交付代码能力与计划路径。
- 请 Tech Lead 复核配置生成器的版本分流/兼容、同源杯层映射、Creator 3.8.8 组件 API、资源引用和隔离构建身份方案；当前实现按已提供的组件技术设计约束执行。
