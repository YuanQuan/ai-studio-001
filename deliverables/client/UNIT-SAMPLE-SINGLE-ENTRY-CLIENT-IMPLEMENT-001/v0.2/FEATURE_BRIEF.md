# U01 竖屏全屏修订概要 v0.2

依据：用户于 2026-10-06 对待审客户端实现 v0.1 的明确修订指令。按 `USER_REVIEW -> REVISION` 处理，保留 v0.1 交付与证据。此为当前实现的展示、适配及安全边界修订，沿用已批准四层内容与镜头操作。

- 场景占满手机竖屏可见区域；画面按高度覆盖，允许水平裁切。屏幕比例改变时重新布局，不保留原 660×680 小视口和上下说明区。
- 复用现有四层 PNG、Prefab、镜头控制器、UI 绘制与按钮；不重制图片。缩放下限为覆盖屏幕的 1×，上限沿用 1.8×。
- 横移由最前景完整图幅约束。四层同画幅、从后到前速度 0.3/0.8/1/1，最前景是横移限制的紧边界；每边留 2 个 UI 单位覆盖余量，避免采样边缝。
- 缩放与视口改变后立即重新计算左右极限并收回越界位置。重置恢复中心与当前视口的覆盖倍率。
- 现有 −、重置、+ 控件浮在场景底部；返回按钮浮在左上。UI 捕获只覆盖按钮区域，浮层其余空白仍可拖动。
- 悬浮按钮避开系统安全区。Web 手机比例验证覆盖 9:16、9:18、9:19.5、9:20、9:21；分别检查最小/最大缩放、左右端、缩小回收、重置及 resize。
- 修改范围：Gallery 与 Controller 的代码、当前实施 Task/Artifact 修订和流程记录；Scene/Prefab/PNG/meta 身份保持原样。用 Creator 3.8.8 CLI 隔离快照构建，HTTP 实际产物在 Codex 内置浏览器检查。
- 性能：保持四层图像与事件驱动更新；不增加逐帧循环。正式 QA 执行门禁仍按当前任务协议保留，本轮记录实现验证。
