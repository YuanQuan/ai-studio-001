# U00/U01 樱花 v0.3 客户端接入概要

状态：Tech Lead Review 通过（遮挡分桶按补充校正执行）。用户已批准 Art v0.3 的 18 张 PNG 与 43 个环境实例；本任务把同一资源与布局数据接入 U00/U01，并兼容 U04 的共享背景消费者。

## 1. 目标与范围

- 将批准的 18 张 PNG 原字节接入 Cocos Creator 3.8.8；以唯一布局数据生成 43 个环境实例，保留清单底到顶顺序、宽高、镜像和 motion 标记。
- 在现有 `pf_street_base_01` Prefab 内替换旧五张背景，保持 Prefab UUID、五个直接子层 `L01_Sky` 至 `L05_WaterGrass`、相机控制器和 U00/U04 插入实体层的接口。
- U00 与 U04 使用同一 Prefab 与同一布局定义；U00 保留六店、游客、显隐、镜头和店铺调节。U01 使用同一 43 条初始布局，沿用现有临时编辑器能力；支持选中、添加、删除、拖动、缩放、镜像、层序调整、重置、JSON 导出及离开恢复。
- 旧 U01 环境活动资源在审计和 Creator/Web 运行验证通过前只解除引用；历史 PSD、批准记录、旧版本备份保留。旧“船”原型不迁移语义，U01 的可新增操作改用批准清单中的树、灵焰、莲花/倒影原型。
- 不增加生图，不扩展正式功能/QA；由单元示例 Owner 记录运行证据，交 Master 在内置浏览器核验。

## 2. 现有能力复用

- `UnitSampleGallery` 已管理 U00/U01/U04 页面生命周期、U00 六店与游客、相机层和输入、菜单 readiness；仅做本功能必要接线并保护文件中的并发 U05 差异。U05返回Gallery使用窄兼容适配器：优先调用仓库基线公开的 `setExitHandler`，在并发工作树暴露 `onExit` 时回退赋值；同一个返回菜单回调保持原生命周期行为，不修改U05组件本身。
- `pf_street_base_01` 现有稳定 UUID `2d697fb3-01f0-4330-a180-a9c162310bf8` 是 U00 与 U04 的共同消费点。保留它以及五个直接子层名称，五层下按全局顺序连续分桶：L01 indices 0–1、L02 2–3、L03 4–16、L04 17–19、L05 20–42；U00/U04 实体插在 L03 与 L04 之间。
- 复用 `U01SakuraLayoutEditor` 的缩放视图、选中/拖动、编辑/相机模式、输入清理、重置和临时 JSON 导出结构；将旧 v0.2 `MANIFEST`/`PATHS`/UUID 与旧 boat 操作替换为 v0.3 稳定实例 ID、资源表和单一布局 JSON，保持每个页面实例独立编辑，不复制 PNG 或初始布局事实。
- 项目已有 Creator 3.8.8 与本地 Web 构建链；先在隔离副本确认可行，避免与并发 Editor/U05 修改争用工程。

## 3. 结构设计

- Art `CUT_MANIFEST.json` 是资源与坐标的只读事实源。将 18 PNG 字节复制到一个正式资源目录，并保存同一套 `.meta`；导入后填入 Creator 实际 image/Texture2D/SpriteFrame UUID。布局数据由批准 manifest 生成一次，U00/U01/U04 运行时共用，不分别维护坐标副本。
- 保持五个根子层 API；按 Tech 校正的连续区间分配实例容器：L01 0–1（天空），L02 2–3（远景），L03 4–16（树、空中灵焰、水栏、桥），L04 17–19（街栏双半幅与牌楼），L05 20–42（前景与水灵）。U00/U04 实体节点插在 L03 与 L04 之间；该顺序使店铺位于街栏之后、近景之前，栏链在店脚前。天空和远景位移由专用容器控制，不改变实例基准坐标。
- 源画布 3072×1024 左上坐标转换：`centerX=x+displayWidth/2-1536`，`centerY=512-(y+displayHeight/2)`；镜像只翻 X scale，不改变中心。Sprite 使用 Custom 尺寸并关闭 trim 影响。
- U01 JSON 导出升为 v0.3 schema，记录 sourceVersion、稳定原型 ID、PNG SHA、Creator 实际资源身份、实例顺序/坐标/尺寸/镜像/motion；不回写正式 PNG/Prefab。添加原型只从新 manifest 可用集合选择。
- 微动限于已批准范围：天空水平不超过 ±12 source px，远景 ±6 px，同向；4 个获批浮动灵焰约 ±2 px / 3 秒。莲花、倒影和其他灵焰保持静止；动态偏移不得写入导出/重置基线，编辑选择/拖拽期间不运行会妨碍操作的动画。

## 4. 协议与平台影响

无网络/API/服务端数据 Contract 变化。目标验证为 Creator 3.8.8 Web 构建与本地 loopback HTTP；不推断原生/小游戏平台兼容或目标设备性能。保留六店和游客现有业务/数据行为，不把场景示例转为正式发布功能。

## 5. 性能影响

- 18 张纹理共享给 U00/U01/U04；不复制第二套图像、不按实例反复加载、不在页面退出释放仍有共享消费者的 SpriteFrame。
- 从 5 个背景 Sprite 增至最多 43 个背景 Sprite 节点；图集/DrawCall、GPU 驻留和目标机帧率不以估值代替实测。清单源 RGBA8 面积估算约 31.45 MiB，非实际 GPU 驻留值。
- 动效采用少量容器级更新和 4 个必要灵焰的低频/确定性偏移；避免 43 个实例各自 Update、逐帧对象分配或 Tween 泄漏。进入/退出清理输入、resize 与更新；不会在退出时 unload 共享纹理。
- 统计节点数、原型 PNG 字节数、理论 RGBA 展开面积；未实测的 DrawCall/GPU/FPS/移动设备均写 `NOT_TESTED`。
