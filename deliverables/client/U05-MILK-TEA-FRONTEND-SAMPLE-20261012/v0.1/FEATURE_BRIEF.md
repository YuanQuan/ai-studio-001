# U05 奶茶小游戏纯前端示例功能简报 v0.1

## 1. 目标与范围
在 U00-U04 保持现状的前提下，于单元示例菜单新增 U05 入口，提供一轮完整可玩的奶茶制作闭环：选择难度、开始、按维度点击原料、撤销、查看配方、交杯、错杯重做同单、三杯通关、计时失败、重试和返回。五档及每档两阶段直接读取已批准生成器 v0.2 的完整 JSON 全量副本（仅限隔离 Lab），从统一配置读取阶段阈值、奖励、配方、选项与解锁门槛；不从展示名推导 ID，也不另写业务数值。新局锁定阶段和参数。正常新存档仅开放简单档。可选验证设置明确标记为示例工具，用于查看其他档位和条件解锁。

本 Lab 不访问网络、不接服务器、不修改正式存档/生产经济，也不实现其他五店玩法。

## 2. 现有能力复用
- 复用 `UnitSampleGallery` 的 `Graphics` 矩形/圆角绘制、`Label`、按钮回调、现有配色及菜单卡片布局。
- 获批完整配置在 U05 隔离目录等字节复制；唯一业务数据源包含五档阶段、XP、奖励、选项、原料、配方和解锁条件，记录源/副本 SHA-256，不改写上游 JSON。全量副本只用于本地示例，不表示接入服务端。
- 不新增图片、字体、Prefab、第三方依赖或公共客户端框架。

## 3. 结构设计
- 新建 `apps/client/assets/labs/u05/` 独立实现：配置适配器、可测的纯玩法状态模块、Cocos 视图组件和本地示例存档模块；配置副本与目录入口同置。
- `UnitSampleGallery.ts` 只新增 U05 import、组件生命周期/页面引用和菜单卡片最小接线；页面内容与交互留在 U05 模块。
- 页面状态限定在选择档位、制作中、配方弹层、结算；离页销毁组件、定时器和 UI 节点。档位/阶段/目标/配方池在开始时冻结，倒计时按单调经过时间计算，不因查看配方、切后台或动画暂停。
- 存档使用 `u05.milk-tea.lab.v1` 独立 localStorage 键，仅记录示例 XP、已通关档位与永久解锁。仅每局第一次通关发经验；失败与退出不发；坏数据校验后恢复为默认可玩状态并保留恢复提示。验证设置存放独立键或仅作用当前会话，不写入通关结果。

## 4. 协议与平台影响
纯前端隔离 Lab；无 API、协议、后端或生产存档影响。依赖 Cocos Creator 3.8.8、Canvas 输入与浏览器 localStorage。localStorage 不可用时本局仍可玩，进度退化为会话内状态并显示提示。

## 5. 性能影响
每次状态变化重绘少量 2D 节点；Component.update 仅用于监测单调时钟绝对 deadline；剩余秒数变化时只局部更新计时 Label，不逐帧重建界面。选项/订单节点数量有上界，最多 5 维×4 选项；无纹理、粒子、Shader、动画、Tween、Prefab 加载或对象池。离页停止玩法计时、清空操作句柄并销毁页面节点。Resources bundle 中只加载这一份配置；组件活动期间保留引用，销毁时调用 release，异步加载晚于离页则立即 release。

## 6. 日志与调试
保留稳定模块标签 `[U05]`，错误及存档恢复提示使用中文。仅设置独立的示例验证面板，可选择验证档位、验证成长条件和重置 U05 隔离存档；默认进度仍为仅简单档。

## 7. 测试与验证
先对纯状态逻辑核对缺项、撤销、错杯清空且不推进、正确逐杯、三杯结算单次、截止边界、验证解锁、坏存档恢复等关键边界；再用 Creator 3.8.8 CLI 构建当前 Web Mobile 产物，经 loopback HTTP 在 Codex 内置浏览器实点菜单、选择/开始、选择/撤销/配方/交杯、成功/失败/重试/返回与重入。检查正常竖屏及较小视口布局和控制台。项目 Creator Editor 当前由并行任务占用，构建在 `/private/tmp` 的有身份记录隔离副本执行，不覆盖正式构建目录；计划 HTTP 端口 8791，启动前核实未占用。

## 8. 风险与 Tech Lead Review
主要风险是全量候选 JSON 只用于隔离 Lab 本地模拟；localStorage 只模拟成长，不可解释为可信结算。生产实现仍需服务端权威契约。请求 Tech Lead 只读确认配置适配与时间/页面边界、localStorage 隔离、菜单轻量接入和临时副本构建路径。当前 Creator 主文件已有并行 U01 未提交差异；基线副本及 SHA 已保存，接线采用小范围增量，不重排或恢复其他代码。
