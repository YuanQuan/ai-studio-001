# U00 参数基线修订概要 v0.6

## 范围

用户提交的 JSON 更新 U00 六店缩放（均为 0.34）、初始顾客数量（1）及顾客 1 缩放（0.20）。六店脚点沿用 v0.5 输入。默认进入、恢复和离开后重进均采用本次 baseline；临时添加的顾客也使用 0.20。U02 独立示例默认不改。

## 复用与影响

复用 `UnitSampleGallery` 现有 baseline、计数和顾客实例化逻辑及 Prefab/适配器。仅更改 U00 组件常量/恢复流程和同一画面的初始文案；无新资源、依赖、API或正式玩法变化。

## 验证

执行 assets + Creator 声明 TypeScript noEmit，Creator 3.8.8 隔离构建，HTTP 与 Codex 内置浏览器 390×844/720×1280 默认/恢复/重进/导出检查。构建失败后基于日志仅做一次有依据恢复；未生成本版产物则标 BLOCKED，不使用旧 build 作为证据。
