# U04 对话客户端接入概要 v0.3

## 目标与范围
将用户明确批准的 v0.3 极简角饰原图同源切片替换至 U04 现有资源稳定路径；角饰固定 128×96 设计单位，并分别与面板左下、右上角按面板四边 48 单位内缩对齐。保留人物层级、肖像左下锚、姓名与对白左对齐、九宫格四边 48 及其余 127 张人物资源。

## 复用与结构
复用现有 U04 `UnitSampleGallery` 对话页面、Sprite 与 `layoutDialogue`。两张 Sprite 使用 `CUSTOM` 尺寸模式，路径及 `.meta` 保持稳定以延续真实 UUID；不新增节点、依赖或加载逻辑。肖像仍为面板子层，角饰仍绘制于肖像上方。

## 协议、平台与性能
不涉及 API、服务端协议或平台架构。仅替换两张批准图并改两处角饰定位；纹理分辨率仍为 128×96，不增加资源数量、节点、Update、GC 或持续运行成本。

## 验证计划与边界
以 Creator 3.8.8 官方 CLI 构建 `web-mobile`，核对 Finished 日志、当前构建产物及 HTTP 8765 实际目录。Master 将在同一新构建通过 Codex 内置浏览器检查默认版式、角饰对齐与九宫格伸缩。90 组合、目标设备、SDK/GPU/FPS/压力测试须有本版实际证据，否则标为未测试。

## v0.3实现和运行结果

本版Creator 3.8.8 web-mobile构建及Master同版IAB已完成。11张当前构建截图支持两角固定显示、三档面板无角饰拉伸、肖像/文字布局、90/90组合、三轴独立保存和连续快速切换检查；细项及限制见 `RUNTIME_CHECK.json`。目标设备/SDK/GPU驻留、压力性能和横屏菜单适配未测试。
