# 仅 PNG 接入与正式 QA 执行范围

用户最新明确排除 WebP，确认 Web 仅用于开发调试，并允许其余内容继续。当前正式发布目标为微信、抖音小游戏。本周期不新增美术、不重画、不扩全库，不引入画质档位或远程托管。

上轮128文件批准身份由 APPROVED_INPUT_CHECK.json 核验。六件候选仅采用已提交的 png_lossless.png，Master 另以 PNG_PIXEL_CHECK.json 独立核尺寸与完整 RGBA 一致。它们合计从4,274,355字节降到4,008,432字节；不能外推全库收益或显存收益。

Client 按正式六项输入清单接入，保留 UUID、裁剪与原画布映射。三张旧大画布资源由既有生产管线使用裁剪导出，不能把原画布与裁剪图哈希不同当作视觉版本冲突；也不能直接覆盖原大画布而破坏旧加载语义。允许必要的严格候选覆盖入口，正式生产命令和输入清单必须持久化，不只替换临时构建。

QA 先按获批计划 v0.2 执行原冻结实现。Master 用只读 Git archive 准备完整 tracked apps/client、tests、精确104个冻结交付、批准导出与探针依赖，146项身份全吻合，见 QA_FROZEN_COPY.json。新 PNG 产物由 Client 提交准确身份后，QA 独立记录受影响用例的补充回归，不覆盖原基线。Web 运行、受控探针与平台真机分别判定。

本轮原基线 QA 实际复现奶茶结算标题的 BMFont 缺字警告：U+FF01 全角叹号未在既有字体图集中，ASCII 33 已存在。Master 授权仅将“三杯完成！”改为“三杯完成!”，不新增字形图片或业务语义；旧/新源码哈希与唯一文本替换见 FONT_PUNCTUATION_FIX_AUTHORIZATION.json。正式源文件和生产输入均须持久化该修复，新基线补充 QA 重跑三杯结算并核警告消失。旧冻结 QA 证据保留原问题，不回填通过。

IAB 的 viewport 能力为浏览器级，QA 矩阵、Client 冒烟和补充 QA 串行占用尺寸控制；分别保留自己的标签和服务。其他会话的四项客户端差异及共享文档区块保持原样。Tech 独立核生产路径、元数据、CLI真实产物与 QA 证据边界；Producer 记录具体批准、状态、连续执行和实际时间复盘。

停止点为本次具体接入实现与 QA 报告的用户审阅、需要用户决策的重大问题或真实阻塞，不能仅以任务解锁或 IN_PROGRESS 占位结束。缺平台工具、账号、真机与性能采样的项如实保留未测，不因此虚称整体发布达标。
