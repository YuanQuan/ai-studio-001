# 九个单元样例验证记录｜v0.1

验证日期：2026-10-01。目标为 Cocos Creator 3.8.8 的 Web Mobile 构建与桌面浏览器交互；本轮没有目标手机实测。

## 构建与静态检查

- TypeScript：使用 Creator 3.8.8 自带 TypeScript 执行 `tsc -p apps/client/tsconfig.json --noEmit --skipLibCheck`，通过。
- Creator 命令行：以 `UnitSamples.scene` 为 `startScene` 构建 `web-mobile`，进程退出码 36（Creator 成功码），构建日志显示 `build Task(web-mobile) Finished`。构建器对未设置的压缩参数使用默认值，未发现资源或脚本缺失错误。
- 场景引用：21 个已导入 SpriteFrame 均由 Creator 资源库解析，浏览器画面可见瓦片、建筑、角色与道具。

## 尚待正式验收的边界

1. 未在手机上验证双指缩放、触控拖动、连续帧时间、DrawCall 与 60 FPS。U09 的桌面读数不能代替手机性能结论。
2. U04/U05 以程序形体展示四方向状态；现有角色和建筑 PNG 没有四套正式朝向资产。
3. U06 的屋檐前景是程序占位层，尚无精确切分的正式 PNG；U07 是轻量视觉示意，不是物理灯光。
4. 本版使用 7×7 独立小地图验证单元接口，旧整体 Demo 的 17×17 TMX 保留为历史资料。正式地图尺寸和建筑占格需在后续模块中校准。
5. 专业评审、QA 测试报告与用户对 v0.1 的验收尚未完成，因此任务保持 `REVIEW`，不记为 `DONE`。
