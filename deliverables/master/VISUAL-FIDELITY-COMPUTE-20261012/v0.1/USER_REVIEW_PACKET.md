# 效果还原与算力控制方案 v0.1

状态：`USER_REVIEW` 候选；专业审阅见同目录 Art/Tech/Master Review。规则文档落盘不等于规则已批准，本轮不生产图片或动画。

## 建议采用的流程

通过效果图 → 冻结原图与视觉锚点 → 检查当前 PSD 与真正可编辑范围 → 在现有制作方案内填分层/修改/动画路线和预算 → 按 Gate1 及 Art/Tech 同批预签制作代表区域/动作 → 验证后扩批或只重导受影响资源 → 实际切片、同尺度重组及动画回放交 Gate2 → 同版接入后核真实运行。

## 四类产物如何继承效果

| 产物 | 核心要求 |
|---|---|
| 多层输出 | 保留原像素与坐标；关闭整图参考覆盖层，用实际交付层重组核对冻结图，保真区零差异；如实说明平面图的编辑限制。 |
| 细节修改 | 当前 PSD 局部改层；先定变化区域及关联光影/遮挡，其他区域保持原样；旧版保留，只重导受影响项。 |
| 序列帧 | 同一套部件与确认的关键姿态先做一个代表动作，检查基准帧、极值、遮挡、循环，再扩批；不默认逐帧独立生图。 |
| 骨骼动画 | 复用原贴图，基准姿态复现效果；核绑定、缝隙、极值形变和遮挡，保留可编辑绑定/时间线及数据/贴图；按实际运行时复验。 |

图中看不到的背面、遮挡内容与新角度无法从单图无损恢复，只补已批准动作会暴露的部分。动画的其他姿态按批准动作和视觉锚点验收，不能要求每帧与静止图逐像素一样。复杂混合、压缩与缩放的差异先公开说明；源图无损目标失败不静默放宽为相似度通过。

## 如何控制投入

无损拆层、导出和复用预计不调用图像生成。先诊断，再选最小范围的制作方式；代表样片未通过不扩全量。各批次在现有方案中填生成调用、候选、时间及已知费用上限，成本不可见时写未知。同一问题最多两轮自动修正，累计计数；仍失败或达到任一预算上限则停该支线提交诊断。缓存只复用同输入/设置/工具版本的结果，修改后只重算失效资源。

文档不等于已安装像素比较、预算拦截或动画工具；当前是人工执行约束。是否减少耗时/调用需要后续真实制作账本验证，本轮不编造节省比例。
