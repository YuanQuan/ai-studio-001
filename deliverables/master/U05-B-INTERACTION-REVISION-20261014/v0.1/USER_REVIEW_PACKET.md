# U05交互与顾客动画修订方案 v0.1

本版是按你反馈整理的具体交互和美术制作方案，尚未修改试玩代码或生产新图。

| 操作阶段 | 新版效果 |
|---|---|
| 选配料 | 台面从左到右摆茶、奶、小料三个已选物件；同类重选替换，撤销移除最近选择。此时不显示合成杯。 |
| 点击“确认” | 三件配料向杯位移动并消失，杯中分层显现茶、奶、小料；约0.65秒完成合成。只有此时才展示玩家成品。 |
| 顾客订单 | 成品杯图缩为现在的78%，气泡不显示配方。 |
| 顾客进入 | 从窗侧完整移入，约0.45秒到位，再出现订单气泡。 |
| 交对 | 眨眼后开心，移出窗口；下一位移入。最后一杯则离场后结算。 |
| 配错 | 眨眼后失落，留在窗口恢复中性，原订单可重做。 |
| 超时 | 失落后移出窗口，显示失败结算。主动退出以中性表情离开。 |

台面三槽分别为源图 `[345,1150,90,84]`、`[467,1150,90,84]`、`[589,1150,90,84]`。物件不新增点击入口；原十二格仍是选料入口。顾客身体/脸受窗口 `[260,278,490,505]` 裁剪，水平从停靠位置完整移出381源像素，不能只淡出半身。正确后的合成、表情和换客约1.85秒，期间选料/撤销/确认锁定；帮助与退出保持可用，计时持续。确认点击时只判定一次，截止前最后一杯已赢不受表现延迟反判。

制作只改两类资源：一是背景中遗留的顾客轮廓、气泡尖和空杯轮廓，局部净底让空窗/台面干净；二是现有幽灵的局部脸层，保留身体、轮廓、光感，输出中性、闭眼过渡、开心、失落状态并做真实表情回放。屋瓦、店铺、标签底板、原料和字图复用。新角色品种、后端、玩法数值不扩展。

制作活动预算上限75分钟；先用现有图层和像素处理，必要局部生成总上限3次，含重试，同问题最多两轮。未改区域保护原像素；出现还原失败或预算到限则停在诊断。先验证一个开心表情加离场的代表片段，再扩失落和入场。
