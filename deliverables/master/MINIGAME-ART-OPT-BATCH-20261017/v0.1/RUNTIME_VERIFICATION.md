# 客户端实际运行验证与证据边界

本报告对应 Gallery v0.5、Resource v0.8，以及它们冻结的当前源码。当前阶段为实现提交审核，不是 QA 或发布通过。测试使用 Creator 3.8.8 的实际 Web 输出、127.0.0.1 HTTP 和 Codex 内置浏览器，操作均由真实鼠标点击/拖动完成，未注入游戏状态。实际浏览器 DPR 为 1。

## 最终运行与版本继承

- `browser-integration-v07/` 实际测试构建为 `minigame-art-opt-integration-final-v0.7-u01fix`。21 个记录中第 2 个因加载早退后进入了错误页面而排除；其余 20 个均保留加载后截图，六个模块全部覆盖。另有 4 次早退尝试单列 `EARLY_CANCEL_ATTEMPTS.json`，均未算有效加载轮数。`CONTACT_20_VALID.jpg` 已逐张核对。
- `DISPOSAL_RESULTS.json` 按每次退出时间匹配 20 个有效循环：退出后的 moduleLeases、pendingRequests、heldDerivedFrames、moduleInflight、derivedLive 全为 0。完整日志含 22 个释放事件，额外早退事件保留。`CONSOLE.json` 中 warning/error 为 0。此证据不等于完整监听器计数或系统/GPU 内存峰值测量。
- v0.7 的 U01 在 320×568 实测拖动后第一次关闭立即生效；再次拖动后点击“下一层”生效且没有拖动误触。六种竖屏菜单均另存稳定截图；320 小屏向上拖动可达奶茶入口并实际打开。
- `browser-integration-v08/` 直接打开最终便携构建，实测菜单、U01 320×568 加载/面板拖动/第一次关闭/返回，以及 U04 720×1280 加载/返回；控制台 warning/error 为 0。它不是重跑全部 20 次。
- v0.7 与 v0.8 三平台输出的完整相对路径/字节/SHA 清单见 `PORTABLE_BUILD_EQUIVALENCE.json`。每端仅主脚本不同。Tech v0.30 证明差异只有两个脚本注册 UUID 和一致的词法绑定换名，归一后完整脚本严格一致；其余输出逐字节相同。故有界继承 v0.7 的运行结果，保留原测试版本标签，不称 v0.8 全部实测。

## 分辨率与功能证据

`browser-integration-v05/` 保留六页面 × 六种竖屏（320×568、360×640、390×844、414×896、412×915、720×1280）及 U04 两种横屏的 38 张稳定截图。早于最终手势修复，不能作为最终交互全部通过。Tech v0.29 核对 Gallery 260 个、U01 92 个布局/绘制成员及实际编译结构，确认最终差异限于手势、取消和按钮生命周期；因此仅继承这 38 张的布局视觉证据。

已有实际功能证据包括：v0.5 场景最大缩放和两端拖动、游客四动作/装扮/镜像、六家店循环、对话 90/90 状态无失败；v0.6 小屏菜单拖动/滚轮、游客面板与拖动不装备、夜市面板、奶茶正确配方推进至 2/3 并确认退出。v0.6 的 U01 关闭问题保留在失败报告，已由 v0.7/v0.8 实测修复。当前短对话没有溢出，不能声称实际覆盖了长文本正向滚动；滚动方向由源码和实际编译方法测试覆盖。

## 未测与发布限制

DPR 2/3、真实刘海/底部手势/胶囊避让、微信与抖音开发工具/账号上传、真机纹理兼容、GPU 峰值、绘制次数及运行堆峰值、全量监听器计数均为 `NOT_TESTED`。适配层和模拟安全区测试不替代真实设备。

三端 Creator 实际 CLI 均 exit 36 且日志含 Finished；不是仅靠退出码判断成功。最终物理产物：Web 38,670,790 字节；微信 38,707,433 字节；抖音 38,681,779 字节。微信排除声明的八个分包后启动根目录 3,256,025 字节；抖音为 3,230,374 字节。实际上传包/账号限制仍待平台工具核验。抖音产物相对 20 MiB 参考仍多 17,710,259 字节；若按十进制 20 MB 则多 18,681,779 字节。本轮没有通过删内容、降低画质或远程托管消除差额。

图集与 GPU 纹理压缩尚未落地：当前独立纹理关闭 packable，避免未经验证的采样/所有权变化。已形成后续六代表压缩样本制作方案，尚无新样本生产授权或产图。
