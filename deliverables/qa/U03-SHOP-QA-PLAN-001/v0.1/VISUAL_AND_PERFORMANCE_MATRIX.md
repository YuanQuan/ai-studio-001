## C. 固定 Web 性能矩阵

主视口 `390×844 CSS px`，目标 `DPR=2`，实际环境按 `TECH_THRESHOLD_PROPOSAL.md` 锁定；`720×1280` 另作布局/视觉，数值不混判。以下候选阈值在 QA、Tech、Client 同版评审及用户批准前不生效，当前所有行 `NOT_TESTED`。

| 行 / 场景 | 测量与原始证据 | 候选判定 |
|---|---|---|
| `P-01` 六店稳定态 | 每店稳定 10 秒后，60 秒×3；逐帧、FPS、DrawCall 与纹理页。 | 每轮 p95 帧时 ≤33.3 ms、>50 ms ≤1%；可证实 ≥60 Hz 前台时平均 FPS ≥50。 |
| `P-02` 冷/热进入 | 各 3 次输入至完整 01 可操作帧；缓存状态与同一时钟日志。 | 冷每次 ≤5 s，热每次 ≤2 s。 |
| `P-03` 切换/快切 | 已缓存目标单次；20 次受控快切、末次目标及代次/完整提交时间戳。 | 已缓存单次 ≤1 s；最后输入后 ≤2 s 只呈最终目标；任何双店/错配另记功能失败。 |
| `P-04` 图页与纹理 | 实际贴图页宽高/格式、RGBA8 等效面积、最大纹理能力和可得 GPU 数据。 | 六店图页等效总面积 ≤128 MiB、单页不超环境上限；GPU 驻留若不可测单列 `NOT_TESTED`。 |
| `P-05` 入退与引用 | 10 次 U03 入退的页面实例、监听、请求、资源引用、页数趋势；标有意缓存。 | 专属实例/监听/请求退出回基线；第 3–10 次页数/引用不单调增加。 |

缺少真实帧时、计数器或固定环境时对应子项 `NOT_TESTED/BLOCKED`，不能以 Creator 导入成功、静态估算、浏览器可见或单张截图判性能 `PASS`。手机、小游戏平台及实际弱网在本 FUNCTIONAL 计划均 `NOT_TESTED`。
