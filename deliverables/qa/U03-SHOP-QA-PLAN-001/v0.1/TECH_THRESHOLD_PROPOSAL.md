# U03 固定 Web 性能门槛候选 v0.1

这是 QA 为开工包提出的 U03 **专用候选**，待 Tech Lead、Client 评审并与 `TEST_PLAN.md` 同版交用户批准；当前均未实测。`project/quality/PERFORMANCE_BUDGET.md v0.1` 仅涉及另一 Demo，且其手机 60 FPS 目标不能借给本静态六店 Web 页。数值服务于本轮固定环境的可复核判定，不是未来手机、主体游戏或其他浏览器承诺。

## 1. 锁定环境与原始记录

主环境：当前 Creator 3.8.8 Web-mobile 构建、本地 HTTP、Codex 内置浏览器前台可见标签，`390×844 CSS px`，目标 `DPR=2`。记录实际 DPR、Canvas 尺寸、safe area、系统/内核/GPU/驱动、显示刷新率、电源与缩放、构建 hash、Gate2 资源版本、贴图压缩/回退格式和冷/热缓存。DPR 无法设 2 时固定同机同浏览器同实际 DPR 并注明；视口或 DPR 不可信时数值项 `NOT_TESTED`。`720×1280` 用于视觉/布局对照，数值性能只记录不与主阈值混判。

稳定态先等待 10 秒，六店各连续取样 60 秒 × 3 轮；从原始帧时间序列算 p50/p95/p99 与慢帧占比。首次冷进入、缓存热重入各 3 次；20 次受控快切记录每次输入到完整原子呈现的时间、最终 ID；10 次进入/退出测实例/监听与缓存稳定。可直接测得的 DrawCall、纹理页、资源引用与 JS 堆另列；测不到 GPU 驻留时只报告实际页尺寸的 RGBA8 等效面积，GPU 项 `NOT_TESTED`。性能取样关闭非必要录屏与 debug 叠层。Client 若需补只读低开销计时/计数日志，必须在批准实施范围内实现并记录开销。

## 2. 建议判定值与依据

| 指标 | 候选判定值 | 取证与解释 |
|---|---|---|
| 稳定帧时 | 六店每店 3 轮各 60 秒，每轮 `p95 ≤33.3 ms` 且单帧 `>50 ms` 占比 `≤1%`。 | 固定 Web 页允许偶发加载/系统扰动，稳定段仍应不低于约 30 Hz 的 95 百分位；加载切换峰值单列。逐帧原始序列必需。 |
| 稳定 FPS | 前台且可证实屏幕刷新率 `≥60 Hz`、无后台节流时，每轮平均 `FPS ≥50`。 | 与同仓 U02 Web 候选口径可比较，但 U03 独立审批；刷新率/节流无法证明时 FPS 子项 `NOT_TESTED`，帧时仍可单判。 |
| 首次与热进入 | 从菜单激活到首个完整可操作 01 帧，冷缓存每次 `≤5 s`，已缓存重入每次 `≤2 s`，各 3 次。 | 本地 HTTP、正式资源；记录同一单调时钟的输入、资源就绪、完整帧与可操作时间。5/2 秒是开工包体验候选，非当前实测基线；不能核实缓存状态则对应项 `NOT_TESTED`。 |
| 切换响应 | 缓存已就绪的目标，每次输入到目标完整画面提交 `≤1 s`；20 次受控快切最终目标在末次输入后 `≤2 s` 完整呈现。 | 单店静态图的可操作响应候选；目标尚未缓存的首次读取另报，不以旧店仍显示掩盖迟迟不提交。若资源故障，应按功能错误态判，不纳入成功耗时。需请求代次/目标 ID/完整帧时间戳。 |
| 图页面积预警 | 六店正式纹理页的 RGBA8 等效面积 `Σ(pageWidth×pageHeight×4) ≤128 MiB`，单页不超过实测环境最大纹理尺寸。 | 约 8 张 2048² RGBA8 页的**预签规划上限**，含透明区和切片分页，不等于 GPU 实际驻留/解码副本。首张真实 PSD/PNG 与 Gate2 图集若超出，Art/Tech/QA 以实际尺寸/视觉影响提交受控预算修订；不得临测时静默放宽或自行缩字牌。 |
| DrawCall 与入退清理 | 六店分别记录稳定平均/峰值/p95；10 次退出后 U03 页面实例、专属监听和未完成请求均回进入前基线；第 3–10 次循环的已缓存纹理页/资源引用数不单调上升。 | 无实图时不凭“同图集”设绝对 DrawCall 数；以真实计数器和同构建对照识别断批或泄漏。缓存可留存，持续增长不可误写正常。无法取得计数时该子项 `NOT_TESTED`。 |

数值来源：33.3/50 ms 是约 30/20 Hz 的卡顿观察界，FPS 50 是固定 60 Hz 桌面 Web 的候选体验目标；5/2/1/2 秒是单店静态页的待审体验响应预算；128 MiB 是尚无正式图时按 8 页 2048² RGBA8 建的审慎预签估算，必须用真实页重算。它们均需本开工包用户批准后才可据以判定。若 Art 正式图的清晰度与此上限冲突，Tech 提尺寸、格式、加载或分页方案及复测成本，Art 评估牌匾/冷暖效果，Master 协调修订，不能为了通过而降质。必要环境或指标不可测时功能/视觉仍可单独报告，但性能和总体验收不得虚构 `PASS`。
