# U03 页面与控件状态 v0.1

| 状态 | 中央画面 | 身份与反馈 | 控件 | 转移/核对 |
|---|---|---|---|---|
| 菜单未就绪 | 不进入 U03 | U03 卡写“资源未就绪”；不声称六店已制作 | 入口禁用 | 来源、正式字形、Gate2 或导入缺一时维持；不以 SVG 填补。 |
| 首次加载 | 中性纯底，无店轮廓/牌匾 | “01 奶茶店正在加载” | 仅返回可见；前后切换禁用；无“重试” | 完整 `01` 图与牌匾可用后原子进入展示态；明确加载失败或超时后才转错误态并提供针对 `01` 的重试。 |
| 单店正常 | 只呈当前店完整轮廓及其牌匾 | `01/06 奶茶店` 等真实当前项 | 上一店、下一店可用；无边界禁用 | `01` 前一店为 `06`，`06` 后一店为 `01`。 |
| 按下 | 画面不变 | 身份不变 | 被按控件轻微下沉/强调，松开恢复 | 不靠颜色一项表达按下；触发只一次。 |
| 切换中 | 保留一间已呈现店与其牌匾 | 身份仍是可见 `presentedIndex`；另写“正在切换至 `desiredIndex`” | 前后仍可接收目标；返回可用 | 连点从最新 `desiredIndex` 递推：可见 01，连按两次后项为 02→03；若 01 可见、后项到 02 再按前项回 01，则撤销待切换并保持完整 01。仅最新目标三元组齐备才整体替换。 |
| 运行时目标缺图 | 保留一间已呈现店；首次缺图时中性错误底 | “02 糖画摊暂不可用，仍显示 01 奶茶店”；首次则说明 `01` 不可用 | 重试及返回可用；未呈现目标不选中 | 记录 `failedTargetIndex=02`，同时将 `desiredIndex` 复位为 `presentedIndex`；重试只重试失败目标，另按前/后则从已呈现店递推并清除旧错误。 |
| 禁用 | 已呈现店或菜单未就绪状态保持 | 明示“资源未就绪”或具体原因 | 灰化且不响应；返回保持可用 | 不是第七店，也不是业务锁定/解锁。 |
| 返回 | U03 展示退出 | 不保留上次项 | U03 控件销毁/失焦 | 待请求取消；返回实际菜单。 |
| 再进入复位 | 新建 U03，目标 `01` | 成功后 `01/06 奶茶店` | 由首次加载或正常态进入 | 不读取上次 `02–06`，无进度持久化。 |

显示索引、名字与店图共同提交。`presentedIndex` 是当前身份栏和画面真值；`desiredIndex` 只用于加载中连续输入的递推；`failedTargetIndex` 只供故障提示与重试。快切时“切换至”是独立提示，不替换当前栏。缺图状态的重试只请求同一失败目标；重试前页面仍只有已呈现店或中性错误。所有错误文案须同时可通过文字辨认，不能仅靠红色或灰色。

正式运行条件是六店图片、牌匾及字体均获对应审批并接入。状态表覆盖异常处理，不授权在权利或 Gate2 未清时以占位图上线 U03。
