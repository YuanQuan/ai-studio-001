# U03 导航、复用与影响 v0.1

## 实际菜单与后续入口

当前 `apps/client/assets/UnitSampleGallery.ts` 的 `openMenu()` 只创建“进入 U01”；U01 的四层镜头、拖动、缩放、重置按现行代码保留。`U02-TOURIST-SCOPE-001 v0.1` 与 U03 Product 均已获批准，但 **U02 的产品审批不等于运行入口已实现**。因此 U03 菜单实施时先读取当时获批并实际接入的菜单版本：如果 U02 尚未完成实现门禁，实际菜单显示 U01 与 U03；如果 U02 已完成并获相应批准，则显示 U01、U02、U03。不得仅因产品规格已批准就在 UI 实图/运行报告中画成三个均可进入。

从实际菜单点 U03 → 初始 `01` → 前/后循环六店 → 返回实际菜单；再进入重置 `01`。U03 不复用 U01 镜头拖放/缩放输入；返回按钮语义、触控优先级和安全区算法可共用现有单元容器。U03 前后切换控件优先于展示区触控，不让按钮事件穿透为场景输入。正式按钮实现由 Client 审核，UI 不指定框架。

## 组件及资源复用表

| 组件/语义 | 复用来源与范围 | U03 差异及原因 | 当前状态 |
|---|---|---|---|
| 单元菜单卡与返回 | `UNIT-MENU-UI-SPEC-001 v0.2` 的 `LAB_MENU_ITEM`、`LAB_NAV_BAR` 语义；U01 已有返回入口 | U03 卡需写六店外观；显示与否按自身正式资源/实现门禁 | 规格复用；现行代码只有 U01，不宣称 U03 卡已存在 |
| `LAB_ACTION_BUTTON` 状态 | 同版普通、按下、禁用等语义；U03 两个方向键共一套 | 按钮文案“上一店/下一店”，两端也不禁用，因为循环 | SVG 仅结构示意；正式图像待生产审批 |
| `LAB_STATUS_BADGE` / 中性状态字 | 同版候选颜色/反馈语义 | 新增“正在切换至 X”和“仍显示 Y”以防错认 | 文字规格，具体实现待 Client |
| 六店身份栏 | U03 Product 六个身份文字；可借用已有身份卡的排版层级 | 不复用 `MT_IDENTITY_CARD` 杯/孟桃图文，五店不能被误认成奶茶 | 六组文字一份组件，正式字库未锁 |
| 牌匾 | `U03-SHOP-ART-PLAN-001 v0.1` 六种方案 | 每店随同一正式店资产切换，UI 不另画公共同形牌 | 计划；实图、字形、Gate2 未完成 |
| 店铺主图 | 同批六店 PSD/导出及未来主体正式源 | U03 只用单店视窗，不做单元专用替代图 | 计划；实际路径/UUID 待登记 |

本规格不新增运行图标；SVG 中箭头、边框、色块为标注图形。字体方面，旧 UI v0.2 的 `Noto Sans CJK SC` 仅曾列为候选，本版不宣称已取得嵌入或分发授权；U03 所用具体字库由后续 Art/Client 与许可记录核定。六店牌匾字形独立于控件文字。

## 审查接口

- Art：按已批准视觉方向复核六店挂位、UI 不遮挡、色彩与牌匾字形来源。
- Tech Lead：同一源/唯一 ID、切换提交、不同视口的可读尺度与纹理约束。
- Client：与现行 `UnitSampleGallery.ts` 菜单衔接、输入拦截、控件与资源故障反馈。
- QA：按 Product AC-01–AC-05 及本状态表设计实际菜单、循环、快切、重入、缺图与小视口用例。

上述为待 Review 项；本版无 Cocos 代码或运行结果。
