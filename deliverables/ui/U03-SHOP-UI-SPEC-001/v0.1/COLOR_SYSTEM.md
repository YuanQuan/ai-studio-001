# U03 UI 候选色与文字规则 v0.1

视觉基线为 `project/ART_GUIDE.md` 的冷蓝夜色、暖橙营业光、木/纸材质，以及获批 U03 Art Gate1 的六店独立牌匾。本表复用 `UNIT-MENU-UI-SPEC-001 v0.2/COLOR_SYSTEM.md` 候选令牌，**不是新的项目级锁定色规**；须经 Art 对实际画面、真机可读性与字体许可复核。

| UI 令牌 | 候选 HEX | 用法 |
|---|---|---|
| `night.deep` | `#0D2343` | 展示区外的低对比承托；不盖店体 |
| `night.surface` | `#18375D` | 标题、状态条暗底 |
| `paper.base` | `#F7E5C2` | 控件浅底；与 `ink.main` 配对 |
| `paper.muted` | `#D9C8A6` | 禁用，同时写原因 |
| `lantern.warm` | `#F6AD55` | 当前状态或可用控件少量强调 |
| `lantern.pressed` | `#D9873F` | 按下配下沉轮廓反馈 |
| `river.info` | `#94C3D7` | 切换中中性提示 |
| `cinnabar.alert` | `#A54D4B` | 运行缺图提示，必须配文字 |
| `ink.main` | `#342B2C` | 浅底正文 |
| `text.onDark` | `#F8EDDA` | 夜蓝底正文 |

六店店体、牌匾、环境光由 Art 正式源控制，UI 不对其重染。六块牌匾不同色重心与挂位按 `SIX_SIGNBOARD_PLAN.md`，不由这套 UI 令牌统一成同一外观。正常、按下、禁用、切换中、错误均有文字或形态反馈；不能只靠颜色辨认。390 宽设备与真实背景叠加后的字形、对比和安全区仍未实测。

字体登记：本版未锁具体系统/美术字体文件。旧候选 `Noto Sans CJK SC` 的项目来源见旧 UI v0.2，但无本版文件哈希、许可文本与实际运行/嵌入/分发/改造核验结论；状态 `UNKNOWN`。SVG 的 `sans-serif` 仅让审阅者读标注，禁止导出成正式按钮/牌匾字形。正式字形若改用原创手绘，仍需来源和近似风险记录。
