# 页面文字布局示意 v0.1

这是可实施规格，不是效果图、切片或运行截图。所有尺寸、阈值引用UI_SPEC逻辑像素契约；每页均先排除safe/capsule再布局。R自上至下分区，各区不重叠。上下文状态栏正文16/24、辅助14/20。长屏将剩余空间给世界/主体，不拉大字号、按钮或原画比例；短屏按下述规则滚动控件，不裁订单或缩字。以下内容最小高度超出R时，进入整体纵向内容滚动，固定导航/必要返回；遮罩和弹窗不参与底层滚动。

## 入口（进入U00—U05之前）

顶部56标题；其余为一列滚动卡片，卡片宽R.width、高至少144（标题28、正文两行48、间距与进入按钮48、按实际测量增高），卡间12。六卡按既有顺序，进入按钮填满卡内宽。说明超过两行时卡增高。加载中显示模块名，不缩卡压进一屏；失败在原卡显示原因及48高重试。返回菜单后保留入口滚动位置，按钮仅一次提交；禁用卡按实际资源状态，不因异步空集合永久禁用。长屏也保持单列，非等比卡片缩放禁止。

## U00 夜市总览

顶部导航56：左返回≥80宽，标题剩余宽，调节入口≥80宽；若标题不足80则标题移第二行导航80。底部相机栏48+上下16，−/重置/+等宽3列；次行人数−/数值/+、以及世界/游客/店铺开关分别48高，3行总184。世界层占其余区域，沿既有3072×1024组合与相机逻辑，不改场景结构；短屏不强放三行常驻：相机栏保留，人数与开关收入“调节面板”的首两组，调节入口原语义包含这些现有功能，触达路径变化需Review。

调节面板以R内弹窗呈现，头56标题和关闭，底48恢复/复制两列，正文滚动：分组开关；人数；店铺/顾客；对象上一/下一；X−/值/X+；Y−/值/Y+；缩放−/值/+；步长1/10/50；反馈全文。所有行高至少48、间8，列间8，正文值区至少64不足则独占一行。遮罩拦截拖镜头，面板打开保持世界状态。复制成功/失败用同一反馈区，未知平台剪贴板失败不假成功。短屏正文滚动可达最后一项；关闭恢复镜头操作。重入沿既有临时恢复规则，不保存调参为正式配置。资源失败阻止未就绪世界拖动但可返回/重试。

## U01 樱花场景布局

导航56（返回/标题/编辑层或镜头模式）；底部48“图层与调节”入口+16内距，状态正文至少24可换行。中间世界视窗沿原画坐标3072×1024，不改变导出参数单位。完整调节面板为R内滚动弹窗，沿现有功能逐组：选择上一/下一/锁定；缩放−/+；镜像/删除；重置/导出；X−/+、Y−/+；新增树A/树B、灵焰等当前可用原型；图层列表。每组自动换行，按钮最小48；删除/导出不新增业务含义。

编辑模式只在世界区域命中被选图层并拖动；锁定态不重选，镜头模式只拖镜头。面板打开取消当前拖动，不把面板拖动传给物件。长屏扩大世界，不额外缩放文本；短屏面板滚动，错误与导出参数完整可复制，不依赖浏览器DOM作为小游戏唯一出口，平台不可用时显示失败和返回。重排保留临时参数，离开按既有恢复初值，重新进入新generation；资源缺失列出可滚动ID、重试与返回，不让空场景可编辑。

## U02 游客动作与装扮

导航56返回/标题/重置。底部区域为独立滚动托盘：状态和装扮说明16/24；动作按钮两列、单格≥48；配饰槽逐项独占行或足宽两列；向左/向右两列，均间8。托盘目标高度为R.height的45%，最小168、最大336，但必须给世界预览至少120和导航间距；不足则托盘缩到120并滚动，世界剩余高度不设会挤出R的固定最小值。预览游客等比，脚底/配饰挂点不因重排改变；允许舞台更小，不缩HUD。

点击动作、配饰、朝向更新选中态；托盘滚动取消按钮点击，世界预览不接收托盘手势。失败停用对应选择，状态列出缺资源，不错误挂载；返回与重试可用。旋转保留动作时相、朝向、装扮；重置沿原有语义。离开再入用既有默认，不新增跨页持久化。

## U03 六店店铺

导航56返回/标题。底栏两列上一店/下一店48+16内距；其上身份与状态分别至少24，可换行，间8。其余展示区按body/sign原1024²逻辑画布等比contain，脚底锚点保持。短屏身份与长错误改成可滚动信息区最大96高，不用现有舞台最小200顶占按钮；长屏只扩大可用展示区域。

切店loading显示目标店名，上一完成画面保持但加“正在加载”说明，未成功不把身份和图像混搭。失败显示失败目标、重试和返回；上一/下一仍可选新目标且generation取消旧请求。重试使用独立48高行，状态区增高或滚动，不和失败文字同点覆盖。重排保留目标与当前呈现店；快速切换只接受最新generation。离开取消在途回填，再入按既有店初值。

## U04 店长对话

竖屏：导航56，人物区域居中；底部对白区内容按姓名18/26、正文16/24、状态14/20测量，初始至少120高、最大R.height的30%，超过则正文独立滚动。人物以已有腰裁范围、脸/前层挂点作为一个不可拆的组合等比contain到剩余人物区，不对表情单独缩放。背景保留既有街景与遮罩，不要求整幅宽景塞入竖屏，不改变已批准人物裁切语义。

控制区在对白上方，管理者六项按三列两行48、魂级三项三列48、表情按三列多行48；控件多于区域时放入固定48入口“人物与表情”的滚动弹窗。竖屏默认使用该弹窗，姓名/对白与人物常驻；面板缩小/放大、巡检90组保持现有功能，置于同弹窗末组，不强塞视口右边。面板大小按钮只改变请求面板尺寸，实际布局仍clamp到可用宽高，不允许遮挡返回、正文或控制入口。

横屏仅在实际width>height：保留现有1280×720基线下底部九宫格对白面板、人物叠前与角花组合及其相对视觉关系，不建立左右分栏。仅将底部组合整体约束到安全区（必要时等比contain），对白按逻辑字号测量并在既有面板内换行/滚动；面板内容装不下时提供同语义可展开阅读覆盖层，不挤压或改造九宫格美术。人物腰裁及脸/前层挂点继承既有组合，不单独拉伸。返回/标题在安全区，管理者、魂级、表情、巡检及面板尺寸按钮若扩展48热区后会相交或侵入对白/人物关键区域，则折叠到“人物与表情”覆盖弹窗，默认关闭。保持主体组合，不能以控件整理重做横屏构图。R高度短于280按受限布局保留滚动访问，不缩字号。

选择店长/魂/表情保留最新目标状态、旧组合不与新名字混合；三层齐才更新，失败列出目标与重试，不显示缺脸的就绪态。巡检状态不可当正式QA结论。旋转保留选择和对白滚动（clamp），取消触控和过期布局任务；离开取消巡检及回填，重新进入以既有默认，新generation。

## U05 奶茶

画幅固定原1024×1536完整contain，禁止裁顶裁底、非等比压扁、重画或移动杯子/人物挂点。先在R中按`s=min(R.width/1024,R.height/1536)`完整居中等比适配，保持原操作位置、图像和文字相对关系；不预留新常驻托盘或双HUD空间，不因适配方案持续缩小主体。安全HUD独立父级，只放返回与必要“操作/配方”入口，优先使用contain形成的空白；无足够空白时用既有页panel样式的小型安全覆盖入口，不再扣减主体布局区。覆盖入口不可遮住原来仍有效的操作目标；冲突目标必须统一迁入面板并停用原热区，不能留下两个相互竞争的入口。

每个有效revision在实际显示尺度测量全部动态文字与热区：关键按钮文字≥16、辅助/图像内信息≥14，热区宽高≥48且彼此间隔≥8、不与safe/capsule、HUD入口或弹窗相交。全部达标的原控件保持原位继续交互；缺陷目标先在原位分配独立48单元并核重叠，不能满足才把该目标及其同一操作组统一转到可开合“操作/配方”覆盖面板。操作组分别为难度/开始、茶选项、奶选项、小料选项、撤销/提交、配方/说明；不强制全机型永久替换全部操作。文字缩小到阈值以下的订单/状态在同面板提供可读全文，倒计时/杯序若不达标则在安全覆盖入口旁提供24/32主数值，不预占持续画幅空间。面板入口自身按16/24与≥48热区执行，明示当前需要代理的组；没有不达标目标时不新增操作入口，沿既有配方入口。

面板默认关闭，R内头56关闭/标题、底48必要动作、正文滚动，间8；分类/选项自动换行，每格最小48、文字16/24，宽不足减列或单列，内容超过可用高滚动。仅迁入目标的原画幅交互停用；面板打开时遮罩阻断所有底层操作，关闭后符合规格的原目标恢复，已迁入目标仍只通过面板操作。画幅原图不抹除、不重画，面板状态直接同步同一run.selected与既有配置ID、解锁条件，不复制业务状态；旋转后的目标集合变化原子提交并取消手势，保证同一动作始终只有一个有效目标。

覆盖面板打开不暂停倒计时，沿当前规则不停表；运行结果改变立即刷新面板的禁用/结算态，关闭保持主体画面及当前run/presentation。开始前难度/熟练度/阶段、验证设置同样以测量是否达标决定留原位置或进入面板，不增加解锁/时间/存档规则。奶茶主体保完整原画与操作视觉，面板仅为确实不达标的可读性/热区补救，后续需同尺度同背景对照证明最小修改。

配方、退出确认、验证设置、结算均以R内遮罩弹窗呈现，头56、底操作48、正文滚动；取消/确认两列，不挂在主体顶部margin，不遮挡外部系统胶囊。弹窗不新增暂停语义，沿现有倒计时处理；状态切为失败/结算时以run结果为准，不继续提交。动画锁输入时撤销/选料/提交disabled，返回及现有配方行为按既有规则；加载字体/配置/图片失败显示原因，未就绪开始disabled、可重试/返回。字体失败保留诊断，不以未知许可系统字体通过正式生产验收。旋转/resize只重排保留run及presentation时相，离开确认沿现有不计熟练度规则，重入不回填旧run。
