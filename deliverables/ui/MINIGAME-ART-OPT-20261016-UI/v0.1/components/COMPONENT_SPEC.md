# 公共组件与状态 v0.1

本文为文字组件规格，不是组件效果图。沿现有Graphics、Label、Sprite与九宫格资源，不新增框架、图片或状态切片；组件逻辑语义统一，U05保留暖木视觉，其余保留夜市实验页视觉，禁止借复用换色。

| 组件 | 共用页面 | 结构与状态 |
|---|---|---|
| SafeNav | 入口、U00—U05 | 返回/标题/动作；56或80高；安全区胶囊排除后布局，不能覆盖系统区域 |
| ActionButton | 全页 | 最小48×48；normal沿当前panel/描边，pressed沿当前高亮，disabled文字/边沿当前muted且不响应，loading显示文字“加载中”并锁重复提交；selected加现有描边与文字“已选”，不只靠颜色 |
| ScrollPanel | 入口卡列表、所有调参/信息 | 固定字号、内容测量增高；纵向裁剪只作用内容，滚动边界clamp；目标移动>8取消点击；末尾间8 |
| StatusBlock | 全页 | loading/ready/error/empty；业务没有空内容时用未就绪说明，不自造“无订单”规则；错误全文16/24+48重试，不能同位置叠字与按钮 |
| OverlayDialog | U00/U01/U04调参及U05弹窗 | 窗口级遮罩拦截；R内宽满、高不超R；头56、底48、间8，正文滚动；关闭时恢复原滚动/焦点，禁止关闭瞬间点击穿透 |
| SelectorGroup | U02/U04/U05 | 列数按规格；实际格宽不足48则减列；未开放显示原因与disabled；selected态不增外框导致位移 |
| ArtViewport | U00—U05 | 同一组合变换，图片挂点/遮挡继承；符合规格的原控件/文字保留原位；不达标组才用默认关闭的安全覆盖面板；不使用世界缩放推导字号和热区 |
| SafeText | 全页 | 标题20/28、分区18/26、正文按钮16/24、辅助14/20、主数值24/32；不SHRINK，测量后换行/增高/滚动 |

所有状态复用相同组件实例规则而非按每页重画。触控目标相邻间8，布局后在窗口逻辑像素域核宽高和相交；可见图小于目标时分配独立单元，原图点击区域停用，防止重复动作。首帧到字体加载完毕均重新测量，但保持滚动和选择；字体变化不能导致内容盖住按钮。

## 字体来源、实际用法与许可边界

| 字体 | 来源证据 | 本轮使用与限制 |
|---|---|---|
| U05_ART_FONT BitmapFont | apps/client/assets/resources/u05_milk_tea/u05_b/U05_ART_FONT.fnt、同名png；同目录U05_ART_FONT_OFL.txt首行ZCOOL KuaiLe版权与SIL OFL1.1全文；milk_tea_lab.ts:193–199、318–323实际加载和绑定 | 复用现有位图字形、嵌入运行资源；许可证随分发保留。OFL文档存在是可核事实，未重新审计每字形源文件链；不新增字体改造、重命名或重制字库。不宣称全局中文覆盖 |
| 当前Label默认系统字体 | UnitSampleGallery.ts:276–285；sakura_layout_editor.ts:89；milk_tea_lab.ts:198失败保留系统字体 | 当前实际调用系统字体，未给出稳定字体名、字体文件来源和嵌入/分发/修改许可。状态UNKNOWN；不能假定“系统字体”授权生产，不打包未知文件，不改造未知字体 |

U05先用既有BitmapFont，文本绑定须核missing字形，包含本规格新增的HUD文字。对缺字不得显示空白或擅自生成新字图：记录缺字与来源问题给Master，保留开发诊断；正式实现前由Art/Tech确认可用授权字体/覆盖方案并经过适用审批。非U05也不得直接扩展当前有限BitmapFont为全局字体或改变其艺术风格；延续原字体调用只用于问题定位与方案，正式生产字体许可未完成核验。14/16等逻辑字号是几何要求，不代表当前BitmapFont采样清晰度已通过。

## 下游影响与验证归属

Art核同语义HUD文字代理、完整奶茶画幅及原人物/配色继承；Tech核逻辑像素→UI映射、input capture、资源代次与字体绑定；Client在用户批准后实现；单元示例Owner保留运行和视觉证据。本文没有运行PASS、字体授权终审或正式QA结论，仍需同版Art/Tech Review与用户审批。

U05覆盖面板仅在实际尺度测量字号/48热区不达标时承接对应操作组，不设置常驻232像素托盘或双HUD预留；保持完整R中的1024×1536主体与原位置。面板共享run状态、不停表，迁入组原热区停用，打开遮罩阻断底层，关闭保留画面。U04横屏组件维持既有底部九宫格、叠前人物与角花组合。全部六竖屏及仅U04两横屏矩阵以screens/LAYOUT_SPEC.md为准。
