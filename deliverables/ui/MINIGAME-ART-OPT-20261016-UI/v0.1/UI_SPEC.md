## 唯一测量契约

对齐本批 Tech v0.1/TECH_DESIGN.md 的联合评审Draft：`ViewportAdapter.read()/subscribe()` 输出 revision、width、height、dpr、safe、capsule、orientation。窗口左上原点，单位均为平台逻辑像素（Web为CSS像素）；DPR不参与布局、字号或48阈值。`ViewportMapper` 以实际Canvas内容矩形和visibleSize转换UI坐标，含letterbox偏移；不得用window宽度猜画布。当前Tech约定唯一代码承载为`apps/client/assets/framework/viewport/`与`framework/module-assets/`，页面以工程内相对导入使用，禁止直接引用packages外部源码。所有下述尺寸均为逻辑像素，落到Cocos由同一mapper换算，禁止直接写成设计单位。

竖屏所有入口、U00—U05采用720×1280设计宽基线，保留世界/画幅层等比策略；安全HUD独立布局。仅U04实际窗口 `width>height` 时使用既有1280×720横屏基线，其他情况为竖屏（方形按竖屏）；不通过点击U04强行切换方向或设计宽1280。旋转只重排，不重新初始化业务。

先将safe与窗口、Canvas内容矩形求交得到S；若capsule非空，向四周扩8形成C。为得到唯一可执行矩形，若C与S相交且C中心处于S上半部，将S顶边降至C底边；否则将S底边升至C顶边。再内缩左右12、上下8得到内容矩形R。胶囊为null时不虚构胶囊，保留诊断；safe缺失按Tech回退窗口并记待真机核验。零尺寸保留最近有效revision，不除零。

固定公共导航高56，底部操作栏按行数×48+行间8+上下16计；页面内容与两栏间各8。标题可换两行时导航高80。R宽不足240或高度不足280时启用受限窗口布局：固定返回48，主体/普通控件进入纵向滚动；提示扩大窗口并保留全部内容的滚动访问，不能让按钮越界。正常验收覆盖最小320×568窗口（左右内缩后R宽296）；在合法安全区/胶囊下须完整可操作，通过换行、滚动及代理布局满足，不能因内缩而提前判受限。仅极端safe将R缩至上述阈值以下才用受限模式。

## 字号、溢出与热区

唯一字号表：页面标题20/行高28，分区标题18/26，正文与按钮16/24，辅助说明与资产ID14/20，计时/主数值24/32。不得通过父节点整体缩放、SHRINK、压缩字距降低实际值；Cocos字号应由mapper换算，使实际逻辑像素符合表。已有纹理内文字保持图片，若实际小于14或关键按钮文字小于16，仅对实际测量不达标组在可开合安全覆盖面板提供同语义文本/控件代理，默认关闭、原贴图保留完整视觉，该组原图热区停用；符合字号/热区要求的原控件保留原位置，禁止全机型强制重排。

正文按字形边界换行；拉丁长ID允许字符断行，不裁切业务值。标题最多两行，更多通过正文详情展开；按钮最多两行，48高装不下时升64，同行统一高。说明完整显示于可滚动区，不用省略号隐藏错误或订单内容。所有滚动区域保留可见滚动提示，滚动末尾最后内容与底栏间8间距。不可用缩小文字或压扁卡片解决短屏。

每个主要触控目标实际可点击宽、高均≥48；最小按钮48×48，普通按钮按文本测量+左右16，行间/相邻目标间8。若图片小于48，先在代理布局分配48单元；空间不够则换行、滚动或打开列表，禁止向邻居扩张重叠。任何扩展后的相交热区都视为布局失败，不按层级抢点击消解。禁用控件仍占布局格，不响应动作。

输入按弹窗→安全HUD→当前滚动容器→世界层命中一次，消费后不穿透。按下记录目标与revision，移动超过8逻辑像素取消点击；滚动区先锁纵向滚动，世界区锁拖镜头；已占用指针直到抬起不转发。释放必须仍在原目标且generation/revision未变才点击，mouse/touch同一路去重。旋转、弹窗打开、离页取消全部在途手势。弹窗覆盖整窗口阻断世界操作，关闭按钮及确认/取消均在R内；不以半透明露出推定可点击。

## 生命周期与状态

公共状态：未进入→加载→就绪；失败保留明确原因、重试和返回；重试生成新generation且禁止重复提交。加载控件只禁用依赖资源的动作，返回始终有效；不把未加载空数组记成永久失败。资源齐备且generation有效才原子显示可交互页面。重入创建新generation，迟到回调不得回填旧页面；退出取消订阅/手势/请求Owner租约，由Tech租约统一释放。不把UI方案当释放实现已完成。

重排只更新布局，不重置当前选择、滚动位置（clamp到新范围）、U00镜头、U01编辑参数、U02动作/装扮、U03店ID、U04人物/魂/表情、U05当前局/订单/剩余时间。离页再入按当前产品既有初始化/持久化行为；U00/U01临时调节不改写正式配置，U05退出确认沿现有语义，布局不得增加暂停收益。后台/前台按既有业务计时规则，只复测viewport和恢复有效显示。
