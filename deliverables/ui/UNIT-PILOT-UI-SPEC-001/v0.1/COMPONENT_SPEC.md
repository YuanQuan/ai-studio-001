# 孟桃单元 UI 组件规格 v0.1

## 公共身份卡 `MT_IDENTITY_CARD`

| 子节点 | 内容 | 资源/行为 |
|---|---|---|
| `frame` | 木框浅纸轮廓 | 未来一份九宫格或矢量源；所有入口共用版本 |
| `cupMark` | 小杯＋吸管 | 将由 Art 的唯一原创标识母版缩放适配；不是纸盒图形 |
| `shopName` | 奶茶店 | 一份本地化 key；不渲染图片字 |
| `managerLabel` | 店长 | 一份本地化 key |
| `managerName` | 孟桃 | 一份本地化 key；「孟」腰牌属于角色本体，不复制进卡饰 |

卡是只读信息，没有 normal/pressed/selected/loading 的按钮语义。完整卡不随 Lab 工作换皮；`components/identity-card-states.svg` 第一行展示稳定卡，第二行是外接 Lab 标签。未来玩家选择店铺若使整卡可点，必须作为新交互规格，不把本卡直接做成按钮。

## Lab 状态标签 `MT_DEMO_STATUS`

独立挂在卡右侧或 Lab 面板上缘，显示「演示 · 资源检查中」「演示 · 待机」「演示 · 准备中」「演示 · 工作中」「演示 · 返回待机」「演示 · 复位中」或错误。读屏/辅助文本读完整状态；颜色、文案和轮廓一起表达，不以闪烁为必要条件。标签不进入主体 UI。

## Lab 控制 `MT_LAB_CONTROL_PANEL`

两个操作：`startDemo`「启动工作表现」与 `resetDemo`「重置」。启动在 `IDLE` 且资源就绪时启用；`STARTING/WORKING/RETURNING/RESETTING` 全程不可重复触发。重置在 `IDLE` 可触发以校验初始态，在其它状态保持可用性由 Tech 评审；本版 UI 候选为保留重置以处理异常/残留，但收到操作后必须等待状态适配器的结果，不自行清场。`ERROR` 时主操作呈「重试启动」或「资源未就绪」的具体原因，不能一概假装可启动。按钮状态图含 normal、pressed、disabled；过渡中的「准备中/复位中」是文字反馈，不额外画旋转加载动画。

点击目标候选 44×44 逻辑单位以上；视觉状态与命中区分离。按下 100–180 ms 内给下压/亮度反馈，随指离开回 normal；不在按钮内部显示骨骼动作进度百分比。键盘/手柄/无障碍焦点如目标平台支持，按 Client 实际输入层实现同一语义。

## 版本与复用合约

公共卡组件定义、文案键、边框和杯标只有一份资产 ID；单元和主体引用同一已批准版本。两入口之间允许位置和缩放不同，但不另绘边框、不换「奶茶店」「孟桃」写法。Lab 专用标签/按钮/诊断保持独立包路径；若未来主体需要状态提示，先由 Product 批准真实经营语义，再出组件版本变更。组件文件内的 SVG 仅为视觉规格源，不是 Cocos 的最终 Sprite、Atlas 或 Prefab。
