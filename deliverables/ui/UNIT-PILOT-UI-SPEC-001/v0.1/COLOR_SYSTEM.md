# 孟桃单元 UI 色彩系统 v0.1

依据 `project/ART_GUIDE.md` 的冷夜蓝环境、暖灯橙焦点、瓦灰/木棕/石灰材料、暗红/柳绿少量点缀。以下色码从当前效果图整理为**UI 候选 token**，不是全项目已批准的生产色表；Art Review 与手机样张可能调整。所有示意图共用这些 token，禁止同义状态任意换色。

| Token | 候选 HEX | 用途 | 限制 |
|---|---|---|---|
| `night.deep` | `#102044` | 场景夜色和面板暗底 | 不做正文底色 |
| `night.mid` | `#24427A` | 远景、Lab 面板分隔 | 与前景身份卡保持层级 |
| `wood.edge` | `#583622` | 卡边框与木饰 | 少量，不能压过奶茶店本体 |
| `wood.fill` | `#91603B` | 卡框中间、按钮边缘 | 禁止大块复刻店铺木纹 |
| `paper.base` | `#F3DFC0` | 卡内容底 | 承载文本 |
| `paper.light` | `#FFF0D4` | 卡高光、按钮可点态 | 不使用纯白刺眼底 |
| `ink.main` | `#35261F` | 深色主文案 | 浅纸底使用 |
| `ink.muted` | `#6F5B50` | 次文案 | 小字号先做对比检验 |
| `lantern.main` | `#EF9A4C` | Lab 主按钮、演示工作标签 | 不等同奖励/完成 |
| `lantern.light` | `#FFD19A` | 暖光描边 | 不烘进组件图片背景 |
| `jade.muted` | `#799274` | 孟桃围裙呼应、小装饰 | 不用绿色代表「成功奖励」 |
| `alert.lab` | `#8F3F36` | Lab 错误/资源未就绪 | 仅诊断，带文本说明 |
| `inactive` | `#9C948C` | 暂不可点击按钮 | 同时写明原因，不仅靠颜色 |

### 状态配色

公共身份卡常态始终用 `paper.base`、`wood.edge` 和 `ink.main`，不随 Lab 工作动作换皮。Lab 的「演示 · 待机」用夜蓝底与浅纸字；「演示 · 工作中」用暖灯橙底与深墨字；「演示 · 返回待机」用木棕浅纸组合；「复位中」用夜蓝底与浅纸字；错误用 `alert.lab` 并配文字。按钮 normal 用暖橙、pressed 降低亮度并产生 2 逻辑单位视觉下压、disabled 使用 `inactive` 加 `ink.main` 深墨字。发光只作为轻微背景描边，不能成为唯一状态差异。

小字号正文、状态标签与按钮在最终引擎/设备渲染时按文本对比度至少 4.5:1、较大主标题至少 3:1 作设计验收目标。当前候选色码按 sRGB 计算：`ink.main`/`paper.base` 约 11.1:1，`ink.muted`/`paper.base` 约 4.9:1，浅纸字/`alert.lab` 约 6.4:1，`ink.main`/`inactive` 约 4.9:1；正式字体及真实背景上仍需复测。夜市场景本身丰富，身份卡采用不透明纸底，避免透明叠色使可读性漂移。视觉统一由 Art Agent 签认。
