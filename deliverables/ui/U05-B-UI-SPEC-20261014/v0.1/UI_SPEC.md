## 页面与布局

选择页沿当前 U05 入口 `apps/client/assets/UnitSampleGallery.ts::openU05()`，五档并列可选，初始仅简单可开始；锁定档可查看门槛说明，不进入局。显示本局档、阶段、三杯目标及起始时间说明。验证设置仅在选择页独立弹层，沿当前示例隔离存档与验证开关语义，不影响正常进度。开始制作后进入 B 工作台：左茶架三固定格，右奶架三固定格，中下小料两行三列六固定格，店外一位幽灵与一个成品杯气泡，近侧透明工作杯，底部查看配方／撤销／确认交杯。顶栏杯数和时钟复用 B 图牌位，动态字覆盖原图占位字，不能双字。退出入口作为窄小的独立操作置于不会遮挡柜格、杯和主按钮的空白区；具体像素由 Art 实层测量后确认。

画布坐标左上为 (0,0)，右下 (1024,1536)。B 图粗区：茶 `x45–224,y413–1028`，奶 `x831–1007,y415–1025`，小料 `x254–773,y847–1080`，工作杯 `x419–603,y1094–1325`；为热区测量起点，非切线。实际十二对象、柜框、杯沿、遮挡层由 Art 母版登记。原料只点击可见独立对象所属格，不能让相邻格热区重叠。名称牌与对象同格状态；触控目标在包含对象的格内尽量扩大，邻格冲突时以格边界裁剪。未开放格保留位置和器皿轮廓，显示锁态、不可选且不得让旧背景烘焙内容露出。三类固定容量 3/3/6，各阶段开放名单严格读已批 Product `CONTENT_PLAN.md`，不由 UI 增减。

## 帮助与订单

气泡只显示当前目标的**完整成品杯**，没有原料名称、图标、公式或气泡内帮助文字。目标杯由同一套茶色、奶纹、小料内容层在气泡杯位缩放组合；工作杯按所选项目逐步显茶液、奶纹、小料，空类不伪造已加入内容。目标与工作杯复用 Art 内容语义层及遮罩，前后杯壁、杯沿仍各自正确遮挡。54 种组合是显示验证范围，不是 54 张整杯图。

完整配方帮助为气泡外独立小面板。简单档入局默认展开，显示当前订单三项名称和类别；中等及以上默认收起，可随时不限次查看。帮助文字跟当前订单更新；帮助不是模态层，不截获面板矩形以外的点击。摆放采用下列确定规则（坐标均从各自矩形左上起，单位为当前 host 逻辑像素）：

1. 先按完整 B 图 contain 得到画面矩形 `R=(left,top,1024s,1536s)`。若 `top-safeTop≥96`，使用**顶部留边模式**：帮助展开板 `x=12,y=safeTop+12,w=W-136,h=76`，退出热区 `x=W-112,y=safeTop+24,w=100,h=52`。板内第一行 `y+8` 为「当前配方」18px，第二行 `y+38` 为「茶 幽灯茶　奶 云魄乳　小料 鬼火珠」20px（内容随当前目标换）；如果文字超出板宽，则第二行分三项等宽列，单列只显示其类别与名称，不缩小到 18px 以下。720×1280、无安全区时 B 图为 `x0,y100,w720,h1080`，板为 `[12,12,584,76]`，退出为 `[608,24,100,52]`，均在画面上方 100px 留边内，离画面至少 12px；帮助收起时只保留底部 B 图「查看配方」按钮，退出仍在此位。留边控件按 host 坐标命中，不经过 B 图逆变换。
2. 若顶部留边不足 96，使用**B 图内回退模式**：左侧夜街可用源图范围 `[238,307,456,473]`。展开帮助板固定 `[240,307,214,166]`，上部 58 源像素留给退出，下部三行从 `y365/401/437` 开始，各高 36 源像素，内容分别为「茶 幽灯茶」「奶 云魄乳」「小料 鬼火珠」；正文使用同源合法字体 **34 源像素**、左内边距 8，不得启用 `SHRINK` 降到 18。最长五字按 34×5+16=186 源像素计算，小于板宽 214；实际字形宽度再以字体测量复核，超宽时优先减字间距至 0，仍超宽则在该行内折为两段且保留不小于 32 源像素。退出可见文字框 `[384,309,68,56]`，只在板上部，帮助正文从 y365 开始。板距左柜 `x≤224` 至少 16 源像素、距气泡 `x≥469` 至少 15 源像素；底 y473 早于幽灵主体 `y≈490`。该区域不压十二格、工作杯或三个底部按钮。帮助收起则三行及面板底消失，退出保留。回退控件随 B 图 `R` 的同一 `left/top/s` 绘制和逆变换命中，不另用 host 屏幕坐标。

退出控件在两种模式均为同一语义，带明确「退出」文字。回退模式的可见框是 `[384,309,68,56]`，点击热区按当前实际 CSS 缩放 `s` 计算 `hitW=max(68,48/s), hitH=max(56,48/s)`，右边固定 x452、下边固定 y365，向左/上扩展；这样手机至少 48×48 CSS 像素，扩展只落在非原料的左夜街/布帘背景，底边不进入从 y365 开始的帮助正文，右边不进入 x469 的气泡，也不碰 x≤224 的茶柜。例如 360×540 的 2:3 窗口 `s=0.3515625`，文字 34s≈11.95 CSS px（32s≈11.25 CSS px），退出热区约 `[315.5,228.5,136.5,136.5]` 源图像素，实际 48×48 CSS px；720×1080 时文字约 23.9 CSS px。对小于约 230px 宽的极端窗口，若左界将越过 x238，就维持不抢占柜格/帮助的边界并报告不满足 48 CSS px 的适配问题，不能裁切 B 图。顶部留边模式退出热区 100×52 host 逻辑像素；帮助收起/展开动作始终由 B 图底部「查看配方」按钮负责，退出扩展热区不能截获该按钮或任何十二格。计时在查看和退出确认期间均继续。

## 操作与反馈

每单茶、奶、小料各选一项，顺序自由。选中格显示 Art 同源亮框，工作杯同步合成；同类点另一开放格即重选，替换对应杯内层。撤销移除最近一次仍有效的选择，并同步恢复该类格与杯内显示；无选择时禁用。缺任一类，交杯禁用并提供「请选齐茶、奶、小料」非阻断提示。三项齐备方可交杯；交对杯数加一、切下一目标、清空本杯选择；第三杯交对转成功结算。交错提示「配方不对，请重做当前这杯」，当前订单保留，选择清空，杯数不加，倒计时继续。反馈位置与动态文字不得盖住关键点击区。按下/松开、选中、锁定和禁用状态见 `components/COMPONENT_STATES.md`。

成功显示三杯完成、原规则熟练度结算、再玩一局／返回菜单；失败显示原因、重试本档／返回菜单。重试从首单重新起局；返回离开本局。制作中点击退出先出确认层，明确「继续制作」「退出本局」；确认期间倒计时继续，若先到截止转失败，不能再退出结算。退出丢弃半局且无经验；退出后回选择页，再进入从第一杯开始。到时、交杯并发和一次结算边界完全遵从 Product/Tech 已批方案，UI 不自行添加数值。配置加载中/失败与本地存储失败复用现有示例的文字错误态和返回操作。

## 画幅与热区

整个 B 画面按同一比例 `s=min(W/1024,H/1536)` contain，显示宽高为 `1024s×1536s`，居中，余边用接近 B 图夜色的界面底色承接；不裁切屋檐、十二格、工作杯或底部按钮，不拉伸。若安全区使可用矩形缩小，先在安全区内算同一 contain。屏幕点到设计点统一用 `x=(screenX-left)/s,y=(screenY-top)/s`；渲染层、文字层与全部热区均使用同一 left/top/s。当前入口 host 为 720×1280；完整画面比例缩放 `s=0.703125`，显示 720×1080，上下各留 100px（无安全区时）；不能用旧 720×1280 画法另缩热区。更窄竖屏仍完整 contain，优先保证格与三个主按钮可点、动态字可读；达不到触控尺寸应报告实测问题并评审，不放大到裁切。

字体：动态标签优先同源 ZCOOL Kuai Le，官方 TTF、SIL OFL 1.1 身份与许可见 `deliverables/master/U05-B-PLAYABLE-20261013/approval-20261014/FONT_SOURCE_CHECK.md`；71 字内存字形探针见同目录 `FONT_GLYPH_PROBE.md`。UI 只引用，不生成字体图片。实际字体嵌入/分发与可读性仍由 Art/Tech 本批核准。

Client 影响：现有 `milk_tea_lab.ts` 的三维文本列表和中央配方阻断层须改为 B 稳定层状态；只读事实不构成编码授权。Art 影响：动态字、状态框、空槽及双杯内容层须在同画布交接。单元示例由 Owner 留运行和视觉证据；升级正式功能后重新走 QA 门禁。
