# U05 B 页面状态索引 v0.1

本文是文字页面图示，视觉入口为已选 B 图 `deliverables/art/U05-MILK-TEA-WORKSPACE-CONCEPT-20261013/v0.3/concept_B.png`。仅该图现存；以下状态均由本批 Art 实际层实现后显示，不引用尚不存在的 PNG。状态图共享 1024×1536 完整画幅与 `UI_SPEC.md` 的 contain/热区变换。

| 页面/状态 | 画面要点 | 入口与去向 |
|---|---|---|
| 配置加载中/失败 | 延续 U05 示例文字及返回；失败可重试加载 | 打开 U05／重试或返回菜单 |
| 五档选择 | 简单、中等、困难、地狱、噩梦；初始简单开放；选中档、阶段、三杯目标和时间说明；永久已解锁可选 | 进入制作；返回菜单 |
| 锁档说明 | 锁图与已批门槛逐项文字，未满足者不可开始 | 点锁档看说明，返回选择 |
| 验证设置 | 单独轻弹层：模式、阶段、隔离存档重置、既有等级/魂/魄测试输入；说明不改正常进度 | 选择页打开/关闭；不在局中悬浮 |
| 制作初始 | B 场景十二固定格；仅阶段开放格可选；气泡纯目标杯；工作杯空；简单完整配方帮助默认展开，中等起收起 | 选择、查看帮助、退出 |
| 制作已选/重选 | 一格/多格亮框；工作杯依次见茶色、奶纹、小料；同类重选仅替换该类 | 撤销、继续选择、交杯 |
| 撤销/缺项 | 撤销最近有效选择后层和亮框同步；缺项时交杯禁用并提示 | 继续选择 |
| 交错 | 原目标留在气泡；工作杯与三类选择清空；杯数不变，计时不断 | 重做当前杯 |
| 下一单 | 交对后杯数更新、目标杯更新、选择清空；帮助随新配方更新，原展开策略保持 | 继续制作 |
| 帮助展开 | 当前目标三项名称在气泡外；720×1280 顶部 100px 留边使用 `[12,12,584,76]` 帮助板，2:3 无留边使用 B 源图 `[240,307,214,166]`，上部退出、下部三行 34 源像素正文；十二格、工作杯和主按钮全可操作；计时继续 | 底部查看配方按钮随时收起 |
| 退出确认 | 「继续制作」「退出本局」；确认层不暂停计时；到时优先失败 | 继续或退出 |
| 成功 | 第三杯正确后结算原经验，显示再玩一局/返回菜单；一次结算 | 重开或返回 |
| 失败 | 到时原因、重试本档/返回菜单；无经验 | 重开或返回 |
| 主动退出 | 本局不结算，回选择/菜单；重进从首杯开始 | 新局 |

现有入口是 720×1280 host，B 图 2:3 必须整幅 contain；无安全区时 720×1080，顶部底部各 100px 留边。顶部留边退出热区 `[608,24,100,52]`；无足够留边则显示 B 源图 `[384,309,68,56]`，按 `max(68,48/s)×max(56,48/s)` 向左上扩命中区、右下锚在 `(452,365)`。360×540 时 34 源像素帮助字约 11.95 CSS px，退出热区 48×48 CSS px。更窄屏和安全区同公式，主画面不得盖出视窗。B 图内各点击区与图像同变换；留边控件用 host 坐标。验证清单：顶瓦、左右十二格、幽灵、目标杯、工作杯、底部三按钮同时可见且可点。运行截图尚未产生，所有页面视觉结果 `NOT_TESTED`。
