# 百鬼夜市 Demo｜UI 色彩与形状

版本：v0.1｜遵循 `ART-DEMO-001 v0.1` 的冷夜暖灯方向。

| 用途 | 颜色 | 使用规则 |
|---|---|---|
| 卡片底 | `#172336`，约 93% 不透明 | 深靛，衬托场景，不叠加复杂纹理 |
| 卡片描边 | `#7D8D98` | 1 px 低亮边，仅用于确认卡 |
| 主按钮 | `#D9894C` | 暖橙，仅用于确认修复；同屏一个主按钮 |
| 主按钮按下 | `#B66F3E` | 按下反馈 |
| 禁用按钮 | `#6E6865` | 同时降低文字亮度，保留可辨识文字 |
| 主文字 | `#F7ECDD` | 米白标题与按钮文字 |
| 次文字 | `#C9C5C2` | 说明、结果补充，不用于小于 14 px 的正文 |
| 提示圈 | `#E8B276` | 暖色细虚线、低强度呼吸；只标唯一目标 |
| 完成提示 | `#B6D8C7` | 低饱和青绿，配文字表达状态，不仅靠颜色 |

圆角：卡片 16 px，主按钮 12 px，提示条 10 px。阴影柔和、短距离；不得使用大面积光晕或闪屏。图中的场景几何示意只表达位置关系，正式地图、摊位和角色由 Art 资产决定。
