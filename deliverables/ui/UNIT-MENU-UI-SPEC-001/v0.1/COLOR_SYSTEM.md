# 七项菜单单元样例｜UI 配色候选 v0.1

任务：`UNIT-MENU-UI-SPEC-001`。视觉基线为获选未加宽、非像素第一街与 `project/ART_GUIDE.md`：冷夜蓝环境、暖灯橙焦点、瓦灰/木棕/浅纸材料，暗红/柳绿少量点缀。本表 HEX 为**UI 样张候选**，不是项目级已锁色值；经 Art 视觉 Review、目标设备截图和用户批准后才可进入正式资源。

| 令牌 | 候选色 | 用法 | 限制 |
|---|---|---|---|
| `night.deep` | `#0D2343` | 页面远景、暗色承托 | 不压成纯黑恐怖风 |
| `night.surface` | `#18375D` | Lab 顶栏、浮层底、场景遮罩 | 保留街景层次，不铺满全部画面 |
| `wood.frame` | `#6D432F` | 菜单卡、对话框木边 | 只做简化材料提示，不仿已有作品纹样 |
| `paper.base` | `#F7E5C2` | 卡面、对话正文底 | 长正文需与 `ink.main` 保持清楚对比 |
| `paper.muted` | `#D9C8A6` | 禁用卡面、辅助区 | 不能仅靠颜色表示禁用 |
| `lantern.warm` | `#F6AD55` | 选中/主按钮、演示光点 | 经营焦点少量使用，不把每个控件都点亮 |
| `lantern.pressed` | `#D9873F` | 按压状态 | 同时改变位移/边框，便于非色觉依赖 |
| `willow.accent` | `#729A76` | 可用状态和少量分组 | 不用于错误提示 |
| `river.info` | `#94C3D7` | 中性说明、镜头手势提示 | 保持与夜蓝背景可读 |
| `cinnabar.alert` | `#A54D4B` | 资源错误/无效反馈 | 配文案和图标，不只用红色 |
| `ink.main` | `#342B2C` | 浅纸上的主中文文本 | 不用透明浅灰表现正文 |
| `text.onDark` | `#F8EDDA` | 夜蓝底上的文字 | 最小字高与设备复查 |

**层级原则**：街景保留冷蓝；可操作纸卡和对话框比背景亮，木框分隔；最重要当前选择仅一处暖橙强调。孟桃/店铺角色原画色由 Art 控制，UI 令牌不重绘其服装或建筑。灯光与阴影效果由 Art/VFX 正式规格决定，UI 样张的圆形暖晕只表示“在此观察光影”，不充当生产特效。

**状态映射**：normal 用纸底木框；pressed 用暖橙加深与轻微下沉；selected 用暖橙描边和勾/点；disabled 用灰纸与文字“不可用”；loading 用常驻“准备中”字样及节制动效；error 用暗红提示和“重试/查看原因”。`busy` 与 `loading` 不使用同一文案：busy 表示演示动作进行中，loading 表示资源或状态等待。按钮不能因选中和禁用只有色差而难区分。

**字体/版权门禁**：颜色表不授予字体或图片许可。系统字体候选 Noto Sans CJK SC 的准确文件与 OFL 声明在生产前锁定；美术字暂无获批候选。所有图片参考必须记录来源、许可及外观相似风险，不能直接裁切或描摹获选场景参考和旧 Demo。
