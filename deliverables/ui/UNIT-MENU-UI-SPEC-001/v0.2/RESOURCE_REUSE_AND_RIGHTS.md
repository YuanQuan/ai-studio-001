## 1. 唯一母版和引用范围

| 源 ID | 正式资源意图 | 本单元引用 | 未来主体接入 | 当前状态 |
|---|---|---|---|---|

相同组件不得在独立单元和组合场景分别导出两套外形或交互逻辑；未来主体实际接入时再核对第三入口的相同 ID／版本，当前只定义契约，不声称已实测。牌匾、孟桃腰牌“孟”由 Art 场景／人物正式源负责；UI 只复用已获批的身份信息，不从概念图或场景截图裁字。顾客的唯一序列帧显示节点左右翻转，世界 UI 与文案正向，顾客帧不得烘入板凳。

## 2. 图片与图标出图前核验

每个正式 UI 底板、状态图、杯吸管标识、头像、装饰纹样与参考来源须登记：原创母版路径、参考 URL／作者、参考用途、版权和外观相似风险、授权文件及可用于商业游戏／修改／分发的范围。禁止完全照搬、描摹、换色或轻微改动受保护表达；旧 Demo 图、审阅 SVG、生成概念字与授权不明素材不可成为正式资源。Art 与 Tech 每次出图前共同核对设计尺寸、九宫格与透明边、图集面积、可能合批、实际纹理内存和目标设备裁切；单一母版／同图集／一次 Draw Call 是不同结论，分别取证。Art 审核视觉和权利，Client 核 Creator 中的实际引用与表现。

## 3. 字体登记表与放行条件

| 类别／候选 | 已知来源 | 当前实际用途 | 待锁定的证据 | 当前结论 |
|---|---|---|---|---|
| 系统／正文候选：Noto Sans CJK SC | 官方项目 `https://github.com/notofonts/noto-cjk`；v0.1 记录候选许可为 OFL 1.1 | v0.1 SVG 仅写字体族名，并有本机回退；未打包具体字库文件 | 实际字体文件名和版本、官方下载与哈希、版权／许可文本；核对游戏运行调用、客户端嵌入、安装包分发、必要子集化和修改许可；Art／Client 签认 | 候选；不得把 SVG 回退效果视为正式字体或已完成许可检查 |
| 美术字体／牌匾字 | 尚无锁定字体文件与许可 | 概念图或 SVG 中生成文字仅供审阅 | 若使用已有字库，记录原文件、来源、原许可、商用、嵌入／分发和改造条款及修改记录；若原创绘字，记录原创过程与相似性检查 | 未批准；不能作为正式资源 |
| 角色腰牌“孟”／杯图标旁字 | 由 Art 正式角色／场景源定义 | UI 只显示身份信息，不提取字形 | 对实际绘字或字体文件按上述对应路径核权 | 正式字形待 Art 生产与审核 |

“系统字体”并不自动意味着可商用、嵌入或分发；“美术字修改过”也不自动消除原字体许可。版权状态未知时使用中性占位说明并标记阻塞，不能以已批准 UI 规格代替资源许可。字体候选最终选择如改变，须保持同一中文可读性、回退策略和页面组件来源记录。

## 4. 接入取证清单

正式资源生产后逐项登记：源文件、导出文件、Creator 资源 ID／Prefab、版本／哈希、许可文件、Art＋Tech 出图前记录、Art 视觉 Review、Client 独立／组合两入口相同引用的运行证据、720×1280 候选画布与目标设备安全区／中文可读性截图。主体游戏尚未接入的条目标注 `NOT_TESTED`，接入后补第三入口复验；审阅 SVG 和示意配色只能作为需求参照，不能填入已完成证据栏。
