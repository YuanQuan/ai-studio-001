# 七项菜单单元样例｜组件与状态规格 v0.2

以下 ID 是**设计追踪 ID**，供 Art／Tech／Client 在正式资产清单与 Creator Prefab 上建立一对一映射；不单方面指定代码 API。相同 ID 只维护一份母版与状态定义，不能为独立／组合入口分别画一套。

| ID | 复用范围 | 状态与反馈 | 资源边界 |
|---|---|---|---|
| `LAB_MENU_ITEM` | 七个顶层入口，③内两个子项复用卡母版 | normal／pressed／disabled／selected，卡片滚动与点击互斥 | Lab 专用，不生成第八顶层卡 |
| `LAB_NAV_BAR` | 七项独立页与组合页 | 返回、编号／标题、重置；操作中按实际状态禁用或说明 | Lab 专用 |
| `LAB_ACTION_BUTTON` | 预览、开始、继续、复位等 Lab 操作 | normal／pressed／disabled／busy／loading／error | 一份纸木按钮母版，文案替换；图标不能独自传意 |
| `LAB_TOGGLE` | 店、孟桃、幽灵、板凳、树、花、灯各开关 | off／on／disabled／loading／error，文字和图形双通道 | 各对象开关不各自出一套按钮图 |
| `LAB_SEGMENT` | 3A／3B、顾客左／右与五态 | normal／selected／disabled，显示已生效值 | 方向标签与顾客帧显示节点分离，不镜像 |
| `LAB_STATUS_BADGE` | 七项演示状态提示 | idle／busy／resetting／error；明确“演示” | 不混入正式身份卡 |
| `MT_IDENTITY_CARD` | 店铺、孟桃、UI 展示、组合及未来主体接入 | normal；缺任一对象时仅显示真实在场身份或隐藏完整双对象卡 | 唯一边框／底板／杯吸管图标与文案键；主体与单元同源 |
| `MT_DIALOGUE_SHELL` | 第 6 项及组合浮层；未来主体仅复用获批容器 | closed／firstLine／secondLine／closing／error | 示例标记、文案与 Lab 触发单独保存，不进入主体剧情 |

## 状态行为与复用细节

- `busy` 是对象演示仍在播放，`loading` 是资源或复位等待；UI 等真实完成事件，不把点击当成动作完成。重复点击不排队叠动效。
- 顾客状态切换后显示最后**已生效**的左／右和五态。坐姿无板凳时禁用或安全退出，标签不能仍显示“坐下”。若角色资源缺失，预览禁用并解释原因，不显示空帧或旧占位图。
- 对话的继续／关闭可复用按钮母版，但对话容器是公共组件，演示文字是 Lab 数据。关闭／返回清掉演示进度；不生成正式剧情分支。
- 身份卡与杯吸管图标只维护一份正式原始资源。牌匾字和腰牌“孟”由 Art 角色／场景资产提供，UI 不从概念图裁字、不为 UI 重画一套。若未来获批其他人物或店铺，使用相同容器语义，通过显式产品和资源版本扩展。
- 顾客只翻转**序列帧显示节点**。独立的文本、状态标签、身份卡、气泡、按钮、方向标签和世界 UI 均保持正向；顾客帧图不包含板凳。翻转后资源与坐点需 Art／Tech／QA 两向实看。

## 制作与证据门槛

本版组件规格通过用户审批后，正式运行 UI 还须取得：可编辑母版、正式切图／九宫格／图标和许可记录，Art＋Tech 逐次出图前签认，Client 对应稳定 ID／Prefab 引用，独立与组合入口的同源检查及目标设备截图。v0.1 `components/shared-controls.svg` 是状态审阅示意，不能当作正式 Sprite、九宫格或已授权字体来源。
