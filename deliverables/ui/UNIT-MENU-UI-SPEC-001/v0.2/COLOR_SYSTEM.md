# 七项菜单单元样例｜UI 配色 v0.2

视觉基线为已获用户采纳的未加宽、非像素、可爱中式地府夜市与 `project/ART_GUIDE.md`。下表沿用获批 v0.1 的**候选令牌**；色值是设计沟通与设备对照基准，未经过正式图片、真机校色和 Art 本版视觉 Review，不是已锁项目色规。

| 令牌 | 候选 HEX | 用途及限制 |
|---|---|---|
| `night.deep` | `#0D2343` | 夜蓝承托；不能变纯黑恐怖风 |
| `night.surface` | `#18375D` | 顶栏／浮层暗底；不遮盖主要街景 |
| `wood.frame` | `#6D432F` | 简化木框提示；不临摹参考作品纹样 |
| `paper.base` | `#F7E5C2` | 卡面与正文底，与墨色正文保持可读 |
| `paper.muted` | `#D9C8A6` | 禁用辅助底，同时显示“不可用”文字 |
| `lantern.warm` | `#F6AD55` | 少量主操作／选中强调，不通屏铺橙 |
| `lantern.pressed` | `#D9873F` | 按压，加深同时伴随边框／位置反馈 |
| `willow.accent` | `#729A76` | 少量可用／分组标识，不做错误色 |
| `river.info` | `#94C3D7` | 中性提示，须在夜蓝底可读 |
| `cinnabar.alert` | `#A54D4B` | 错误，必须配文字／图标 |
| `ink.main` | `#342B2C` | 浅纸上的正文 |
| `text.onDark` | `#F8EDDA` | 夜蓝上的文字 |

`normal` 用浅纸木框；`pressed` 用加深暖色与轻微下沉；`selected` 有暖橙细框、勾点及文字；`disabled` 用灰纸与“不可用”；`busy` 写“演示中”；`loading` 写“准备中／复位中”；`error` 用暗红配原因与重试。不得只用色差表达状态。对话正文在浅纸上优先深墨色，避免暖灯反光降低对比。角色衣装、店身、世界灯光与特效颜色仍由 Art／VFX 负责，UI 令牌不重绘美术主体。

所有色值须在 720×1280 候选画布及目标设备截图上核对，尤其夜景背景上的中文、选择态、禁用态和对话浮层。调色不代替字体文件与图像许可审查；正式资源的色彩／材质、透明边与图集合批仍走 Art＋Tech 出图前签认。
