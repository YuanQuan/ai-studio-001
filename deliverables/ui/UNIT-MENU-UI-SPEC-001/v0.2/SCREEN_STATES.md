# 七项菜单单元样例｜页面状态 v0.2

状态语义以获批 Product v0.2 `FLOW.md` 与 `ACCEPTANCE.md` 为准；本文件只规定可观察 UI 反馈，不改变对象内部动画和镜头逻辑。

## 1. 导航和通用状态

| 起点／触发 | 画面和控件反馈 | 返回／重进／异常 |
|---|---|---|
| 顶层七卡 → 某项 | 卡片按压一次，进入相应 Lab 单元并显示编号／标题 | 快速双击只进入一次；未就绪项禁用并说明 |
| ③角色项 → 子项 | 只显示 `3A 孟桃`、`3B 幽灵顾客` | 返回仍为七卡首页 |
| 任意单元 → 重置 | 状态徽标“复位中”，完成事件后回该项初始状态 | 失败显示原因与重试，不能伪装完成 |
| 任意单元 → 返回再进 | 清除 Lab 浮层、演示操作和旧选择 | 第 7 项回空底板／初始镜头／所有对象关；第 1 项仍为空背景 |
| 对象资源缺失 | 仅禁受影响操作，并显示“资源未就绪” | 不切到旧图、空白贴图或复制对象 |

`pressed` 仅在按压期间；`selected` 有选中图形与文字；`disabled` 有“不可用”；`busy` 有“演示中”；`loading` 有“准备中／复位中”；`error` 有原因和可行退出／重试。所有状态须在目标设备上可辨，不能只靠颜色。

## 2. 单元特别状态

| 入口 | 正常选择 | 异常／依赖变化 |
|---|---|---|
| 1 空场景 | 手势提示可关闭；复位镜头 | 手势在边界停止，不假装仍平移 |
| 2 店铺 | 奶茶店可选；预览中按钮 `busy` | 无正式店铺资源禁预览；不显示未来店铺可用 |
| 3A 孟桃 | 待机／工作演示／重置可见 | 连点不叠播；资源未就绪报错 |
| 3B 幽灵 | 左／右×移动、跑动、高兴、沮丧、坐姿可分别选 | 顾客**序列帧显示节点**翻转；方向段选与所有文字 UI 不镜像；无板凳坐姿禁用或安全退出 |
| 4 元素 | 树、花草、灯笼开关各自可见 | 某项关闭后对应特效一并消失，其他项状态不变 |
| 5 UI | 展示共享组件及 normal 等状态 | 不添加经营数据或伪正式字体 |
| 6 对话 | 打开、第一句、第二句、关闭 | 返回／重置清演示进度，不留下浮层 |
| 7 组合 | 各对象开关独立；重置回空底板 | 板凳关时坐姿安全退出；店／孟桃缺席时身份卡不误称双对象在场 |

## 3. 对话和输入焦点

| 状态 | 内容与操作 | 输入焦点 |
|---|---|---|
| `closed` | 无对话；可点 Lab 打开 | 场景按对应单元规则接收输入 |
| `firstLine` | 孟桃名／头像槽／第一句／“演示文案 · 非正式剧情”／继续／关闭 | 对话消费拖拽、缩放和底层按钮 |
| `secondLine` | 玩家侧标识／第二句／同一演示标记／结束或关闭 | 同上，不出现分支与奖励 |
| `closing` | 过渡中防二次关闭 | 结束后才恢复场景输入 |
| `error` | 说明资源错误，有关闭入口 | 不显示空姓名或空正文 |

UI 命中顺序：活动对话浮层 > 可交互菜单／顶栏／托盘 > 场景空白区。跨边界多指动作不可同时选择控件并缩放镜头。Client 须在 Creator 目标设备验证安全区、中文长度、可触目标、焦点恢复和对话浮层遮挡。
