stateDiagram-v2

  对杯 --> 入客: 非末杯、旧客离场
  对杯 --> 胜利: 第三杯、旧客离场
  选料 --> 超时: 截止
  入客 --> 超时: 截止
  合成 --> 超时: 非末杯截止
  错杯 --> 超时: 截止

  退出确认 --> 主动退出: 确认退出
