# 七项菜单单元｜店铺与场景特效规格 v0.1

任务：`UNIT-MENU-VFX-SPEC-001`。状态：专业评审候选，待 Art 视觉 Review、Master 评审与用户审批。产品语义仅采用已 `USER_APPROVED` 的 `UNIT-MENU-PRODUCT-001 v0.1` 与孟桃试点产品 v0.1；遵循当前 `project/ART_GUIDE.md`。`UNIT-PILOT-VFX-SPEC-001 v0.1`、本轮 Tech/Art/UI v0.1 均属待审版本，只作差异对齐，不能当成已批准生产输入。本任务只提交规格，未制作正式特效图、骨骼、Prefab 或设备性能证据。

## 1. 视觉与语义边界

冷夜蓝环境中用低亮暖橙表达店铺和灯笼的温度，木砖瓦、浅纸牌匾、简洁阴影保持非像素可爱中式插画。特效不覆盖奶茶店木框牌匾、杯吸管小标、孟桃腰牌“孟”、脸、手和幽灵表情；不出现法阵、惊吓、金币、订单完成或超自然奖励解释。灯光属于**可单独退出的表现层**，不得被烘进不可关闭的店身底图；样张中现有半透明暖晕不能直接裁成正式 Sprite。

必要表现：奶茶店一处动效及**同镜头下暖灯照亮区域与邻近暗部/投影的对应变化**，而非只亮一个点；树木、花草、灯笼各有可辨认动态或伴随效果；幽灵左/右五状态靠骨骼姿态和表情可辨。热气仅作为奶茶机周围的轻量环境提示，不声称正在制作具体商品，也不作为工作完成条件。可选孟桃摇杯动作线沿用旧 VFX 待审稿的候选思路，但其资源未获批准，不能自动集成。若出图/性能评审不允许可选层，保留必要骨骼动作、店铺亮暗投影和对象可辨动态。

`SHOP_LIGHT_PAIR` 的“亮”与“影”是一个**逻辑效果**，同一个生命周期控制：不能只关亮部却留下地影，也不能只调整 UI 图标。店铺热气可与光影同场，但热气不阻塞任何骨骼动画的完成与复位。店铺工作表现结束以孟桃骨骼动作结束为准；VFX 不发业务完成事件。顾客高兴/沮丧的动作表现由 Art/Client 的骨骼状态提供，VFX 本版不为情绪预留新图集和新魔法语义。

## 3. 层级、遮挡和左右翻转

采用相对层而非抢先锁定渲染序号：天空/河与桥后层 → 地面及店铺后层 → 贴墙亮部与店灯范围 → 树花灯后片、板凳后片 → 孟桃/幽灵按脚点排序 → 店前柜、栏杆与板凳前片 → 局部蒸汽或短动作线（按真实遮挡可被前片盖住）→ Lab/共用 UI。灯笼光斑和店铺地影锚在世界位置与对应表面，不随幽灵视觉根翻转；相机水平拖拽/缩放后仍与物件对位。桥和栏杆不应把所有特效统一压在顶层，穿过时需 Art 前后分片/遮挡区复核。

幽灵仅做一个原创方向骨骼源，另一向水平翻转复用；如情绪动作有局部骨骼挂点，其角色随身局部效果跟着 `VisualRoot` 镜像，而世界光、地影、板凳座点、文字与 UI 保持非镜像。左右都检查挂件、手势、光照、脚点及坐姿，不以调用翻转属性当作通过。优先改源设计、同源挂点或分离不镜像节点；若必须新增反向专属绘件，先走显式变更与用户审批，VFX 不自行补画。

## 4. 菜单与组合场景生命周期

第 1 项空场景只显示固定背景，不实例化上述可切换店、人、树花灯或它们的光/烟。第 2/3/4 项分别只装载对应源；第 5/6 项不因为 UI/对话操作触发场景经营效果。第 7 项从第 1 项同一底板起步，按开关逐项实例化**与单元相同的资源和参数源**，各实例可独立开关；不能制作组合专用合成灯光贴图或复制一份时序脚本。

对象隐藏、移除、重置、返回菜单、Scene 卸载或异步加载失败时，只清理所属实例的骨骼轨道、透明度/材质状态、计时器、事件订阅、挂点和光斑/蒸汽；不清掉其他仍在场对象。顾客从坐姿安全退出及板凳移除时没有遗留情绪/坐姿光效。重复显示从一致初态开始，不复活上次烟缕；慢设备延迟回调不能在退出后重新生成效果。详细资源归属见 `ASSET_REQUIREMENTS.md`，测量与降级见 `PERFORMANCE_AND_CLEANUP.md`。

## 5. 可验证结果与审批

Art 需先核对本版灯/烟/影的冷暖比例、非像素轮廓、可爱地府语气及对象层级；用户批准后 Art+Tech 才可按每次正式出图签认资源。Client 在 Creator 3.8.8/Web/微信/抖音目标环境核对触发与同源引用，QA 在同镜头取“灯低—灯亮—灯回基态”的亮部和邻近暗部/投影关键帧，并对树/花/灯开关、顾客左右情绪、组合全开/逐项移除/重置取证。帧时、Draw Call、显存与手机小屏可读性尚无实测，本规格不宣称达标。
