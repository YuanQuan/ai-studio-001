# 七项菜单单元｜性能、降级与清理约束 v0.1

任务：`UNIT-MENU-VFX-SPEC-001`。当前没有可据以锁定帧时/显存阈值的真机数据；下面是**实例数上限与验证方法候选**，正式预算由 Tech/Client 结合目标 Web、微信小游戏、抖音小游戏设备批准。本规格不声称已达到任何 FPS、Draw Call 或内存目标。

## 1. 同屏数量与测量矩阵

| 入口/组合状态 | 本版候选同时数量上限 | 须记录的证据 |
|---|---|---|
| 2 店铺 | 一组店灯亮暗投影、一组机口热气；动态件按该店一源实例 | 关/开灯同机位前中后帧，热气 alpha 覆盖、动画与材质批次 |
| 3A 孟桃 | 一名角色骨骼；可选摇杯短弧最多一组，且只在审批后启用 | 动作开始/结束/重复/复位时实例数与挂点 |
| 3B 顾客 | 一名幽灵骨骼，无额外情绪粒子；左右同一源 | 左/右×五状态与坐姿，地面影及受光方向 |
| 4 场景元素 | 一棵树、一簇花草、一盏灯笼各一个骨骼源实例；灯笼一组光 | 单开、全开、逐项关闭的骨骼/透明层/Draw Call 对照 |
| 7 组合峰值 | 上述已批准Product范围内的对象候选可同时存在（新视觉资产尚未获批），每对象只一组所属效果；一店灯与一灯笼光允许并发，不乘出第二份资源 | 空底板→逐项增加→全开→逐项移除→重置；帧时、Draw Call、GPU/纹理内存、设备温升/卡顿及残留实例 |

本版只提出**样例密度候选**；完整第一街店铺和环境装饰密度另行评估。每骨骼对象单页降低纹理切换风险，却不保证一个 Draw Call；不同 Spine 数据、混合模式、UI、遮挡前片、半透明层可能断批。将店铺亮部/阴影、蒸汽和灯笼光全部采用全屏后处理或动态实时光照，不是本版默认方案；需要新 Shader/大粒子系统时先评审跨角色性能与资产契约。

实测至少包括：Creator 3.8.8 导入与构建成功；获批代表机和低端机的 Web/微信/抖音入口2、3、4、7；相同镜头位置/缩放下的开关前后截图与短录屏；多次切换、连续预览及对象来回增删；Sprite/bone 数、骨骼 atlas 页数、实际纹理尺寸与压缩回退、Draw Call、CPU/GPU 帧时和常驻显存。镜头竖屏 720×1280 与横向参考的裁切、牌匾/腰牌/幽灵情绪与灯影可读性需同步记录。测试阈值、机型和允许劣化由 Tech/QA正式计划定稿，不从本文件的候选数值推出通过。

## 2. 分级降级

| 等级 | 可调整项 | 不能削掉的验收点 |
|---|---|---|
| 基础 | 低透明、局部灯照/投影、慢速一至两缕热气、单树/花/灯摆动；幽灵无附加粒子 | 店灯亮部与邻近暗部/影的联动、三类元素可辨动态、角色状态与遮挡 |
| 轻度 | 先降低热气频次/同时缕数，缩小灯光透明覆盖面积，减少可选摇杯动作线；保持对象骨骼与单页 | 亮部/阴影仍可比较，灯笼仍能看见暖光与摆动；幽灵情绪仍由骨骼可辨 |
| 强度较高 | 关闭可选热气和可选摇杯动作线，树/花降低摆幅/刷新频率，灯光使用更短的局部过渡 | 奶茶店仍有动效加亮/暗投影对照；树、花、灯各仍有可辨动态或伴随反馈；对象开关、左右坐姿及遮挡正确 |

若目标设备连必验表现都无法保持，应标记阻塞并由 Art/Tech/VFX 重新设计与用户审阅，不能把必要亮暗联动、任一类场景元素效果或顾客情绪表现默默删掉。降级在所有入口引用**同一资源和同一等级规则**，只按设备档位和获批配置选择，不分别手改 Lab/组合/主体场景。资源图集、光影质量和角色视觉身份不能因为降级漂移。

## 3. 生命周期与无残留约束

单个效果对象有 `inactive → active → stopping → inactive` 的表现生命周期；状态名称仅为说明，不指定 Client API。触发时先检查所属对象存在、资源就绪、无重复实例；停用时立即阻止新回调并关闭或回收到可预测基态。重置/返回/Scene 卸载必须停骨骼/补间、清计时器和事件订阅、复原 alpha 与材质参数、释放局部挂点、销毁或回收该对象的热气/光斑/影/动作线。异步资源到达时先确认仍属当前场景会话，不能在切菜单后重生旧效果。

同名资源可由第2/4/7项共同引用，但运行实例必须归各自店、树、花、灯对象；移除一盏灯笼只清它的暖光，不把奶茶店灯也关掉。组合场景里独立 Prefab 可用同一源 UUID/哈希，场景配置只允许获批的装配差异，不复制效果参数或建立“组合版”。顾客左右翻转只作用于局部视觉骨骼；地面影、世界灯照、文字/UI和座点不随镜像，坐姿板凳移除按角色安全退出后清理。对话浮层只抢输入，不触发或延长场景效果。

QA 应在独立入口与组合入口取以下无残留证据：一次预览后效果数回初值；同按钮连续多次触发仍一组；店/灯分别移除互不影响；快速返回/重进没有旧烟缕或光斑；组合全开后重置与第1项空底板一致；设备降级后仍满足必验效果。正式资源和状态接口未获用户审批前，这些是后续验收要求而不是测试结论。
