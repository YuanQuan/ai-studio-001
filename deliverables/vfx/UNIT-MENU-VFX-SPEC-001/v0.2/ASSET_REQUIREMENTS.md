# 七项菜单单元｜特效资产与出图需求 v0.2

任务：`UNIT-MENU-VFX-SPEC-001`。本表是**正式生产前需求**，不是完成清单。当前没有本版正式分层 VFX 原画、幽灵逐帧源、骨骼、图集、Prefab 或设备实测。具体资源 ID、目录、骨骼分件、贴图尺寸和参数由获批 Art/Tech 契约锁定；下列效果 ID 只是跨角色沟通标识。

## 1. 所需原创源与归属

| 表现 | 可编辑正式源 / 导出所需信息 | 归属、挂点和复用 | 出图核验 |
|---|---|---|---|
| `SHOP_LIGHT_PAIR` | 灯罩基态/亮态、墙与柜面对应受光层、邻近暗部与地面投影的基态/亮态；保留干净 alpha 和同机位前中后对照。店身不得预烘无法关闭的暖晕 | 归一间奶茶店；灯罩和受光随店动态件/店表面，地面影留世界锚。菜单 2/7 与未来主体同一源；不另制组合版 | Art 验证冷暖比例、木砖瓦材质和牌匾/孟桃无遮挡；Tech 核贴图、材质、透明覆盖、真实批次与目标设备。亮、暗、影须同启停 |
| `SHOP_STEAM`（候选） | 若获准，提供机口附近一至两缕轻量蒸汽的可编辑笔画、透明范围与极限姿态；不画具体商品 | 仅归当前店实例的奶茶机局部，受前柜遮挡；可并入店动态件附件。若独立骨骼对象，仍按该对象单页评审 | 不凭旧待审稿自动导入；若挤占图集或透明面积过大，先简化/取消该候选层，必要灯影不减 |
| `MT_WORK_ACCENT`（候选） | 只有另获批准才制短工作线；无需新魔法、奖励或商品图 | 属孟桃实例的手/杯局部，跟工作骨骼姿态；3A/7 同源 | 未获批准时本项不进入正式资源目录，也不阻塞孟桃本体动作 |
| `GHOST_STATE_VISUAL` | **一个方向**的原创可编辑逐帧母版、干净透明帧、每动作帧序和原点/脚点/接触点记录；移动、跑动等需循环的每动作约 4–6 帧起评，情绪可一次动作加保持，坐姿分进座/稳定/离座 | 属一名幽灵顾客；3B/7 与未来主体复用同一帧图及状态。另一方向只翻转帧显示节点；板凳是独立对象 | **不用骨骼、骨骼挂点、骨骼单页约束**；逐动作检查首尾接缝、轮廓/透明边/体量、左右×五状态、地影和板凳接触。幽灵图集页数、材质和批次按真实 packing 与设备结果决定，不能强制一页或凭 4–6 帧推断低消耗 |
| `TREE_SWAY` | 一棵树的原创枝/叶分件、可编辑骨骼与轻摆极限帧；静态根/地影可另层 | 属当前树实例；4/7 同源，世界根及地影不随枝叶摆动 | 动态树**每骨骼对象附件一页**；前后叶片、透明边、遮挡、尺寸与合批双签 |
| `FLOWER_NOD` | 一簇花草的梗/叶分件、可编辑骨骼；土/盆与世界脚点可另层 | 属当前花草实例；4/7 同源 | 动态花草每骨骼对象附件一页；小屏轻摆须可辨，不加花粉大粒子 |
| `LANTERN_SWAY_GLOW` | 灯笼摆动分件、局部暖光范围与受光层；世界挂点及前后遮挡范围 | 属当前灯笼实例；4/7 同源，一灯一组光；邻近受光可分材质，但启停仍从属该灯 | 动态灯笼每骨骼对象附件一页；光/影独立关停、不盖字与脸；一灯移除不关店灯 |

静态店身、板凳、地面、固定背景和 UI 不因为与光影同镜头，就强行拼进动态骨骼单页。骨骼对象单页是纹理归属约束，不是单 Draw Call 保证；遮挡、透明混合、材质、Spine 数据或 UI 都可能断批。幽灵是逐帧纹理动画，不要求“所有状态共 4–6 帧”，也不要求一页。任何资产不能由概念展示图直接裁切；需新的可编辑正式源与可追溯导出。

## 2. 每次正式出图前 Art / Tech 双签

每一版、每一对象在**画出或导出正式资产之前**记录：所依据的 Product/Art/VFX/Tech 已批准版本；原创源与参考出处；图片/字体/作者工具的商业使用、嵌入、分发、修改许可和外观相似风险；对象 ID、层级、世界/局部挂点、脚点/座点、极限姿态；原始画布、附件或逐帧像素 bbox、alpha 留白/padding；单方向与翻转后字形/挂件/持物/手势/光照核对；真实或草排图集的宽高、页数、纹理格式及压缩回退；材质混合、预期断批、透明覆盖面积及显存估算；目标屏幕比例与最低设备可读性；Art 与 Tech 两人的签名、日期和版本。

幽灵再列**每动作**的帧数、序列顺序、循环首尾差异、情绪保持和进/离座转换、左右十格的取证计划；骨骼对象再列骨骼源、作者工具和运行版本兼容、每对象单页 packing。新增附件、帧、材质、贴图页、挂点或目标平台后，原签认失效并重签。若约 4–6 帧无法自然循环或需另一向专属绘件、显著扩帧、退回骨骼，先走变更与用户审批，不仅凭双签扩大范围。

获批产物登记可编辑母版、正式透明导出、图集与稳定 Creator 资源身份/版本；独立单元和组合单元引用同一源，未来主体接入再复验相同 ID/版本。未核实来源或字体许可的图像不得集成；修改字体外形不能替代许可。具体技术阈值、Prefab/资源路径和实测结论留给 Tech/Client/QA 的获批版本，VFX 只定义需证明的表现。
