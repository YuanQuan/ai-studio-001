# U05 B 三类奶茶人工配置草案

版本 v0.1，待 Product／Tech Review 与用户对**本配置版本**明确批准。已批准的上游 Product v0.1 规定每杯恰选茶、奶、小料各一项、十二种幻想原料及十阶段开放数 2/2/2 至 3/3/6；本稿只把这些内容落到独立人工源，不改现行源、索引、生成器或客户端。

一局仍逐单制作三杯，简单不限时，中等起沿旧倒计时。五档两阶段的熟练度起点、时间、每档通关经验、初始简单及解锁开关与阈值逐项沿用旧正式表。成功和重打通关给对应 XP，失败退出不给；累计 XP、通关记录、永久解锁沿用，旧五维未完局不恢复到新三维局。成品气泡仅显示杯图，独立查看配方入口继续存在；本表不写 UI 布局、图像资源或存档格式。

新版配方用三类 ID 组成。每档阶段 1 可用的三类前 N 个 `sort_order` 原料与阶段 2 增量共同定义可出题池。每档阶段 2 的全部合法组合各列一条配方，`min_stage_no` 为这三个原料首次同时开放的阶段，因此阶段 1 不会抽到阶段 2 才出现的正确项。每档最大开放池的组合数为简单 12、中等 27、困难 36、地狱 45、噩梦 54，共 174 条；这不是一局杯数、整杯图片数或新增奖励。茶色、奶纹、小料轮廓由同源图层组合表达，具体美术可辨性由 Art 与单元示例 Owner 验证。

工作簿全部行保持 `status=DRAFT`、`export_enabled=false`，只供审阅。Tech 需审字段类型、ID 引用、生成校验及旧记录兼容，然后本配置版本再交用户审批；未经过这些门禁，不发布到公共无版本源或运行资源。完整字段与迁移见同版 `CONFIG_SPEC.md`、`FIELD_GUIDE.md`、`CHANGE_IMPACT.md`。
