# 百鬼夜市核心场景 Demo｜产品规格

版本：v0.1｜任务：DEMO-001｜负责人：Product Agent｜状态：待专业评审与用户审批

## 1. 目标与输入

用一段可运行的竖屏手机 Demo 验证四件事：远景 2.5D 夜市大地图能拖拽和缩放；玩家能修复一处破败摊位并看到店长出现；可爱鬼怪顾客从奈何桥入口走进夜市，经过主要通道后从画面右下的桥离开；最简点击 UI 能完成上述操作。此 Demo 只验证场景、镜头、交互和表现串联，不代表正式游戏首版。

视觉输入：[破败场景](../../../visual-concepts/DEMO-001/nightmarket-ruin-reference-v1.png)与[首摊修复后](../../../visual-concepts/DEMO-001/nightmarket-first-shop-reference-v1.png)。两图体现同一固定远景构图的修复前后对照：竖屏等距视角、水域与桥、冥界门楼、石路、灯笼和模块化摊位；重点是中央偏上的一处摊位从破败变为点灯营业，并出现店长。图中的资源栏、多个菜单、金币和其他玩法按钮只是视觉示意，本 Demo 不据此增加系统。`PRODUCT-001 v0.7` 仍未批准，仅作背景，不成为本任务上游需求。

## 2. 场景与镜头边界

- 单张连续夜市地图，世界尺寸大于竖屏初始可视区域；初始镜头展示入口方向、待修复摊位及主要通道，让玩家识别下一步可点击目标。右下离开桥可在初始画面边缘或通过拖拽看到，但完整顾客路线须落在同一张地图内。
- 场景保持远景 2.5D／等距观感。入口定义为地图左上奈何桥，出口定义为地图右下桥；两者是角色路线地标，不靠屏幕像素坐标判定。背景可以包含多个破败摊位以形成夜市规模，但本 Demo 只有一处可修复、可交互的目标摊位。
- 单指拖拽移动镜头；双指缩放或等价触控缩放使玩家能看清目标和整体布局。缩放后仍可拖拽。镜头不得露出地图外空白；应有可见的近、远缩放边界，不能缩到目标无法辨认或场景只剩空白。具体缩放比例、阻尼和安全区由 UI／Tech 后续给出，不在产品稿锁数字。
- 拖拽、缩放不改变摊位状态或顾客路径。点击目标摊位时应避免与拖拽手势混淆；镜头移动后目标仍可点击。重新打开 Demo 默认回到可重复验证的初始破败状态；是否需要保存进度不纳入本次验证。

## 3. 摊位交互状态

| 状态 | 玩家可见内容与操作 | 下一状态 |
|---|---|---|
| 破败／待修复 | 目标摊位与其他破败摊位有可辨识的点击提示。点目标摊位弹出最简“修复”操作。 | 确认修复 |
| 确认修复 | 点“修复”后立即展示修复结果；无需资源、倒计时或任务条件。点关闭可返回破败状态。 | 已修复 |
| 已修复 | 摊位外观转为参考图中的点灯营业状态，并在该摊位出现一名可辨认的店长。可给一次简短的结果提示。 | 保持已修复 |

修复行为在本次运行中只生效一次。修复完成后再次点击该摊位，可查看“已修复／店长已到位”的简短提示，不重复生成店长、不重放修复收益。连续快速点击也只产生一个修复结果。其他背景摊位不弹出可修复入口。店长只需能被看见且与该摊位有明确归属，不要求招募、技能、排班、故事或交易。

## 4. 顾客路线与表现

- 顾客是可爱卡通鬼怪，和阴森但温暖的夜市形成视觉对比；至少有可辨认的行走表现。可复用少量外观，不要求角色图鉴或特殊顾客。
- 顾客从左上奈何桥的地图入口出现，沿可见石路经过夜市主要区域，再从地图右下桥离开。路线在修复前后都可观察；修复后可表现顾客经过亮起的摊位，但不要求驻足、排队、消费或收益。
- 角色不穿越建筑或水面、不在屏幕内凭空消失；到出口后从地图边界离开。持续观察应能看到不止一名顾客依次走完路线。镜头拖拽或缩放时，路线与地标保持一致。
- 路径具体点位、生成节奏、同屏数量及避让方式由后续技术与美术规格确定；验收关注入口、经过、出口三段可见且连贯。

## 5. 最简 UI

只保留完成验证所需的可点击控件：待修复摊位提示、修复按钮、关闭／返回按钮，以及修复完成的短结果提示。镜头拖拽和双指缩放直接在场景操作。控件在竖屏安全区域可触达，不遮住目标摊位或关键顾客路线；按钮状态须能区分“可点”和“已完成”。具体外观由 UI 与 Art 在参考图风格下细化。若测试环境缺少双指输入，可由技术测试工具模拟手势；产品界面不为此增加永久功能按钮。

## 6. 不做项与边界

不做资源扣除或产出、货币栏、进货、摊位升级／改造／装饰、店长招募与培养、商品订单、顾客偏好／驻足／排队、闹事者、任务、广告、社交、世界共享、账号或服务端同步。参考图中多个摊位和复杂顶底栏只用于气氛与布局。修复动作是一次性状态变化，不表示正式游戏修复规则。无永久存档要求；重启回初始状态使验收可重复。

## 8. 验收场景与证据

1. **地图**：竖屏启动画面能辨认入口、目标摊位和夜市通道；拖向各边界并缩放到两端，画面不露空白，缩放后目标仍可点击。证据：启动及两端缩放截图、连续手势录屏。
2. **修复**：破败摊位点开修复入口，关闭不改变状态；再次打开并修复后，摊位切换为点灯营业状态且出现一名店长。证据：前后同镜头截图与点击录屏。
3. **幂等**：修复后连续重复点击，只看到已完成提示，店长仍为一名。证据：连续点击录屏或状态日志。
4. **顾客路径**：至少一名可爱鬼怪从左上奈何桥进入，经过夜市石路，从右下桥离开；拖拽缩放过程中路径仍附着地图。证据：覆盖入口、经过、出口的连续录屏。
5. **UI**：只有上述验证必需控件可操作，竖屏下可触达；场景手势不会误触修复。证据：界面截图及点击／拖拽交替录屏。

本节定义产品可观察结果。目标机型、帧率、加载时间与性能数据的验收口径由 Tech Lead 后续确定；QA 在批准后据此增加测试，不以概念图的像素级一致性作为通过条件。
