# PRODUCT-001｜产品概要与变更说明

版本：v0.8｜成熟度：头脑风暴／待用户审批
主阅读入口：[交互脑图](https://mindmapai.app/canvas/ca3de2ca0bd9198b95d4c3b88ed23be70c4ace16febc0e03d0dd67e08e14b467/edit)｜[项目内可编辑源](BRAINSTORM_MAP.md)｜[提交时静态快照](MINDMAP_AI_SNAPSHOT.md)

## 1. 本版目标与版本关系

按用户本轮明确方向，修订 M02 店铺、M03 店长、M05 故事、M06 资源及相关模块之间的关系。v0.7 的非店长系统方向仍可作为讨论背景，但 v0.7 中凡涉及抽卡、招募、重复店长、升星专精、跨店搭配、店长数量预测和对应广告机会的表述均由本版替代；旧版只供追溯，不是现行开发输入。整包仍待用户审批。

核心体验：清扫破旧店铺 → 修复并迎接该店专属店长 → 经营和探索中帮助店长找回魂魄 → 店长能力、认知、沟通和性格逐步恢复 → 展开更深的角色剧情与经营目标。

## 2. 本轮用户确定的方向

| 模块 | 方向 |
|---|---|
| M02 店铺 | 店铺与店长固定绑定；通过清扫破旧店铺及游戏进程迎接对应店长。取消不同店长搭配不同店铺的玩法。 |
| M03 获取 | 取消抽卡获取店长，也不以重复店长作为养成来源。 |
| M03 养成 | 店长初始等级为 0；消耗资源升级。等级达到门槛后逐层开启魄与魂的恢复。魄每增加 1 个，整体属性按比例提升；魂影响工作效率、清醒程度和后续剧情。数值门槛、比例和资源消耗待具体设计。 |
| M03/M05 角色表达 | “三魂七魄”是店长逐渐找回完整自我的主题；0 魂时只能说只言片语，之后认知、沟通和性格逐渐清晰。店长初来时不能发挥全部工作能力。 |
| M03 视觉 | 0、1、2、3 魂有四种可辨认状态。每次升魂，表情明显变化；人物姿态按 0 魂、1–2 魂、3 魂三档区分。对话框半身像、详情立绘和主场景店铺工作表现均反映阶段。骨骼结构和装扮挂点保持一致，为后期换装留空间。 |

“已找回魂魄累计保留”是本轮讨论中接受的表达原则。旧例 `0魂7魄→1魂0魄` 不应作为玩家可见的恢复进度；若数值内部需要段位循环，必须设计不误导玩家的显示与命名。本版不锁定升级次数、魂魄获取频率或最终属性公式。

## 3. 脑图模块影响

| 模块 | 本版需要修订的关系与边界 |
|---|---|
| M01 夜市经营 | 删除跨店安排店长作为经营策略的表述。店长工作效率影响其绑定店铺的产出与接待；与店铺并行容量分开定义。 |
| M02 店铺与建设 | 清扫、修复、迎接店长成为同一店铺的进程链。店铺装修仍可与顾客互动，但不改变店长归属。 |
| M03 店长 | 删除招募、重复转化、升星、跨店适配与专长配置。采用等级／魄／魂逐层成长；先明确恢复叙事，再设计数值。 |
| M04 进货探索 | 可以承担部分魂魄找回线索或资源来源，但具体关卡、掉落与条件未决定。不得预设探索是唯一来源。 |
| M05 故事 | 为店长设计随魂阶段变化的台词、认知、性格与剧情节点；清扫店铺和迎接店长构成相遇事件。 |
| M06 经济 | 移除“招募券→抽卡”和“重复店长→妖魄→升星”闭环。旧妖魄名称、来源和用途与新七魄语义可能冲突，须在数值设计时重审，不直接沿用。 |
| M08 任务活动 | 原招募券奖励和额外招募机会候选失效；长线目标可连接店铺复苏与角色清醒。 |
| M09 广告 | 删除“额外招募机会”候选。其他既有自愿增益仍仅为待审候选，不绑定找回魂魄主进程。 |
| M11 顾客 | 特殊顾客仍可与绑定店长互动；触发条件可考虑魂阶段，具体频率与任务内容待细化。 |
| Art/UI/Tech/QA | 这是跨专业影响提示，尚非制作规格：Art 需评估四状态、三姿态及同骨骼换装；UI 需呈现养成与三个展示场景；Tech 需评审骨骼与状态引用；QA 后续验证各阶段表现一致。均需下游正式任务和用户审批后执行。 |

旧版原型估计“2–3 店／4 店长、6 店／12 店长”与一店一长方向不一致，不能继续作为首版规模依据。具体店铺和店长数量待重新评估。

## 4. 待细化的问题

1. 等级、魄、魂的具体开放门槛、资源来源、消耗和属性曲线，由 Product 数值设计后提交审批。
2. 三魂与七魄的玩家界面表示、找回顺序和剧情触发条件待细化；已找回的进度不应在升魂时显得消失。
3. 每个店长的清醒阶段台词量、剧情量、表情差异与工作动作差异，需要 Art、UI、VFX、Tech Lead 评估制作成本。1 魂与 2 魂共用姿态但要保留可辨认表情变化。
4. 同一骨骼跨装扮的部件边界、挂点和动画复用方式属于技术／美术规格，本概要不预先锁定实现。
5. 与已批准 Demo、单元样例或当前候选店铺／店长选型的关系需分别做影响评审；本版未批准前不直接改动其正式范围。

## 5. 验收口径

- 脑图及同版短说明包含店铺清扫→迎接绑定店长→找回魂魄→能力与人格恢复的闭环。
- 抽卡、重复店长升星、跨店搭配及对应资源／广告路径从现行脑图删除，历史版本保留。
- 四个魂状态、三档姿态、三处展示场景和同骨骼换装空间均可在脑图与说明中找到。
- 数值和制作细节明确标为待细化；用户批准本版前不解锁下游正式制作。
