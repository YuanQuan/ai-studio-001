# 六位店长性格与魂成长｜验收标准 v0.2

以下是本版产品规格的可审条件。通过表示文档已覆盖，未表示美术、剧情实装或 QA 已通过。

| 编号 | 条件 | 本版核对结果与证据 |
|---|---|---|
| A01 | 名单只包含孟桃、阿棠、阿炭、阿角、阿灯、小锦，并保留四位历史核心标签、六人的身份和店铺关联；新增的阿棠与阿炭性格明确标为提案。 | PASS：`PRD.md` 第 1、2 节。 |
| A02 | 六人各有独立的主成长维度，包含用户提出的语言、记忆、体力及另三个新维度，维度与人物目标、工作表现相符。 | PASS：`PRD.md` 第 2 节一人一行，新增情感感知、精细动作协调、舞台自信与感染力。 |
| A03 | 六人均有 0／1／2／3 魂可区分变化，同一情境下能对比对白或行为；0 魂保留原人格。 | PASS：`PRD.md` 第 3 节六张四阶段对照表。 |
| A04 | 仅阿棠在 0 魂只言片语、3 魂完整表达；其他五人 0 魂能正常交流，不把语言受限套给全员。 | PASS：`PRD.md` 第 3、4 节；阿棠另可用糖画和手势交流。 |
| A05 | 情感感知不等于道德低劣，体力恢复不改变阿炭身份，阿角技巧与发型状态不贬低审美和人格，阿灯记忆与方向感分开，小锦舞台自信不等于语言能力。 | PASS：`PRD.md` 第 2–4 节对应角色及共通边界。 |
| A06 | 六人表注明店铺；阿角本人发型在0／1／2／3魂依次为油腻贴头分头、开始整理仍服帖、清爽蓬松尚未最终、精神挺立时髦；半身对话、详情立绘、店前全身工作三处有可供 Art 评估的辨识线索，同时不锁定具体造型、骨骼或额外生产资源。 | PASS：`PRD.md` 第 2–4 节。后续实际视觉验收需独立任务。 |
| A07 | 七魄、数值、玩法奖励、美术出图、动画和客户端接入没有被此提案擅自确定；受影响的历史 Artifact 和再审批点可追溯。 | PASS：`PRD.md` 第 1、4 节及 `CHANGE_IMPACT.md`。 |

本版进入用户审阅前仍须 Master 对同版 Artifact Review 通过，并由 Producer 核对应审批记录。用户批准前，本版只作待审提案。
