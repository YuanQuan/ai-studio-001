# 六位店长性格与魂成长差异｜产品提案 v0.2

任务：`U04-MANAGER-PERSONALITY-001`｜所属方向：M03 店长／M05 故事｜状态：待 Master Review 与用户审批。此版只确定人物性格与魂阶段的辨识语义，不是绘图、数值或开发输入。

## 1. 来源与已确认边界

用户已确认本轮六位店长为孟桃、阿棠、阿炭、阿角、阿灯、小锦，并暂停绘图，先确定性格与魂成长。用户本次补充阿角本人的发型须从颓废油腻分头逐魂变成精神挺立的时髦造型，并要求六人表明所属店铺。用户明确纠正：只有其中一人采用“0 魂只言片语、3 魂完整表达”，不能成为全员特征；本提案选阿棠。四阶段仍为 0／1／2／3 魂；已找回的七魄累计保留、影响属性的方向沿用讨论，不在此定义数值、门槛或每一魄的外形变化。

四位历史种子标签来自 `project/research/历史市场调研与方案_v0.2/03_世界观与角色叙事框架.md`，其身份和梦想沿用为人物识别素材：孟桃“叛逆甜品控”、阿角“爱美自信”、阿灯“热心路痴”、小锦“舞台型梦想家”。阿棠、阿炭的身份和店铺关系来自 `project/brainstorm/SIX_STALLS_TAP_GAMES_v0.2.md`，此前未给定性格。两份均是历史讨论资料，不自行升级为已批准规格。`PRODUCT-001 v0.8` 中全员 0 魂只言片语的讨论表达，以用户本轮修正覆盖；其他视觉阶段要求只作为后续 Art 评估输入。

## 2. 六种主成长表现

“主成长维度”是玩家最容易识别该人物变化的一条线，其他能力仍可自然变化，不禁止角色正常说话、记事或工作。0 魂保留性格种子，3 魂让原有长处更稳定；成长不应被表现成缺德、低智或换了一个人；不把现实障碍当笑料，也不将身体差异与人格价值绑定。

| 店长／店铺 | 主维度 | 性格核心与反差 | 玩家最先看到的变化 |
|---|---|---|---|
| 孟桃／奶茶店 | 情感感知与共情（新增） | 叛逆甜品控，嘴上反抗家族安排，实际上很在意客人是否喜欢自己的配方。她从“急于证明自己”成长为“能听懂别人需要什么，仍坚持自己选择”。 | 对话从抢着推荐自己的口味，到能回应客人情绪；半身像从急着争辩转为先观察再递杯。0 魂并非冷漠或恶意。 |
| 阿棠／糖画店 | 语言表达（用户例子的独立承载者） | 内敛、执拗的糖画灵；画得比说得快，想把夜市故事留在糖画里，却害怕自己的意思说不清。恢复表达后仍是少言而精确的人，不变成话痨。 | 0 魂只能说只言片语，但能用动作与画表达；对白从词语、短句，到能讲完整的画中故事；半身像的目光和手势越来越主动。 |
| 阿炭／炭烤串店 | 体力与耐力（用户例子） | 外表像可靠的灶火精，做事执拗、嘴硬心软；过去只会机械地守火，逐渐重新享受给人做热食。体力恢复使其能持续照顾一摊人，不以“壮＝粗鲁”代替人格。 | 全身站姿从短时倚靠、肩臂力量不足到稳定站直、肌肉轮廓更有支撑感；烤串工作动作从需停顿到连贯。对白始终正常，心意逐渐更直白。 |
| 阿角／造型铺（理发） | 精细动作协调（新增） | 爱美、自信，讲究手艺，遇到自己做不好的细活会不服输地反复练。她0魂仍有爱美的审美判断，只是暂时不能把自己的头发与细活做到理想样子。她不靠家人的体力长处证明自己，而以理发、编绳与发饰找到位置。 | 手指、理发、编绳与佩饰收尾从不稳到利落；本人发型由油腻贴头的分头，经过整理、蓬松支撑，最终成精神挺立的时髦造型。半身像手势从掩饰失误到主动展示作品。0魂仍有自信与审美；发型状态不代表道德或人格价值。 |
| 阿灯／花灯店 | 旧街记忆（用户例子） | 热心路痴，想重新点亮整条街；记得人的温度与承诺，却一时想不起旧街的具体往事。恢复记忆后仍会在陌生岔路走错，路痴是空间方向感，不等于记不得熟人或说不清话。 | 对话中对旧牌楼、人和点灯次序的回忆从零散片段到能完整讲述；半身像在熟悉灯面前从迟疑到确认。 |
| 小锦／投壶游艺店 | 舞台自信与感染力（新增） | 舞台型梦想家，爱模仿戏台开场，私下在意评价；从只敢对自己排练，到能让顾客放心参与、享受主持。0 魂有梦想与表演欲，不是社交失能。 | 对话和工作动作从排练式开场、容易收声，到自然看向观众、稳稳接住喝彩；半身像姿态与表情更开阔。不会因魂低而语言退化。 |

## 3. 四阶段逐人表现与对白校准

以下对白是校准语气的短例，不是最终剧情台词。每人选一个相近场景做横向对照，以免把进阶误写成四个无关事件。各阶段对话半身像、详情立绘、店前全身工作表现均应有辨认线索；具体造型、资源复用及动作由后续 Art／UI／Tech 评估。

### 孟桃／奶茶店｜情感感知

| 魂 | 性格与对白示例（顾客犹豫喝什么） | 可见表现 |
|---|---|---|
| 0 | 急于证明新配方，仍愿意帮人：“我这杯甜的。你试试？不好喝算我的。” | 抢先举杯，眉眼倔强；会看顾客但错过犹豫。 |
| 1 | 注意到顾客没有接杯：“你是不是不想喝太甜的？” | 递杯动作停一下，开始留意对方表情。 |
| 2 | 主动追问但保留自己的主张：“今天看着累，我给你调淡一点，香味还在。” | 先观察再动手，表情从争辩转为关切。 |
| 3 | 能理解未说出口的需要，也守住独立选择：“你想要一点暖，又不想被甜味盖住。试试我改的这杯。” | 递杯动作稳，目光与客人交流，自信而体贴。 |

### 阿棠／糖画店｜语言表达

| 魂 | 性格与对白示例（客人问糖画画了什么） | 可见表现 |
|---|---|---|
| 0 | 只能说词语或碎片：“灯……街。给你。”能指画面和点头回应。 | 低头画出清晰图案，用画和短手势补足表达；不表现成不懂问题。 |
| 1 | 能说短句：“是旧街的灯。我想把它留下。” | 指向画中灯，抬眼确认客人是否明白。 |
| 2 | 能把前因后果接起来：“以前这盏灯照着回家的人，我怕大家忘了它。” | 讲述时边画边看客人，停顿自然。 |
| 3 | 完整、精练地讲出自己的故事：“这盏灯曾给晚归的人指路。我把它画给你，夜市就又多一个记得它的人。” | 手与目光主动引导客人看画，仍保持内敛。 |

### 阿炭／炭烤串店｜体力与耐力

| 魂 | 性格与对白示例（客人问还能不能再烤一串） | 可见表现 |
|---|---|---|
| 0 | 能清楚回答，嘴硬：“能。你先等，我换口气。” | 站姿略靠烤台，肩背使力不足；翻串后需要短暂停顿。 |
| 1 | “能烤，别急，火得看稳。” | 可独立站稳，烤一轮后仍显疲态。 |
| 2 | “再来一串？正好，火候刚到。” | 肩臂力量与持串动作更稳定，连续照看多串不慌。 |
| 3 | “给你留了热的。忙了一晚，吃口刚出炉的。” | 肌肉轮廓有可靠支撑感，动作连贯；关照他人的心意更自然。 |

### 阿角／造型铺（理发）｜精细动作协调

| 魂 | 性格与对白示例（给顾客编一条绳饰，同时打理自己的头发） | 可见表现 |
|---|---|---|
| 0 | 审美和自信已在：“颜色我选好了。这个结……再给我一下。” | 本人头发为颓废油腻、贴头的分头；她知道理想造型，只是暂时整理不到位。能挑对颜色，手指收结不稳，反复调整；不拿手部状态当笑料。 |
| 1 | “这个结还差一圈，别急，我会系好。” | 开始整理自己的分头，仍较服帖、欠支撑；编绳顺序更清楚，仍需停下确认。 |
| 2 | “你看，纹样和衣角正好对上。” | 本人发型轮廓清爽、已有蓬松支撑，但未到最终造型；双手配合流畅，能边整理边展示。 |
| 3 | “这条是给你配的。我把收口藏在背面，戴着也舒服。” | 本人发型精神挺立且时髦；收尾细致稳定，主动翻转作品让客人看细节。 |

### 阿灯／花灯店｜旧街记忆

| 魂 | 性格与对白示例（客人问旧牌楼的灯） | 可见表现 |
|---|---|---|
| 0 | 热心仍在：“牌楼那边有灯……我记得有人等过。” | 对熟悉灯面迟疑，仍主动为客人指亮处；可能指错陌生岔路。 |
| 1 | “那盏灯好像给晚归的人留过。” | 触到灯面时出现片段回忆。 |

| 3 | “旧牌楼每晚最后一盏灯，是等收摊的人平安回来的。” | 笃定地讲述与点灯；随后仍可能笑着问“去新巷子该往哪边？” |

### 小锦／投壶游艺店｜舞台自信与感染力

| 魂 | 性格与对白示例（邀请客人投壶） | 可见表现 |
|---|---|---|
| 0 | 能完整说话，偷偷演练：“各位……欢迎试试。这样说还行吗？” | 面向空处排练，见人会收小手势；仍期待被看见。 |

| 3 | “投得漂亮！下一位也来试试，今晚的戏台有每个人的位置。” | 主持节奏自然，能把注意力分给顾客，开阔而不喧宾夺主。 |

## 4. 共通边界与后续评估

- 六人的 0 魂均有身份、偏好与可辨认的人格。只阿棠采用只言片语到完整表达；其余五人所有阶段能正常交流，成长表现在各自维度。
- 魂阶段表达的是逐渐找回自我，不以道德水平、智力或身份切换作为升级奖惩。阿灯的旧街回忆与路痴分开，阿炭的体力变化与关照他人的性格分开，小锦的台风与语言能力分开。
- 每次升魂应有可辨认的表情变化；历史概要提出 0、1–2、3 魂三档姿态及同骨骼／换装挂点空间。阿炭的渐进体力轮廓、阿角本人发型演进与手部精度等具体做法须由 Art 与 Tech Lead 复核，不预定新骨骼、换衣或逐魄造型。
- 此稿不锁定剧情事件数量、对白量、养成资源、属性公式、经营奖励、商品和新场景。获批后由 Master 编排 Art 更新六人形象方案；其后正式图片、切片与接入仍逐环节审批。
