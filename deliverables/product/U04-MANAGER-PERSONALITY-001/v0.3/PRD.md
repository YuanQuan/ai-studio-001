# 六位店长性格与魂成长差异｜产品提案 v0.3

任务：`U04-MANAGER-PERSONALITY-001`｜所属方向：M03 店长／M05 故事｜状态：待同版 Review 与用户审批。本版只定义人物性格、对白和可见成长语义，不是美术生产、医学设定、数值或开发输入。

## 1. 已确认方向与提案边界

用户已确认六位店长为孟桃、阿棠、阿炭、阿角、阿灯、小锦，先定义性格与魂成长，暂停绘图。用户本次明确修订五人的成长方向：孟桃由叛逆外显到淑女文静；阿棠语言困难且害羞内向到表达流畅、自信外向；阿炭由瘦弱黑眼圈、厌食症表现到健硕有精神、症状消失；阿灯需呈现三句聊天会忘前一句的短时遗忘；小锦是女性鲤鱼精，近视从明显圈纹高度近视眼镜阶段逐渐改善，后期使用隐形眼镜。阿角沿用 v0.2 已提出的发型与精细手艺四阶段。六人店铺对应在本版总表与逐人小节列明，其中角色身份／店铺关系源于历史种子与六摊讨论稿，六店对应沿用当前已明确的名单与店铺关系。

用户明确“0 魂只言片语”只属于一人而非全员；本版继续提议阿棠承载，具体人选待用户批准。六人四阶段仍为 0／1／2／3 魂。七魄已找回进度累计保留、影响属性的方向沿用讨论；本版不定每魄造型、数值门槛、具体度数、治疗方式或新玩法。

四位历史种子标签来自 `project/research/历史市场调研与方案_v0.2/03_世界观与角色叙事框架.md`：孟桃“叛逆甜品控”、阿角“爱美自信”、阿灯“热心路痴”、小锦“舞台型梦想家”。阿棠、阿炭身份和店铺关联来自 `project/brainstorm/SIX_STALLS_TAP_GAMES_v0.2.md`。来源均是历史讨论，不等于整版获批；用户本轮明确的新特征优先。旧 `PRODUCT-001 v0.8` 对全员只言片语的描述已由本轮用户要求覆盖。

## 3. 四阶段逐人对照

短对白是人物语气与能力的校准例句，并非最终剧情文本。各阶段须在店前全身、对话半身、详情立绘和工作表现里留下可检查的识别点；具体图层、骨骼和资源量由 Art／Tech 后续评估。

### 孟桃／奶茶店｜从叛逆外显到淑女文静

| 魂 | 同一情境对白：被问是否要继承家里的汤铺 | 外形与行为 |
|---|---|---|
| 0 | “不回去。我就开这家奶茶店，怎么了？” | 多枚耳钉／耳饰是叛逆风格提案，站姿带挑衅感；甜品控与开店意愿明确。 |
| 1 | “我还是想做自己的甜饮，别替我决定。” | 耳饰可略减，动作较少顶撞，仍会急着辩解。 |
| 2 | “我知道家里在担心，但这家店我想自己经营。” | 耳饰更克制，站姿收稳，能平静说明选择。 |
| 3 | “谢谢家里惦记。我会把这家奶茶店好好做下去。” | 少量或无可见耳钉，气质文静、仪态柔和；自主选择与甜品热爱未消失。 |

耳饰数量是视觉提案，具体数量、佩戴部位与许可风险由 Art 定；不把耳钉当坏，也不把“淑女”写成道德更高。

### 阿棠／糖画店｜语言与社交表达

| 魂 | 同一情境对白：客人问画了什么 | 外形与行为 |
|---|---|---|
| 0 | “灯……街。给你。” | 只言片语，害羞内向，低头、缩小手势；听懂提问，能用糖画和指画回应。 |
| 1 | “是旧街的灯。我想画下来。” | 能说短句，偶尔抬眼，愿意确认客人是否明白。 |
| 2 | “这盏灯照过晚归的人，我想让更多人记住。” | 能说完整因果，主动把画转向客人展示，仍会紧张。 |
| 3 | “你看，这里是回家的路。我画给你，也想听听你记得的夜市。” | 语言清晰，自信外向、主动发起交流，目光和手势开放；认真与执拗仍在。 |

### 阿炭／炭烤串店｜食欲与体力

| 魂 | 同一情境对白：客人问他是否也吃烤串 | 外形与行为 |
|---|---|---|
| 0 | “你吃。我……现在吃不下。” | 瘦弱、黑眼圈明显，工作后易疲惫；给客人烤得认真，但面对自己的食物回避，不拿症状开玩笑。 |
| 1 | “我先给你烤，等会儿再试一小口。” | 仍偏瘦、黑眼圈尚在；能面对自己的食物，偶尔尝一点但可能停下。 |
| 2 | “这串火候刚好，我也能吃完一串了。” | 气色与肩臂支撑变好；能较稳定进食，工作中休息后继续照看炉火。 |
| 3 | “我也饿了，收摊后一起吃刚烤好的。” | 健硕、有精神、动作连贯；自然出现饥饿感并能进食，用户要求的厌食症状在角色叙事中消失。 |

这是游戏中魂损与恢复的虚构人物线，不描述现实厌食症治疗、诊断或康复办法。体型、进食与人格价值不绑定；症状消失需由本人食欲和进食行为共同证明。

### 阿角／造型铺（理发）｜精细手艺与本人发型

| 魂 | 性格与对白示例（给顾客编一条绳饰，同时打理自己的头发） | 可见表现 |
|---|---|---|
| 0 | 审美和自信已在：“颜色我选好了。这个结……再给我一下。” | 本人头发为颓废油腻、贴头的分头；她知道理想造型，只是暂时整理不到位。能挑对颜色，手指收结不稳，反复调整；不拿手部状态当笑料。 |
| 1 | “这个结还差一圈，别急，我会系好。” | 开始整理自己的分头，仍较服帖、欠支撑；编绳顺序更清楚，仍需停下确认。 |
| 2 | “你看，纹样和衣角正好对上。” | 本人发型轮廓清爽、已有蓬松支撑，但未到最终造型；双手配合流畅，能边整理边展示。 |
| 3 | “这条是给你配的。我把收口藏在背面，戴着也舒服。” | 本人发型精神挺立且时髦；收尾细致稳定，主动翻转作品让客人看细节。 |

### 阿灯／花灯店｜短时对话记忆

| 魂 | 同一情境对白：客人要蓝色花灯 | 外形与行为 |
|---|---|---|
| 0 | “蓝色？……你刚才说要哪盏？” | 热心地接待，但对刚说过的话频繁断片；停顿、回头核问。 |
| 1 | “蓝色，我记住了……你要挂在门口吗？” | 能留住最近一句，但多轮对话中仍要复述确认。 |
| 2 | “蓝色的，挂门口，想要亮一点。我给你挑这盏。” | 能记住短对话与简单需求，仍可能漏掉更早的信息。 |
| 3 | “蓝色、挂门口、要亮一点，我都记得。这盏正合适。” | 多轮信息完整保留，自然接话；旧街往事也较清晰，仍可在陌生岔路迷路。 |

**三轮对话核对示例，使用同一客人需求：**

| 轮次 | 客人 | 阿灯 0 魂 | 阿灯 3 魂 |
|---|---|---|---|
| 第 1 轮 | “我想要蓝色花灯。” | “蓝色，好，我找找。” | “蓝色的，我记下了。” |
| 第 2 轮 | “要挂在门口。” | “蓝色，挂门口。我找找。” | “蓝色，挂门口。我看看尺寸。” |
| 第 3 轮 | “亮一点，夜里好认。” | “挂门口，要亮一点……你刚才说什么颜色来着？” | “蓝色、挂门口、亮一点。这盏合适。” |

上述是编写好的角色对白对照，不要求新增实时对话 AI、记忆系统或玩家输入解析。

### 小锦／投壶游艺店｜虚构视力恢复

| 魂 | 同一情境对白：请客人投壶 | 外形与行为 |
|---|---|---|
| 0 | “前面那位……是你吗？请往这边站。” | 女性鲤鱼精，戴有明显圈纹的高度近视眼镜；眯眼辨认远处客人和壶口，靠近确认后仍能完整主持。 |
| 1 | “我看见你了，往壶边再走一步。” | 眼镜仍在，辨认近处更稳；较远的细节还会看错。 |
| 2 | “你的箭落在壶边，我看清了。再试一次。” | 远处轮廓与投壶结果更易看清，可评估较轻眼镜或准备隐形；不把换镜片当恢复原因。 |
| 3 | “我看见你投中了！大家来给她鼓掌。” | 对远处客人、箭与壶口判断清楚；戴隐形眼镜修正仍有的轻微模糊，外观更利于舞台表达；看清能力的改善归于魂成长叙事，隐形眼镜不是治愈原因。 |

不写真实医学度数或“隐形眼镜能治近视”；3魂仍有近视角色特征；具体镜片形状、圈纹、佩戴方式与表达尺度由 Art 评估。保留小锦舞台梦想和主持能力，低魂不是语言退化或人格缺陷。

## 4. 共通边界与交接

- 六人 0 魂保留身份、偏好与人格。仅阿棠的只言片语人选为待批提案，其余五人能正常交谈。六条主线按用户最新人物要求组织，不再强求六种互不重叠的抽象能力。
- 阿灯的短时遗忘要在三轮对话里可见，旧街记忆可并行，路痴是独立旧标签。阿炭的厌食症用慎重的虚构叙事呈现，不以体型评价人格。小锦的视力恢复是魂成长设定，隐形眼镜仅为外形媒介。
- 各阶段表情和店前全身、对话半身、详情立绘、工作表现应可区分；历史概要提出0、1–2、3魂三档姿态及同骨骼、装扮挂点方向。阿角逐魂发型、孟桃耳饰、阿炭体型、小锦眼镜变化等具体资产做法须 Art 与 Tech Lead 复核，不预定新骨骼或逐魄外观。
- 本版不锁定剧情事件量、对白量、养成资源、属性公式、收益、商品、医学参数和正式图稿。用户批准准确产品版本后由 Master 安排 Art 修订方案；实际图片、切片和接入继续按各自审批门禁推进。
