# 百鬼夜市三类原料视觉候选

版本 v0.1｜全部为 **候选**，用于辨认性和概念图讨论，尚未确定业务品种、配方、稳定 ID、解锁档位或资源制作范围。名称与形态均为本项目拟议幻想元素，不引用现实茶奶小料品种或商业 IP。

| 类别 | 候选短名 | 便于画面区分的颜色与形态线索 |
|---|---|---|
| 茶 | 幽灯茶 | 金橙半透明液色，细小灯纹像浮在液面。 |
| 茶 | 月雾茶 | 淡青银雾色，杯中有缓慢旋开的叶影。 |
| 茶 | 冥霞茶 | 紫红渐层，轻薄霞片悬于液面。 |
| 奶 | 云魄乳 | 乳白与浅蓝云丝交织，流动时有软云边。 |
| 奶 | 霜铃乳 | 冷白微银，泡影像小铃形，不使用现实奶包装造型。 |
| 奶 | 萤绢乳 | 暖黄柔光，细点萤纹像绢丝铺开。 |
| 小料 | 鬼火珠 | 青蓝发光的圆珠，边缘有短火尾。 |
| 小料 | 梦纹冻 | 紫色半透明菱形块，内部有缓慢游移纹路。 |
| 小料 | 灯芯脆 | 金黄色短条与星屑形碎片，干爽且轮廓明确。 |

同类候选至少在色相、轮廓和动静表现上可区分；小料仍是每杯**一项**，并非多小料混搭。上表只有首轮视觉词汇，不代表五档所需的最终品种总数。

扩展节点也仅为讨论候选：简单先提供每类少量可辨品种；中等、困难、地狱、噩梦逐步增加各类可用品种，档内阶段仍可增加，但不改变三类结构。具体各档每类数量、哪些名称先开放、何时新增更多幻想品种，待看过概念与可读性验证后形成新版正式规格；本稿不将候选数量写入现行配置。
