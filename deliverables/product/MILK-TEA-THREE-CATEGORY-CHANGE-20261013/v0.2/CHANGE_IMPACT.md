# 奶茶三类原料与订单提示变更影响

版本 v0.2｜待 Review。用户确认所有难度只用茶、奶、小料三类，取消甜度和冰量，品种须为百鬼夜市原创幻想内容；工作区茶、奶各最多可见 3 格，小料最多 6 格。顾客订单气泡只显示目标成品奶茶图，不显示原料组合。格数是**显示容量上限**，不代表初始全部开放或每档品种数量已定。

| 受影响范围 | 后续处理 |
|---|---|
| 已批 MG01 Product v0.1 | 旧中等加甜度、困难加冰量、五维和现实配方不再作为新设计输入；需在新版正式规格中确定三类品种与开放节点、提示呈现及验收。旧版保留审批历史。 |
| 人工源表、字段说明、生成器 | 旧 SWEET/ICE 维度、配方引用、`recipe_dims=3/4/5/5/5` 与现实名称需评估替换和迁移；本轮不改现行源、归档、运行配置或生成器。稳定 ID 不改义复用。 |
| U05 客户端与 QA | 旧五维选料、配方提示及现实内容要在新规格批准后改为三类并重测各档配方池、纠错、计时、结果和回归；既有运行测试不能证明新版通过。 |
| UI 与 Art | 工作区中段按茶 3、奶 3、小料 6 格容量设计；顾客在远侧柜台上方，气泡仅成品图，近侧杯子点击合成。独立查看配方入口保留；简单档既有完整提示如何在气泡外呈现、展开状态与实际画面由 UI 定义。Art 概念可探索幻想内容，但候选名不构成正式资源。 |
| Tech／Server／QA | 评估旧字段废止、跨端配置、存档与判定兼容；按获批新版契约实施和验证。本轮不指定 API 或迁移实现。 |

保留当前店铺蓝瓦、木框、布帘、灯笼、悬杯装饰与非像素插画基线，不复制外部参考素材。一次处理一杯订单、交对后下一单；整局仍为原已批三杯目标，不能从“一单一杯”推成一局一杯。五档、简单不限时／中等起限时、原经验奖励、累计熟练度与解锁机制不在本次修改范围；新三类难度的秒数与完成性仍需后续验证。
