## 2. 受影响角色与重审范围

| 角色 | 后续需形成或核对的 Artifact | 门禁与主要风险 |

| Art | 六店视觉锚点、各异牌匾与位置、两处屋顶大 LOGO 去除、来源/许可、多图层母版、正式制作方案、六店成品及切片/同尺度重组 | 正式图片方案先获用户批准；首图前 Art/Tech 同批签认；实际切片效果再次送用户批准。附件不能直接裁成六店正式资源。 |
| UI | U03 入口、单店容器、前后或直接选择控件、当前身份与不可用反馈、小视口可读性 | UI 规格及适用视觉稿按专业流程审批。必须与 U01、可能获批的 U02 导航整合，不遮住牌匾。 |

| QA | 六店×牌匾、两处屋顶、单店状态、快切/循环/重入、小视口、U01 与适用 U02 回归 | 基于批准 TEST_PLAN 和实际运行环境判断；参考静图或代码路径不能代替运行通过。 |
| Server/VFX | 本版不要求服务端或新特效 | 如评审发现真实依赖，提交 Agent Request 由 Master 判断；不静默扩范围。 |

## 3. 当前工作区与审批事实

`apps/client/assets/UnitSampleGallery.ts` 当前仍只显示 U01 四层场景入口，并未包含 U02 或 U03。该文件属于 Client 工作区，Product 本轮不修改；工作区状态需由 Client/Tech 在各自任务核对。U03 参考附件是只读副本，不属于已批准正式美术资源。旧产品、美术与菜单的已批版本和正在评审的 U02 均保留独立版本链。

本版将初始店设为 01 奶茶店、六项按第一街编号顺序循环、返回再进入重置到 01，是为形成可验收稿的低风险产品约定；提交用户审批时应连同本版明确呈现。若用户要求随机首店、其他排序、同时展示多店或加入动态玩法，需修订产品范围及对应专业评审，不能由下游自行解释。
