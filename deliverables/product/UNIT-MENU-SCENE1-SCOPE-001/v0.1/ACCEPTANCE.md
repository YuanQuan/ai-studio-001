# 单元示例1｜产品验收条件增量 v0.1

任务：`UNIT-MENU-SCENE1-SCOPE-001`，与 `PRODUCT_DELTA.md` 同版。下列是**未来正式资源和 Creator 运行**的判定标准，不是本产品稿的运行测试结果。`UNIT-MENU-PRODUCT-001 v0.2` 中非本次冲突的七项范围、资源复用及其他单元条件保留。旧 A03、B01、B05、B08 涉及第1项固定/可切换边界的语句，待本稿获批后按本表新编号执行；旧稿仍保留历史。

| 编号 | 可观察的通过条件 | 最低证据 |
|---|---|---|
| S01 版本与竖屏 | 示例1运行画面引用获批的当前四层 PSD 对应正式导出，图层顺序正确；运行视口为竖屏，至少覆盖 720×1280 设计比例及一个不同的真实目标竖屏比例 | 源/导出哈希与资源引用、Art/Tech 版本签认、Creator 和目标设备截图 |
| S02 首帧语义 | 初始镜头以桥区域为中心且固定景物完整，允许看见画中树、右侧灯廊、纸船/烛光；不出现尚未加入的店铺、孟桃、顾客、板凳或第4项**独立可切换对象**。不要求首帧同时看见月亮 | 统一初始状态截图、场景节点/资源清单；第4项独立对象可见性检查 |
| S03 四层视差 | 相同一段水平拖动中，从前到后四层相对于初始状态的可见水平移动量为 `1:1:0.8:0.3`；两近景同步，远山和天空依次较慢；无图层互换、错帧或突跳 | Creator 同一拖动路径的分层位置记录及前/中/后帧录屏；Tech 说明像素容差与测量方法 |
| S04 操作与边界 | 鼠标与目标设备触控可左右拖动，松手后停在合法区域；中心、左右极限、连续反向拖动及各批准倍率下，画面四周不露白、黑底、透明底或未制作区域，边界不抖动 | Creator 与目标设备录屏，覆盖最小/最大倍率和左右端；Art 同尺度重组视觉复核 |
| S05 缩放 | 有明确放大、缩小操作；在 Tech/Client 提交并获批的倍率上下限内，画面变化可辨、四层同尺度且保持视差层序；最小倍率仍铺满竖屏。`1.00–1.80×` 只是隔离预览候选，不据此判正式 PASS | 获批倍率/适配规格、Creator 操作录屏、至少两种竖屏比例边界截图与目标机触控记录 |
| S06 重置与 UI | 拖动/缩放后按重置、离开再进入均回同一桥居中位置与初始倍率；操作 Lab 按钮/滑杆不误拖场景，场景拖动不误触控件 | 重置前后叠图、跨入口录屏、鼠标和触控交互记录 |
| S07 固定/可切换区分 | Art 清单清楚标出本四层画中固定树/灯廊/纸船等，以及未来第4项独立对象；第4项关闭对象时独立对象和特效退出，但第1项固定景物保持不变，不能出现误称“全场景同类物已隐藏” | 资产 ID/层级清单、未来第4项开关录屏与前后截图；第4项未制作前标 `NOT_TESTED` |
| S08 组合同源 | 未来第7项引用第1项同一获批四层底板与镜头规则；移除新增对象后回到四层固定场景，无另制底板、重复树/灯、额外纸船或错误遮挡 | 稳定资源引用/哈希对照、独立与组合入口同机截图、遮挡取证；第7项未制作前标 `NOT_TESTED` |
| S09 资源门禁与改图 | 正式导出前有参考来源/许可、Art/Tech 切图及同尺度重组 Review 和用户对该具体版本的审批；若需修边、拆物、补画或改构图，修改前已向用户给出图层、区域、原因和效果差异，修订后重新审阅 | 版本链、源图/PSD/导出对照、审阅与用户审批记录；未改图时以原图哈希证明保持原样 |

网页隔离预览和 `geometry_report.json` 仅支持提出 S03–S05 的候选范围，不能让上述 Creator、目标设备、授权、Art/Tech/QA 项目自动变成 `PASS`。S07/S08 属后续暂缓项目接口验收，不要求在本次单元1制作时伪造运行证据。技术测量精度、目标设备清单及性能阈值交 Tech/QA 正式制定，Product 只锁定玩家可观察的比例和结果。
