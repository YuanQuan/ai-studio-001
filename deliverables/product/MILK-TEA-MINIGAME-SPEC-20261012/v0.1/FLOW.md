# 奶茶小游戏单局与解锁流程

版本 v0.1。标记 `PROPOSED` 的分支等待本版用户审批。

## 进入与单局

1. 店铺入口展示五档及永久解锁状态。初始仅简单可选；锁定档展示上一档通关和各启用条件的未达成项。入口呈现由 UI 细化。
2. 玩家选择已解锁档，点击“开始制作”开始新局并启动限时档计时（`PROPOSED`）。此时按选档和当前熟练度阶段锁定本局目标杯数、时间、配方池与备选数量，通关经验引起的阶段变化下局才生效。简单无倒计时。
3. 展示当前单饮品要求。简单同时显示完整配方；中等以上允许随时打开配方，查看时继续计时（`PROPOSED`）。杯间过渡、切后台和退出确认期间也继续计时，不设暂停（`PROPOSED`）。
4. 玩家逐维点击一项选料，交杯前可撤销／更换。维度尚未选齐时确认按钮不可提交（`PROPOSED`）。
5. 确认交杯：正确则完成杯数加一；未达到目标则清空本杯选择并展示下一单。错误则杯数不变，清空选料后重做当前单；限时继续。每单正确项始终包含在显示的备选池中（`PROPOSED` 清空与选池约束）。
6. 达到目标杯数通关并仅结算一次熟练度经验。时间先归零且尚未过关则失败（`PROPOSED`）。
7. 结果页可返回店铺或重试新局（`PROPOSED`）。中途主动退出为未通关，无经验；半局不恢复（`PROPOSED`）。

## 状态与竞争边界

| 状态 | 可接受动作 | 迁移 |
|---|---|---|
| 档位选择 | 选已解锁档 | 新局、当前订单 |
| 当前订单 | 选料、撤销、查配方、确认、退出 | 正确→下一单或通关；错误→当前单重做；超时→失败 |
| 通关 | 返回、开启新局 | 发经验一次，刷新通关与解锁记录 |
| 失败／退出 | 返回、开启新局 | 不发经验 |

`PROPOSED`：交杯动作的接受时间严格早于本局截止时间才有效；等于或晚于截止即失败。重复确认、结果页重入或重试请求不得重复结算。时间记录方式和存档权威端由 Tech Lead 评审。

## 难度解锁

初始简单永久可选。每次已结算通关或外部条件改变后，对下一档检查：上一档至少通关一次，并且启用的熟练度、店长等级、魂数、魄数门槛全部满足；关闭的条件忽略。全部可选条件关闭时只检查上一档通关。首次满足即永久解锁，不消耗熟练度经验，条件之后变化不回锁。`PROPOSED`：仅逐档解锁，达到更高门槛但尚未通关上一档时不跳档。
