# 孟桃奶茶店单元｜产品验收条件 v0.1

状态：`USER_REVIEW`（专业评审通过，待用户批准），与 `PRODUCT_SPEC.md` 同版。以下条件是本单元后续实现的产品验收口径；当前仅检查规格覆盖，不声称资产或运行效果已经通过。

| 编号 | 后续可验证条件 | 证据与责任环节 |
|---|---|---|
| P01 | 场景中能明确识别一家奶茶店及在其工作位的孟桃；店铺和店长可分别替换、迭代，不因调整一方必须重做另一方 | Art 资产清单、Tech 资源依赖说明、Creator 场景与 QA 截图 |
| P02 | 店铺和孟桃仅按获批的实际使用视角呈现；不以缺少四方向判失败，也不把单视角图称为旅客四方向资产 | Art 视角稿、资产清单与 QA 核对 |
| P03 | 孟桃的常态与工作表现能辨认；工作表现由演示控制触发，至少一次完整进入并返回常态，重复操作后无动作或特效残留 | Creator 录屏、状态日志与 QA 用例 |
| P04 | 店铺至少一处可动部分或场景反馈与工作表现同步；凡被定为骨骼动画对象，分别满足单对象单图集方案并有 Art 与 Tech Lead 出图前共同确认记录 | Art 源文件／图集、动画预览、技术评审记录 |
| P05 | 工作表现及 VFX 不显示具体饮品、订单完成、价格、收益、奖励或未经批准的角色能力；无顾客仍可独立演示 | 运行录屏、UI 文案清单与 QA 检查 |
| P06 | 共用界面准确显示“奶茶店”与“孟桃”的关联；演示控制与诊断信息有明确隔离；演示入口和主体游戏入口引用同一版共用组件 | UI 规格、组件引用关系、双入口截图 |
| P07 | VFX 有明确触发与结束点，动作结束或重置后无残留；具体视觉、时序和性能指标依后续获批 VFX 与技术规格检查 | VFX 规格、关键帧／录屏、QA 结果 |
| P08 | 正式店铺、孟桃、UI 和 VFX 均为本轮新制作源产物；无旧 Demo 图片／Prefab／UI 图稿的生产性引用；图片与字体来源、许可和出图前检查可追溯 | 资产来源记录、许可记录、依赖扫描及 Art/UI Review |
| P09 | 修改一个获批源产物后，独立单元和主体游戏集成入口都能看到同版结果，且身份、动作含义及共用 UI 细节一致 | Client 实现报告、双入口对照证据与 QA 回归 |
| P10 | 商品、价格、制作时长、收益、开店／升级、顾客接待、孟桃成长与旅客四方向均未被本单元偷定义或假验收 | 产品范围核对、各专业规格及 QA 显式未测试项 |
| P11 | 在本版获用户批准后，Art 概念说明逐项回应“孟婆外孙女、叛逆甜品控、不想继承汤铺、想开自己的奶茶店”，角色与店铺视觉不违背四项约束；不以具体造型、对白、技能或商品冒充本版已批准内容 | Art 概念说明、角色／店铺概念稿及 Product／Art Review |

### 门禁说明

本版产品 Artifact 需先经专业 Review 和用户明确批准。P01–P11 是后续分角色验收条件，不替代 Art、UI、VFX、Tech、Client 和 QA 各自的正式交付与审批；`CP-UNIT-REUSE-001` 未获批前，同源工程契约仍需另行评审。
