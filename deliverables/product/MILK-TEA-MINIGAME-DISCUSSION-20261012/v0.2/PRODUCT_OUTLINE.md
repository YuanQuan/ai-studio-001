# 六店小游戏与奶茶玩法讨论总纲

版本 v0.2｜送审讨论稿。本版汇总截至 2026-10-12 已确认方向，供用户核对；完整 PRD、数值配置、资源和开发仍需后续分阶段审批。

## 六店范围与顺序

| 模块 | 店铺 | 当前玩法状态 |
|---|---|---|
| MG01 | 奶茶店 | 核心操作与下述规则已确认，细节待正式规格 |
| MG02 | 糖画摊 | 描线仅为候选 |
| MG03 | 炭烤摊 | 火候、翻面、调味仅为候选 |
| MG04 | 理发店 | 修剪造型仅为候选 |
| MG05 | 花灯铺 | 拼装或灯光解谜仅为候选 |
| MG06 | 投壶铺 | 方向与力度仅为候选 |

六店按上述顺序逐个讨论、确认后开发。六个游戏都开发简单、中等、困难、地狱、噩梦五档，初始只开放简单；简单不限时，中等起限时。各档随熟练度增长逐渐加难，六个游戏分别调参，调整 MG01 不改变其他游戏。MG02–MG06 仅继承已明确的六店共同规则，不继承 MG01 的订单与配方玩法。

## MG01 奶茶店当前闭环

玩家处理当前一杯订单，点击选料，确认后交杯；交对才出现下一单。正确完成规定数量的订单即通关。通关增加对应店长熟练度经验，已解锁难度可重复挑战并再次获得经验；失败或中途退出不给经验。具体杯数、时长、经验数值和失败／重试／返回流程尚待正式规格。规则速览及五档表见同版 `MILK_TEA_RULES.md`。

## 模块边界与关系

MG01–MG06 归属 M01 夜市经营的店铺互动。M02 店铺入口／解锁 → 小游戏 → 夜市经营反馈的具体输入输出待定义；M03 店长成长、M06 奖励／资源、M11 订单与顾客语义需做影响评估。熟练度、店长等级、魂魄等级作为不同条件，不能自行合并。入口、选档、进度、返回需在正式规格中定义，本稿不拟定 API 或字段，也不从未整版获批的 PRODUCT-001 v0.8 继承其他规则。

## 待正式规格解决

配方具体选项及内容、杯数与倒计时、五档和档内难度曲线及上限、经验与解锁门槛数值、可选解锁条件的组合关系及魂魄指标、失败／重试／保存／返回、奖励和经营反馈，均未确定。本稿不授权运行配置或代码。
