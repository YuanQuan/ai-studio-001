## 锚点判定

| 锚点 | 结果 | 实看依据 |
|---|---|---|
| G1 方向/剪影 | REVISE | 比旧版更向右且圆润，但近手遮面、两向同尺度可读性未验证。 |
| G2 走跑/柔尾 | REVISE | 两个关键姿差异不够，尾部趋向水平条带；没有 4–6 帧循环与接缝证据。 |

| G4 凳/坐姿 | REVISE | 空凳低矮无靠背的形态方向可保留；坐姿没有压座接触、遮挡关系或进稳离连续过程。 |
| G5 风格/权利/落地 | REVISE | 样张是新写源，但轮廓与体积完成度仍偏程序化；正式许可、图集、Creator/目标设备未测试。 |

## 技术与工具限制

本轮代码路径能保持统一画布、透明导出及可编辑源，但用 SVG 路径拼出角色姿势时，手与尾的形体、表情体积和逐帧一致性不足。继续靠增补程序路径做 23 帧，预计会扩大帧间造型误差。**当前实现方法没有通过视觉闸**；不把这解释为 SVG 格式或骨骼/序列帧路线在一般情况下不可用。

建议下一轮先在可编辑分层绘画工作流中完成原创正姿和姿势设定，再逐帧绘制。若改用 imagegen 作参考探索、绘画软件、分层位图或其他源格式，已越过本轮签认的 SVG+Node/sharp 范围，**新图前必须修订预案并重取 Art+Tech 签认**。用户旧参考权利未知，不裁图、描边、换色或沿旧 v0.1 SVG 微改。

### 下一版可执行源方案（待重新签认，尚未执行）

1. **工具与母版**：建议在核验版本与许可后使用 Krita 分层绘制，以原生 `.kra` 为可编辑母版。一个角色造型母版保存体块/线稿/暗面/表情分组；每个动作关键姿和后续逐帧保留独立原生源或可单独编辑的帧组，统一 256×224 画布、锚点、透明边和座面接触点。独立板凳另建 320×160 分层母版，保留后片与前沿。若采用别的绘画工具，须在新预案明确原生文件格式及可编辑分层、逐帧可追溯能力。
2. **先造型后动画**：先原创绘制面朝右的圆润侧向正姿，定义面部、近远手、两股以上宽软拖尾的可复用比例与线宽；再画走/跑/喜/悲/坐五态与空凳高质量关键姿。实际显示尺度和水平翻转预览先过 G1–G5，坐姿需和板凳后片/前沿片合成验接触。通过后制作移动/跑动各约 4–6 帧及其他态的进入/保持/退出，逐帧复核轮廓、体量、锚点和末首循环。
3. **导出与证据**：从逐帧原生源导出单方向透明 PNG、各态接触表、alpha bbox、源/帧/图集哈希映射；只在目标图尺寸和页数经过 Tech 真实预算后打 atlas。审阅板并排概念、退回图、新原创左右向实际显示尺度五态和无靠背凳，附走跑循环视频或逐帧播放记录、坐姿进稳离和遮挡截图。
4. **双签与扩展顺序**：新工具/`.kra` 源格式、笔刷/字体/参考许可、统一画布、候选图集尺寸与合批策略、内存预算、目标设备写入修订 `PREFLIGHT_PLAN`；Art+Tech 在下一张图生成/导出**之前**先签仅含五态与凳的样张范围。样张视觉全通过后，Tech 再基于真实帧测算并签全量逐帧/atlas；Creator 与目标机的双入口同源检查另留截图和日志。
