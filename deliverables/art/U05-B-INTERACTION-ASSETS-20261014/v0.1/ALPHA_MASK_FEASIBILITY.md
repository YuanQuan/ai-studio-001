# 原语义层 Alpha 补底可行性（只读，不出第4候选）

结论：**原图层 alpha 可定位旧角色/杯的主体，却不能单独作为这批残影的精细修补 Mask；“原 alpha + 必要小 halo”目前不能替代 GEN-03 的新方法。** 这不否定同源 donor 已有干净窗口与台面，也不声称图层源坐标错位；失效点是原切层 alpha 未包含遗留在 `STATIC_BARE` 上的外扩半透明轮廓。若要给它足够大的统一 halo，就会把自然夜街或木纹纳入复制范围，无法依“只改旧物像素”的获批标准直接出图。以下均为读源计算，没有重写图、Mask 或 PSD。

## 按已签 ROI 与失败手描位置的覆盖计算

计算以 alpha `>0`，ghost 与 bubble 取并集、cup back/front 取并集；halo 是相应全层并集的半径为 4/8/12/20/32 源像素的形态扩张，最后裁入已签三个诊断 ROI。已失败 `source/mask_residual_confirmed.png` 的 1600 像素只作为原旧物轮廓的**位置证据**，不能再作为生产 Mask；它们是 Art 在原旧影上手描、再与 donor 4–11 差求交得到的已确认修补位置，且本 Mask 因漏边已被判失败。

|---|---:|---|---|

将当前 MANUAL-01 图对干净 donor 作纯数值比较时，窗口 ROI 的差≥4有 17,510px，其中绝大多数也可能是自然街景，**不能**将这17,510px全部解释为幽灵。更能说明回贴风险的是阈值无关的 RGB 非零差：窗口原 alpha 内仅 133px不同于 donor，32px halo 内升至 14,379px；rim 原 alpha 内 4px不同，8px halo 内升至 519px；玻璃原 alpha 内 275px不同，12px halo 内升至 674px。把这些像素全按 donor 复制会混入尚未逐像素辨明的街景/木纹差异；即使保护 Mask 外能做到零差异，Mask **内部**也未证明只包含旧物。弱差旧影还有越出原 alpha 的事实，不能靠不设阈值直接补齐。

## 与 GEN-03 的选择关系

| 路线 | 生成调用与来源 | 已测风险 | 当前判断 |
|---|---|---|
| 原层 alpha + 小 halo 后确定性复制 donor | 0 次；来源/坐标可追溯 | 小 halo 明确漏旧幽灵外沿和杯 rim；足量 halo 会覆盖窗口约81%、rim约99.5%、玻璃100%诊断区，难以把自然差异与旧物隔开。 | **不宜直接生产**，需新的对象级人工边界证据才可能成为另一候选方法；不能默认为获准的“简单修补”。 |
| GEN-03 局部生成补底 + 新签认对象 Mask 回贴 | 最多窗口1次、台面1次；同源原 Crop/donor，其他像素零差异 | 生成补洞存在材质匹配与局部边缘风险；仍需能分离旧物的完整细分 Mask，无法保证首图通过。 | 保持为待用户决定的下一轮工具方法提案；先核可做 Mask、同批 Art/Tech 复签，失败即停。 |

两条路线都涉及同一净底问题的额外唯一轮次；**无论最终选哪条，都需用户明确批准轮次 `2→3` 的例外**，不能借“0生成”绕过轮次停止线。此文件只论技术可行性，不构成新出图授权；本任务仍 `BLOCKED`、Art 自查仍 `REVISE`、无 FULL/PSD/Gate2。
