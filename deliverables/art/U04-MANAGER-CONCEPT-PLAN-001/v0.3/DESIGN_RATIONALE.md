# 非人 Q 版造型设计理由 v0.3

用户要看到鬼怪店长本身，而非穿戏服的人。故每人先由物种主形决定剪影：孟桃家族鬼魂、阿棠糖滴、阿炭炭团、阿角牛怪豆形、阿灯纸灯、小锦鲤鱼。高矮差异让六店长在店前小尺度也能先被识别，暖黄灯芯、琥珀糖滴、暗炭火芯等只用于传达店铺与物种，不额外增加玩法或职业。

已批 Product 的成长语义仍落在可读部位：孟桃耳叶饰件和浮态承载直率到文静；阿棠糖丝手承载回避到主动展示；阿炭的虚构瘦弱／健硕转译为炭体由窄弱到饱满与火芯转稳；阿角的油腻贴头到挺立发型留在两角之间；阿灯的停顿只能静态暗示，完整记忆线由对白验；小锦用鱼脸厚镜多圈纹到无可见眼镜表达视力线，隐形镜片仍只在文档。各人的身份、偏好和经营能力从 0 魂起就成立，外形变化不对人格作高低评价。

职业物各只保留一个主读点，人物图禁止文字与品牌。方案获批后从新非人图源开始生成，同批做图、板和 PSD；旧人形资产是方向退回的历史，不可修饰后冒充新版。
