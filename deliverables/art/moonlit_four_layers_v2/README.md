# 月夜景观四层分离 v2

本版本按用户 2026-10-03 最新划分制作，替代之前的分层方案。所有图层画布均为 2172×724，位置均为 (0,0)，普通透明度合成，不缩放。

从底到顶：

1. `01_sky.png`：月亮、云彩、星星与蓝天背景。完整不透明底图。
2. `02_mountains_buildings.png`：山峦、远方建筑与远景雾林。上方透明，遮挡处补绘并延伸至底部。
3. `03_ground_trees_corridor.png`：地面、树木、灌木、右侧走廊和阶梯。背景与叶间空隙透明，地面补绘延伸至底部。
4. `04_bridge_railings_foreground.png`：桥、栏杆、岸墙及前方水面、浮灯、反射、近处石头与植物。保留桥洞中的水面，其他上方区域透明。

`moonlit_four_layers.ora` 是四层可编辑母版，Krita、GIMP 可直接打开。也可将四张 PNG 按上述顺序导入其他绘图软件，保持原始尺寸、100% 图层透明度和 Normal 混合模式。

`merged_preview.png` 是四层的实际合成结果；`source_original.png` 保留输入原图；`foreground_alpha_check.png` 是前景在灰底上的透明度检查图，不属于四层资源。

制作采用内置 imagegen 分层与遮挡补绘，再以原图校准可见像素、画布及透明边缘。细碎树叶与光晕使用半透明边缘。补绘内容是根据周围元素推断的延伸，并非原图中不存在的可恢复信息。

实际合成与输入图逐像素比较，RGB 通道最大差值为 5/255，平均绝对差值为 0.123/255（独立用 Pillow 标准透明合成复核）。构图及可见主体保持原图；透明细节存在轻微差异。本交付未记录为正式游戏资产批准或接入版本。

## 提示词要点

工具：内置 `image_gen`，未使用外部 API。

- 天空：只保留原始可见天空、原位置月亮与穿月薄云、星星；移除其余物体，依照周围夜空连续补到底部。
- 山景：原位置保留山峦、远方建筑、瀑布与雾林；移除近景树木、地面、走廊、桥、栏杆和水，补足遮挡区域并将山脚雾林延伸到底部；天空透明。
- 中景：保留地面、柳树、灌木、上方垂柳和右侧走廊、灯笼、阶梯；移除桥与栏杆、水及远景；铺地补齐至底部；叶间与建筑开口透明。
- 前景：保留原位置原形状的桥与桥灯、前方栏杆岸墙、水面及浮灯反射、近处石植；地面、树、走廊、山景天空透明；保留软暖光半透明，清除背景色边与重复灯。
