# U03 六店视觉锚点 v0.1

状态：Gate1 方案待审批；以下是将来实图必须逐项对照的基线，不是现成资源验收。参考：新附件 `deliverables/product/U03-SHOP-SCOPE-001/v0.1/reference/user_shop_reference.png`；旧 `ART-DIRECTION-FIRST-STREET-001 v0.4` 仅限旧牌匾形式参考。

| 锚点 | 必须保持 | 可调整及重批边界 |
|---|---|---|
| 画风/视角 | 平滑非像素二维、近似平视的正面略见侧深度、可爱中式夜市；轮廓清晰且阴影简洁 | 每店局部细节可整理；像素化、换透视或显著加宽店体须重新审批 |
| 材质/光色 | 木棕、蓝灰瓦、布或竹的类别真实；深冷蓝环境衬暖橙灯，营业开口最亮 | 单店灯位可避开牌匾；改变冷暖主次或换现代材质须重批 |
| 构图/尺度 | 六店用同一审阅视窗与同一地面脚线，单次只呈一店，牌匾和完整轮廓均在安全区内 | 瓦房宽于摊车、各自原有比例保留；具体像素及UI留白由后续同批预签，不能靠拉伸统一宽度 |
| 背景/遮挡 | 安静的夜色和必要接地阴影可共用；前件、店体、牌匾层深正确，无邻店、殿或桥 | 小面积近景可服务店型；完整街景、两桥、阎罗殿、相邻店进入任一图须产品重审 |
| 字与身份 | 六块牌匾不同且可读，文字与六身份一一对应；不靠屋顶大杯/大剪刀识别 | 字形细节待授权字体或原创字确认；变更正式牌匾字义、去掉其一须重批 |
| 状态 | 本批静态外观，暖灯以静态明暗表达 | 动画、经营状态、NPC 或特效新增须另立任务 |

## 每店必须辨认的主体

| 店 | 轮廓与材质 | 保留的经营识别物 | 禁止/补画与遮挡要点 |
|---|---|---|---|
| 01 奶茶 | 蓝灰瓦顶、木质方正窗口、浅色窗棚；房身保持新附件未加宽比例 | 饮品瓶罐、冲泡设备、服务开口 | 无屋顶大杯/吸管；补全瓦行、正脊、檐口背光与 alpha 边；牌匾不得遮工作窗 |
| 02 糖画 | 红伞顶、单轮车与轻盈竹木摊架 | 糖画造型和小制作台 | 伞缘与车轮分层；牌匾不可盖过糖画剪影或把摊车扩成瓦房 |
| 03 炭烤 | 斜拉红布棚、横向木炉台 | 炭烤食物和静态炉火暖光 | 布棚前后沿、烤台烟影分层；不自动纳入烟火动画 |
| 04 理发 | 蓝灰瓦顶、木屋门面与局部蓝白布帘 | 镜台、座椅、理发柱 | 无屋顶大剪刀；补全瓦面、正脊、暖边光与 alpha 边；横额不遮镜台 |
| 05 花灯 | 开敞竹木架体、红暖灯点 | 莲灯、鱼灯、兔灯三类轮廓 | 灯前后与牌匾挂件分层，牌匾不吞掉中心灯群 |
| 06 投壶 | 简洁竹木横架、无遮挡的投壶摊台 | 壶、箭束与投掷区 | 牌匾置侧方或悬挂，不能遮壶口与箭线；不增加小游戏反馈 |

实图检查必须附相同审阅视窗、相同地线/投影比例下的六店对照、奶茶和理发屋顶近景、牌匾可读截图，以及每个锚点的 `PASS/REVISE/NOT_TESTED`。实际目标小视口由 UI/Tech 确定后复验；Gate1 只评方案覆盖度。

审阅矩阵至少覆盖现设计比例 `720×1280` 与较小的 `390×844` 模拟竖屏：六店逐项完整图、同尺度并排图、两店屋顶局部图。各项记录真实可见视口/DPR、安全区、店体与牌匾投影像素、文字可辨结论和是否受 UI 遮挡；首图预签确定阈值，当前全部实图项 `NOT_TESTED`。同源资源未来进入主体镜头时另做实际尺度复核。
