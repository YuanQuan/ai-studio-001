## 2. 美术分层与对象排除

从远到近：`UB_SKY`（夜蓝渐层、月、少量云）→ `UB_DISTANCE`（低对比山云剪影）→ `UB_WATER`（前河与桥下支流，河面连续）→ `UB_BANK`（岸墙/水线）→ `UB_GROUND`（两岸街面，桥中央留水口）→ `UB_BRIDGE_BACK`（桥拱和后坡/后栏）→ `UB_RAIL_BACK`（远侧短栏）→ **将来独立对象/顾客足点层** → `UB_BRIDGE_FRONT`（拱前缘/近桥栏）→ `UB_RAIL_FRONT`（近水栏）。实际 Client 渲染可根据角色通过桥前/上坡/桥后切换前后片，不用单张全桥 Sprite 常压住角色。

世界布局草案：天空 `y=0..460`，山线约 `y=240..510`；石街主通路 `y=490..825`；前景河自 `y≈835` 连续至 `1024`，岸墙/栏杆沿 `y≈780..860`；桥两坡约 `x=1280..1792`、`y≈450..805`，桥下支流位于中央缺口并连前河。桥两侧店铺待后续独立加入，街中央从两端到桥坡保留行走带；栏杆休息带留空给未来独立板凳，不烘进此层。月云、远山不画成可切换树冠或灯笼。岸墙与拱洞需实际 PNG alpha 空口，不以深色实心块伪装透水。

## 4. 竖屏镜头草算与不露边条件

现有 Creator 工程为 `720×1280` 设计视窗，底板世界图 `3072×1024`。以“屏幕 px / 世界源 px”的示意缩放 `s` 计算，竖屏要完全覆盖视窗高度，`s_min=max(720/3072,1280/1024)=1.25`；此时可见世界宽 `720/1.25=576`、高 `1024`，镜头中心 x 合法 `[288,2784]`、y 固定 `512`。候选初始 `s=1.35`，缩小下限 `1.25`、放大上限 `1.8`，中心 x 每个 zoom 依 `visibleWidth/2` 收紧合法区间；reset 回中心 x=1536、y=512、s=1.35。`s=1.8` 时可见约 `400×711` 世界 px；缩放有可见差别。UI 操作与世界拖动的事件隔离由 Client 实现。本草算不替代真实安全区/DPR/各平台纵横比取证，若铺图边界露白或桥/水断裂，调整裁切/合法镜头区再经 Art/Tech Review，不能拉伸用户参考或私改平视镜头。

导出后预览至少包括全景 `preview/empty_scene.png`、前后片分解 `preview/layer_occlusion.png` 与可选的左端/中央/右端竖屏最小/初始/最大镜头裁图。须实查所有世界像素边、桥下水与河连接、地砖/水纹/栏杆复用接缝、alpha 透明口和分层支点。Creator 实际拖缩、目标机可读性/性能、两入口同 UUID 仍 `NOT_TESTED`；空景审阅图不是一张运行时背景贴图。

本批任何正式 SVG/PNG 输出前先取得 Art/Tech 双签。若实际纹理数/边长、画布比例、镜头下限、层语义、工具版本或授权输入变化，暂停出图并重新双签；完成后按实际资源和目标设备再评审。
