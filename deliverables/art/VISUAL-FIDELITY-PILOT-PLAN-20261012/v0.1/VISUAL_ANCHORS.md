# 阿棠 AT_S0 冻结锚点与比较边界 v0.1

本文件冻结阿棠 AT_S0 已获 Gate2 批准的人形对话资源，供独立 pilot 比较；`project/DECISIONS.md` 的 `DEC-U04-HUMAN-REVISION-20261010` 明确人形为当前适用方向。此样本的锚点不能代替其他角色的逐一验证，也不证明身体网格骨骼能力；本批新嘴形和动作范围仍待 Gate1 批准。

基准分三层，不能互相冒充：①上游完整原图 1024×1536 RGBA，哈希见 `ART_BRIEF.md`；②当前 Gate2 获批的微笑态 PSD 与 `base + face_smile + front_hair` 交付层，准确路径、哈希、顺序及位置见 `U04-DIALOGUE-LAYERED-ASSET-001/v0.1/LAYER_EXPORT_MAP.json` 的 `AT_S0`；③游戏中的实际显示画面尚无本任务运行证据。当前 base 的源裁切框为 `[247,0,750,1024]`，输出 503×1024；脸片框 `[380,180,636,436]`、支点 `[508,308]`、相对 base 偏移 `[133,180]`；前发框 `[395,177,570,252]`、偏移 `[148,177]`。只对同一裁切和同一画布作静态零差判断。

必须保持：暖棕卷发外轮廓与前额刘海、侧边浅色花饰和垂饰、浅棕/奶油色衣装、双手持物的可见轮廓、脸宽和五官关系、前发在五官前的叠放、人物整体暖色明暗和柔软二维笔触；不凭图像推断持物用途。参考覆盖层必须关闭；重新组合只能使用真实交付层。对现有拆层能力的声明限于眉/眼/嘴与前发栅格附件；底图内部的手、身体、隐藏皮肤并非独立可动画源。

唯一计划修改区是微笑态嘴层在 256×256 脸片内的嘴形及最小相邻清理遮罩，正式制作前在该脸片上保存精确像素遮罩和 bbox。遮罩外（含其他眉、眼、头发、服装）要求归一后可见 RGB 与 alpha 均零差；嘴区可随 Gate1 批准的短说话动作改变，仍须守住笔触、肤色、阴影与前发关系。若嘴角阴影需扩大，先登记新遮罩并查批准范围；不得用扩大遮罩掩盖漂移。

骨骼动态另有独立动作区：仅现有 smile 眉附件允许在原坐标上下 2 像素以内短暂移动，前发仍是独立附件但位置不动。动态比较逐帧以该附件变换后的包围框为允许区，未影响区零差；首末基准姿态全画面须回到当前获批 smile。此动作是待 Gate1 批准的新范围，不倒写历史 Gate2。

比较配置预签为：两对象均以同一锁定版本解码器读取为 8-bit RGBA，ICC 存在时统一转换至 sRGB；直通/预乘 alpha 先归一为直通 alpha；静态源坐标 1:1、禁止重采样、普通 source-over、背景 `#16202f`，逐项核透明度和指定背景可见 RGB。记录解码器实际版本、ICC 存在性、遮罩版本和输入哈希。若 PSD 合成只有 RGB，alpha 必须与可追溯 PNG 层合成比较，不拿 PSD RGB 冒充 alpha 依据。运行对照另锁 Cocos Creator 3.8.8 的实际构建、设备、分辨率、采样/压缩与显示尺度，由 Tech/Client 预签允许误差；缺这些条件时运行结论为 `NOT_TESTED`。

已有只读审计 `deliverables/master/VISUAL-FIDELITY-COMPUTE-20261012/v0.1/EXISTING_RESOURCE_READONLY_AUDIT.json` 只报告裁切框内 PSD 合成与切片重组 RGB 零差；框外 91,757 像素不同、PSD 合成无 alpha，原概念和运行均 `NOT_TESTED`。这是前置线索，不是本批的还原 PASS。
