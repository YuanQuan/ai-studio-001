# 出图前 Art / Tech 联合预检与图集草排 v0.2

本稿是逐次出图前必须填写的检查模板与候选排布法，**尚无真实分层源、帧图、骨骼导出、贴图或设备测量**。旧 v0.1 对幽灵的 Skeleton/单页/1024²建议作废；旧 Tech 对概念生成的签字不等于本轮正式资源放行。Product v0.2 D01/D02 要求每次正式图片输出前 Art 与 Tech Lead 共同确认，不能用一次总签代替后来新增对象或尺寸变更。

## 逐批双签字段

每批记录：批次/Task/版本/资产 ID、用途与七菜单对应项、可编辑母版路径、原创绘制责任人和工具版本、图片/字体/制作工具许可、参考来源与相似风险结论、原始画布和目标设备可读尺寸、支点/挂点、透明 alpha/边缘、动作状态、极限包围盒、候选材质和图集页数、纹理面积/留白/padding、压缩后内存预估、同屏最大数量、批次/Draw Call 假设、回退方案、Art 姓名/日期、Tech Lead 姓名/日期、各自结论及证据路径。无具体签字或缺授权时状态为 `BLOCKED`，不可出正式图。输出后再填真实贴图、导入、设备截帧与性能结果；实测不符须重排/重签。

## 分流草排

| 资产 | 出图前须量的内容 | 草排方法及禁止误判 |
|---|---|---|
| `UG_GHOST_01` | 各状态逐帧统一画布、alpha bbox、原点、循环末/首、左右翻转、坐姿接触；实际全帧数量 | 先按需要循环的移动/跑动各约 4–6 帧做原创草帧，情绪与进稳离另算；对每帧真实透明边/padding 打包；按材质/批次/纹理内存和设备限制确定**实际页数**，不硬限一页，也不把概念 1536×1024 板当页 |
| `MT_CHAR_01` | 身体、手、头发、腰牌、杯等附件原始 bbox，待机与工作极限 pose | 一个骨骼对象附件排一页；1024²若被引用仅为历史草排起点，实际尺寸由双签；“孟”字小屏检查 |
| `MT_SHOP_MOTION_01` | 帘片原始边界、挂点与摆幅极值 | 一个对象附件一页；不能把静态整店或环境光晕塞入帘页 |
| `UE_TREE_01` | 稳定树干/根、枝叶组及左右摆极限 union bbox | 一个骨骼对象附件一页；重用叶团源件，不能按展示板面积估算 |
| `UE_GRASS_01` | 花头、茎、叶和摆幅极值 | 一个骨骼对象附件一页；整簇作为一对象候选 |
| `UE_LANTERN_01` | 固定环、灯体/穗摆幅与灯光独立范围 | 一个骨骼对象附件一页，柔光/世界投影由 VFX 分离；灯图不可烘固定受光方向 |
| 背景、店身、板凳 | 各可编辑层和前后遮挡片尺寸、重复材料与同屏数量 | 静态图按实际采样/材质安排，不因“同一个源”假设一定同页或一次 Draw Call |

对每对象先列附件或逐帧的 `(width,height,alpha_bbox,pivot,padding)`，再量动画极限姿态 union bbox 与可见像素面积，做真实打包图和目标设备内存估算。真实 draw batch 还受材质、混合、渲染顺序、遮挡与 VFX 影响；**单页不等于一 Draw Call**。横向长街在当前 Creator 竖屏 720×1280 设置下需验证镜头裁切/缩放、贴图采样、牌匾小字和顾客辨识；具体输出比例由 Tech 审批。

出图后 Art 检查轮廓/颜色/相似性/遮挡与全部左右帧，Tech 检查实际导入、贴图页、材质、运行批次、CPU/GPU/内存与工具版本。正式资源只有在用户批准相关方案、逐批双签、实际导出与 Creator/设备通过后才能标 `INTEGRABLE`；目前全部记录为 `NOT_TESTED`，无生产放行签字。
