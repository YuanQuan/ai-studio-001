# 场景分层、遮挡与支点方案 v0.2

本方案只定义美术拆层和需拍证的位置；真实 Creator 排序算法、世界坐标、尺寸由获批 Tech 设计和实际导出确定。选定参考为未加宽近正面横街。空底板与组合入口必须引用同一背景层，不能各画一张相似图。

## 从远到近的场景关系

`UB_SKY → UB_DISTANCE → UB_WATER/UB_GROUND → UB_BRIDGE_BACK/UB_RAIL_BACK → 可加入对象后片 → 角色/对象按地面支点 → 店前柜/凳前沿/桥前栏/近栏 → 独立光效及 UI`。这只是视觉语义顺序；同一角色走到桥坡、店前和栏杆附近时会改变具体遮挡关系，不能用一张全桥 Sprite 一刀切盖住所有位置。

| 检查位 | 美术交付要求 | 双入口取证 |
|---|---|---|
| 石拱桥两坡及桥口 | 拱洞留透水，桥体后/前片分离，桥坡可落角色底部参考点 | 顾客桥后、上坡、桥前与水口边缘，不悬空/穿桥栏 |
| 店后/前柜 | 奶茶店后架、店身与前柜独立；补绘柜台遮住部分与角色被遮部分 | 孟桃工作手/杯可读，身体与前柜交接稳定；幽灵经过店前无遮挡错位 |
| 板凳 | 凳板、腿与必要前沿片出自同一母版；凳底原点，左右座点在同一世界物体上 | 幽灵由左/右进座、坐稳、离座，尾部接触而不穿座面；移除凳安全退出 |
| 柳树/花草/灯笼 | 根/挂点固定；树冠、花头、灯体摆幅不越过不应遮挡的营业牌和顾客通路 | 每类单独开关，隐藏后其光/影与附属件全退，不带走其他对象 |
| 栏杆与岸边 | 远/近栏、桥边断口分组，桌椅若获批放栏杆休息带 | 顾客动线连续；前后栏遮挡不突然跳层 |

## 支点与包围盒记录

幽灵每帧统一透明画布与底部参考点 `ghostFoot`，状态内轮廓与原点波动须实际测量；翻转只作用帧显示节点，逻辑底点、世界座点、非镜像 UI、世界光影保持原世界方向。`BENCH_01` 以凳底中点作道具支点，`seatLeft/seatRight` 在板凳局部坐标；进稳离座必须通过两向实看，不把板凳画入角色帧。树以根、花草以土点、灯笼以挂环为静止支点。孟桃以脚点，店铺以基脚；每个对象正式源提交所有状态极限 alpha 包围盒及遮挡截图，不能拿整张概念图的外框代替。

固定远景可以有低饱和蓝色山林剪影，但不得出现与可切换棕干绿柳、花簇、灯笼同形的前景对象。空场景不预烘店、顾客、板凳、动态花树灯及其暖光斑。空间仍以宽通路为优先，桌凳靠栏杆带，桥两端和店前服务区留可通行空隙。实际摆位要在横向与当前竖屏 720×1280 视窗上验证；本稿不伪造像素坐标。
