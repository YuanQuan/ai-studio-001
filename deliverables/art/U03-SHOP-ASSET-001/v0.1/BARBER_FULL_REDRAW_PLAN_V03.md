# U03 04 理发店整体重绘方案 v0.3｜用户审批稿

本版替代未获批的局部重建 v0.2。用户已允许整体重绘。当前文件与尺寸示意仅用于方案审批；04 新图、新 PSD 和切片须在本版获用户批准且 Art/Tech 对同一批次预签后制作。

## 视觉目标和尺寸锚点

- 画布固定为透明 `1024×1024`，脚点固定 `(512,900)`，前台地面不得漂浮或低于原六店共同地线。主体围绕 x=512；计划主体可见宽 `600–760` 源像素、高 `610–750` 源像素，上缘约 y=150–290，下缘 y=900；这是开工控制区间，首样必须按六店同尺度实图核验，不为凑区间拉伸建筑。
- 视角跟随其他瓦房店的近正面观看方式：屋脊、正檐、门额和台阶大体水平；侧墙可见宽/正面宽 `≤0.12`，不再呈旧版三分之四侧视。镜台、座椅、理发柱等仍在正面营业开口可辨。
- 输出同源 1024² 图，在 `390×844` 和 `720×1280` 两个完整视口沿同一脚线投影，并排放入其余五店的同尺度总览。按现行保守 `1024→316 CSS px` 的 390 投影，主体宽约 `185–235 CSS px`；720 投影缩放由现有六店同一规则测得，严禁单独放大 04。牌文在 390 视口检验可读性，沿用已批准 B 92% 字效的 ≥24 CSS px 字芯高候选线。
- [尺寸示意](preview/barber_full_redraw_v03_size_diagram.svg)为坐标及比例审查图，不是新效果图，也不替代真实投影测量。

## 必须保留的设计语义

蓝灰瓦屋、卷檐中式轮廓、暖木梁、蓝白布帘、暖灯与理发经营物应形成与原版相同的夜市身份。保留牌匾双层形制及檐下横额挂位、准确简体「理发」；不在屋顶增加大剪刀、大字或其他 LOGO。建筑可整体重构以达近正面，但不把既有屋顶、牌匾和经营线索换成另一种店型。新图仍与其他五店共享冷蓝夜色、暖色营业窗和非像素二维绘制语言。

## 来源、母版与制作边界

旧 `psd/shop_04_barber.psd`、`shop_04_barber_font_r1b.psd` 及原 PNG 是视觉参考和差异证据，保留原文件与 SHA；本轮建立**独立新 PSD**，不能覆盖旧 PSD，也不把旧图改名冒充新母版。正式开工前锁定输入源、生成/绘制方法、参考版权记录、图层规划与同尺度控制框。允许整体重绘屋顶、立面、室内经营物、灯光和接地，但逐对象对照本方案锚点。参考其余五店的正面角度和比例，不直接复用其瓦、木、牌匾像素。

建议独立层组为 `body_structure`、`roof`、`interior_objects`、`front_counter`、`light`、`ground_contact`、`sign_hardware`、`sign_board`、`sign_glyph`、隐藏的 `reference_source`。字效层只在已批准受限栅格字体预案与同版 Art/Tech 预签后合成。TTF 仅在本地渲染，PSD、仓库和游戏包均不嵌入字体软件。

## 首样与失败条件

首样提交独立多层 PSD、实际可见重组、`body`/`sign` 两张 1024² 透明切片、四底 alpha 检查、390/720 全视口、六店同尺度总览、新旧 04 对照、逐层路径与 SHA。由组织 Agent 自行切图的效果随实图直接交用户 Gate2；用户批准具体版本前不进入 Client。

任一出现即停止并修订：04 明显比同尺度五店偏大/偏小；脚点偏离 `(512,900)`；近正面侧墙比未达 `≤0.12`；牌匾碰檐或丢双层形制；镜台/座椅/理发柱不清；瓦、木、光色脱离六店体系；出现屋顶大 LOGO；文字错字或低于小屏可读候选线；两片不能还原母版、PSD 不可编辑或透明边脏。正式首图前先取得本 v0.3 用户批准和 Art/Tech 对同版预案签认。
