## 字体与图层规则

| 项 | 本轮样张参数（1024² 店铺母版坐标） | 正式落地约束 |
|---|---|---|
| 字体与牌文 | `HappyZcool-2016` Regular Version 3.12；奶茶／糖画／炭烤／理发／花灯／投壶，全为准确简体 | 仅调整现有 `sign_glyph` 字层及随字图层；保留六块牌本身和原挂位 |
| 字芯与整体字号 | 先按原字号字框约 90% 适配生成字效，再把**完整字效合成层整体居中等比缩至原版的 92%**，包括字芯、粗圆底、描边、立体背面和亮边；原牌匾和小装饰不缩 | 六店同一倍率；字框与牌边保留安全空白，不得碰牌框、挂绳、灯笼或经营物 |
| 粗圆体打底 | **仅用同一站酷快乐体字形**，对原 alpha 用半径 **3 源像素的圆盘形膨胀**，叠在原字芯下方；以各牌同系深色填充，形成可见的厚圆底字。无需第二字体或另一个字体许可。 | 保留原字孔、简体笔画和字间空白；若局部粘连，优先局部收回圆底半径，不改原牌文 |
| 描边 | 在粗圆底外再对原 alpha 用半径 **6 源像素的圆盘形膨胀**；与圆底之间形成约 **3 源像素**的浅色窄描边，390 投影约 **0.93 CSS px** | 外描边不能填平字内孔或连字；正式逐牌复核 |
| 立体厚度 | 外描边整体向右下 `(4,4)` 源像素错位，390 投影约 `(1.23,1.23)` CSS px；深色背面 + 浅色边 + 粗圆底字 + 原字芯 | 单方向、一层低厚度；不能成为第二排影字或增加新 LOGO |
| 明暗 | 字芯沿原牌深浅取色；上侧少量亮边，背面取同系暗色 | 不用强发光和大面积投影；390 预览保持字形封闭与边界清楚 |
| 小装饰 | 每牌 **最多 2 组**，单组不大于约 22×12 源像素；角点、短线或铆钉等材质提示 | 仅在牌空白处，不能遮字、经营物或成为独立图标；不得改变原牌形 |

六牌配色：01 奶茶暖米描边／茶棕背面；02 糖画糖金描边／糖褐背面；03 炭烤炭橙描边／深焦背面；04 理发银蓝描边／石板灰背面；05 花灯金粉描边／胭脂背面；06 投壶灰青描边／墨青背面。字芯沿各自原牌明暗维持对比。小装饰分别用温暖角点、糖金角点、短炭线、金属短刻、花灯角珠、竹牌短线。装饰是牌面纹理提示，不改变六店经营线索。

实际叠层顺序（从下到上）：原店体与原牌板／五金 → 右下 4 px 深色立体背面 → 外扩 6 px 浅色描边 → 外扩 3 px 深色粗圆底字 → 站酷快乐体原字芯 → 顶侧轻亮边 → 不超过两组牌面装饰。样张脚本 `source/font_candidates/render_zcool_kuaile_styled.py` 固定这些参数，六张 390 预览可直接检验四种处理同时出现。

2026-10-07 字号修订：在上述字效合成后，以每字原牌内定位框中心为轴整体缩到 **92%**；数学上源样张 3/6 px 圆底／描边半径与 `(4,4)` px 立体偏移均随层一同缩至约 2.76/5.52 px 和 `(3.68,3.68)` px，栅格化后保留抗锯齿。旧版不覆盖。新版 12 字原字芯 bbox 高的 390 投影范围为 **25.00–28.08 CSS px**，最低「发／花／灯」仍高于 24 px；六张 390 图需继续目视核字孔、笔画、牌框余白。牌匾、挂位、装饰、屋身和经营物未缩放或移位。

## 正式制作门禁与后验

1. 用户先批准此视觉方案及对应具体样张；04 视角方案仍独立审定。
2. Art 和 Tech Lead 对同一批次制作预案预签；首张正式样张前完成。预案锁源 PSD、允许修改的字层／附属纹理层、色宽、偏移、牌框与经营物禁区、六店输出列表。
3. 在当前六张 PSD 的牌匾字层定向制作，不重画店体；输出可编辑 PSD、双片 PNG、1024² 同尺度重组、六店 390×844 投影、版本清单和 SHA。
4. Art 视觉后验逐牌检查字形、描边、立体厚度、装饰数量和店体一致性；Tech 检查 PSD 可编辑性、切片重组误差、有效细笔、小屏可读性及性能；六店实图交用户第二次审批。用户批准具体切片版本前不进入 Client。
