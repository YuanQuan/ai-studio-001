# 站酷快乐体 2016 修订版：原发布文件核验记录

日期：2026-10-07；用于 U03 六店牌匾 B 方案正式生产门禁。本记录区分**原发布方声明**、**当前实际 TTF**与**未取得的原包**，不以聚合仓库的“免费”描述替代授权。

## 已取得的证据

- [站酷原素材页](https://www.zcool.com.cn/assets/7285916528355077132.html)的公开索引内容写明“站酷快乐体〖免费商用〗”、2016 年 6 月修订版、刘兵克学员和工作室团队、“免费授权全社会使用（包括商用）”，并列出 `站酷快乐体2016修订版.ttf` 与 `站酷快乐体（修订版）使用声明.docx` 两个文件。页面下方另有素材站通用授权选项，不能在没读随附声明前推断其对字体文件的全部交付场景。
- [站酷 2016 资讯](https://www.zcool.com.cn/article/ZNDE1OTc2.html)称其免费商用；[刘兵克原发布文章](https://www.zcool.com.cn/work/ZMTMzMDQ0Mjg%3D.html)指向原字体专题下载页 `https://www.zcool.com.cn/special/happyfont/`。
- 第三方转载的[《站酷快乐体修订版使用必读声明》可读预览](https://max.book118.com/html/2018/1222/6011231215001240.shtm)前段称 2016 修订版权归站酷、可用于任何商业范围、不得通过字体本身牟利。该副本来源独立性不足，**仅为旁证，不作为原声明原件**。
- 当前选型使用的实际 `source/font_candidates/wordshub_requested/ZCOOL-KuaiLe.ttf` 来自用户指定的 `wordshub/free-font` 聚合仓库，SHA-256 `302D8DEE7D2CB7D25D6BC89399E43513D2CAFD031862BD46BCE47F573C68807E`，MD5 `0ACEAB97AF2CD21DC57F76ACEB1B1722`，name `HappyZcool-2016` Regular Version 3.12，六店 12 个简体字 cmap 均覆盖。独立 Tech 检查发现该 MD5/版本/约 1.59 MB 与多个公开目录中“站酷快乐体2016修订版.ttf”的描述一致，**只能证明同版可能性，不能证明官方字节一致性**。

## 原包获取尝试及现状态

1. Web 检索可读到站酷原素材页的公开描述和两个附件文件名，但 web 页面直开超时，未返回二进制下载链接或声明文件。
2. 原专题 `https://www.zcool.com.cn/special/happyfont/` 由网页工具返回不可访问；PowerShell `Invoke-WebRequest` 到该 URL 出现 SSL 连接失败。未关闭证书校验，也未绕过浏览器安全警告。
3. 用 Chrome 打开原素材页的 UI 自动化请求发生 `nodeRepl.fetch request failed`，未呈现可点的下载控件。未提交账户资料、未接受任何站酷素材授权选项。

**状态：原版 TTF 与随附使用声明原件尚未取得，未完成当前聚合 TTF 与原版的字节级比对。** 站酷原发布方的免费商用表述有明确正面证据，但就本项目拟输出游戏牌匾图片与是否可随游戏分发字体而言，仍需原声明核验。当前游戏资源只计划导出字形 PNG，**不计划嵌入 TTF**；这一限制不代替授权核验。按原制作方案，此门禁未过之前不得将当前聚合文件转成六店正式 PSD/切片。可独立推进理发店角度制作方案审批与预签，不制作含该字效的正式图。

后续解除条件：从站酷原发布入口或版权方可验证渠道取得原 TTF/声明，保存实际文件、URL/获取时间、SHA-256；逐条记录图片商业输出、修改字形效果、是否分发字体的适用条款；将原 TTF 与候选文件做版本及字节比对。若原文件不一致或声明限制与项目用途冲突，向 Master 提交差异与新字体／版本方案，不静默替换用户已批准的 92% 视觉版。
