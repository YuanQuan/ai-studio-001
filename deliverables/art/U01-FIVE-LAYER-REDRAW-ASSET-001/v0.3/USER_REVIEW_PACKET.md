# U01 五层重绘资源 v0.3｜生产阻塞说明（非 Gate2 切图送审）

已批准的制作方案仍是3840×1024五层，天空更高、河水少、石路更宽且保持通桥纵深。Art与Tech针对内置生图分区方法完成同版首图预签，实际制作了两张各2172×724原生分区样张，并用指定 `bggg-creator-image2psd` 原版工具以1:1放到3840×1024试验画布。第一张中央块显示更宽街道和更少水面；第二张左块接上后，**接缝明显失败**。试验画布只有两张区域层，空白仍未制作，不是正式五层PSD或切片。

查看实图：[S03 中央块](source/sample_lower_center_s03.png)、[S04 左块](source/sample_lower_left_s04.png)、[两块原位试拼](source_build/s03_s04_seam/trial.preview.png)、[接缝逐项检查](S04_SEAM_VISUAL_CHECK.md)。在两块试拼的x=834接边，柳树和远山硬切、前景草重复，栏杆、水岸与石板纹路无法连续。中央石路还可能视觉上通向桥洞下方，未证明保留原图通桥面的纵深。两项都需要修订后重新看实图。

按首图前预案，现已停止其余窗口和五层扩批。没有3840×1024完整新绘画面、五层透明PNG、正式PSD、同尺度重组或运行结论，因此**Gate2仍为DRAFT，不能请用户批准具体切图或交Client接入**。S01/S02旧失败、S03/S04原图、完整提示词、参考与拼接manifest均留在各自版本目录。后续制作方法须能以真实输出证明目标清晰度、同一空间的接缝与桥前纵深；方法确定后，下一张图前由Art/Tech对受影响方案重新同版预签。

本文件只供用户了解当前生产状态和失败实图，不是对已批准Gate1构图的重审，也不是Gate2审批包。
