# U01 v0.5 工具与方法核验

- 内置 `image_gen` 可编辑已查看的本地 S05R 和旧图，可请求透明对象；它无确定输出尺寸参数。旧 S01/S02 和 S05/S05R 实际均为 2172×724。正式输入须逐文件读尺寸、模式与 hash；不能把目标 3840×1024 写成工具原生输出。没有 API/CLI fallback 授权，本批不调用外部图像 API 或读取密钥。
- 已安装的 `bggg-creator-image2psd` 脚本 `scripts/image2psd.py` SHA-256 `af7217e0f3dad1edaf7eb4017c717cc49c6ce45d35be88a00c0d2f284b390ebd`；此前已用临时文件验证 3840×1024 PSD 组装、层回读。它支持 manifest 中源图、fit、x/y、全画布图层导出，可承载等比适配与层级组装；不会自行生成清晰新笔触、语义分割或无缝续绘。宽高/层数/alpha/PSD 回读须对本批正式输出重新验证。
- 拟产 3840×1024 五 PNG 的来源链为：生成或透明提取的独立中心语义层（实测原尺寸）→ 等比适配到约 3072×1024；同层左右续绘（实测原尺寸）→ skill manifest 原位合并；五张正式 PNG → skill 再组装 PSD/预览。严格记录实际放缩数值。中心只放大插值后的局部锐度不会等于原生新绘高清，须在手机视窗中判视觉结果；若不满足既有清晰度目标，不能判通过。
- 第一风险是透明提取及河面补底；先对 L04/L05 做一组代表样张。第二风险是左右续绘接缝；第一组两翼出来就核，失败停止扩批。第三风险是 3840 宽贴图在当前客户端和设备的实际适配；属于 Gate2 后 Client/Tech 验证，不冒充已测。
- 图片权利：源参考为用户已授权的项目原四层图及本项目内置生图 S05R；不引入第三方图片、商标或字体。旧版 PSD、PNG 留在原路径，不覆盖。
