# 六店长表情修正具体制作方案 v0.1｜Gate1 待用户审批

## 批次与目标
首批仅 MT_S2、AT_S0、AC_S0、AJ_S2、AD_S0、XJ_S0，每阶段 happy / surprised / sad / smile / angry 五态，共30态。余12阶段60态在首批视觉、可编辑性与预算复核后另提扩批，不由本方案直接开工。原18份 PSD、获批人形源图及当前90脸片均冻结只读，源身份与坐标详见 `SOURCE_PSD_AUDIT.json`。本方案继承 `rules/visual_fidelity_compute_contract.md` v0.1。方案批准后仍须首图前 Art/Tech 同批预签；具体切片与同尺度效果另行 Gate2 用户批准，Client 才能接入。

## 实际制作路线
1. 从每阶段旧 PSD 复制新版本，保留锁定的 `REFERENCE_APPROVED`、旧基底、旧表情和遮挡层；以真实获批原图为基准。核每一态在原1024×1536画布中的脸部 ROI、与旧 256×256 源脸层的坐标对应。新版以稳定语义层 `BASE_LOCKED`、`FACE_{STATE}_BROWS/EYES/MOUTH`、`FRONT_OCCLUSION`、`REFERENCE_LOCKED` 管理，旧层保留可回退但不参与新版输出。每阶段单一母版；不是把30张平面脸片堆成假分层。
2. Art 逐态手绘/数位板或PSD栅格笔刷局部重绘眉、眼、嘴的线稿、色块和必要阴影，先在当前可编辑语义层上修笔触。固定几何嘴、眼拉伸或眉旋转只可作定位草稿，不作主成品。需生成式辅助时，先在已批准方案与预算内只提交面部 ROI 加少量上下文，得到候选后人工复核/取局部；生成输出的尺寸、精确蒙版和图层能力均不可预设；独立态/变体逐一调用，不以一张五态拼板生成后裁切。非 ROI 像素由冻结源确定性拷回；扩大遮罩须记录理由。优先不调用生成，详见预算。
3. 脸上旧笔触删除后出现的皮肤缺口，先取同 PSD 原有肤色/光影层及邻域纹理修补；只补实际暴露的脸颊、额头、鼻口连接边，不重绘身体衣装、发型、道具或整脸。若局部修补在同背景同视窗同尺度两轮仍失败，停该态，提交差异与最小重绘区域，经受影响方案与预签复核后方可重绘。原PSD与输出一律留旧版。
4. 小锦 S0 保留获批的**圈纹高度近视眼镜**设计，镜框/镜片须对照获批原图单次显示。先对 base、eyes、front 中重复/错位的镜框像素按遮挡顺序作无损分离；选 `FRONT_OCCLUSION` 为唯一实际显示的镜框/镜片层，base/eyes 中与该层重叠造成额外圈线、扭曲、遮挡污染的像素局部清理，镜后眼形按原透视重新画。圈纹本身是身份特征，不视为缺陷。S2戴镜、S3不戴镜的阶段规则保留。唯一显示层须从获批原图保留单次镜片透光、圈纹与光效；若 front 提取不足，不得简单丢弃 base 原光效，先局部无损转移并逐像素核重组。若剥离破坏镜片透光或前发边缘，停用该候选并复核原图，不用自动去底强行修。
5. 合成固定 `base -> one face state -> front`。源画布1024×1536；MT/AT/AC/AJ 导出脸画布256×256，AD/XJ源脸256×256、导出192×192，依各自旧映射的 source rect、offset、pivot；MT/AT/AC/AJ为1.0缩放，AD/XJ为0.75缩放，不改稳定ID或客户端契约。每阶段输出1份新版PSD；每态导出三个眉眼嘴源层、合成脸片与同尺度重组图；对应层/切片哈希、坐标和版本在新清单登记。`bggg-creator-image2psd` 的 `assemble` 仅在现有PSD无法可靠回写且各层透明栅格已验证时用于组装；其栅格层不是原生可编辑笔触，`split-colors` 不用于语义脸层。若转换脚本不能保持 `visible:false` 的旧版/参考层，只能复用已验证的旧PSD隐藏层适配方法或受控补足脚本；必须实际核五态互斥可见，禁止全开叠五态。

## 样张与扩批门槛
预签后先做 MT_S2 的 surprised、AT_S0 的 sad、AC_S0 的 angry、AJ_S2 的 happy、AD_S0 的 happy、XJ_S0 的 happy 六张代表样张，覆盖眉眼嘴、侧目、疲态与镜片遮挡；含同阶段另外四态的纸面分辨设计。六样逐一通过 Art 视觉检查及 Master 独立看图，Art/Tech 对实际PSD层级和同尺度重组签认后，才制作余24态。其后逐人五态隐藏标签盲辨；每态检查相同背景、1280×720视窗、实际使用缩放的已批准/旧版/新版三列及脸部原寸近景，记录判错对和原因。禁止以90旧脸片字节一致、PSD有层或重组零差代替新表情自然度。

## 有界预算与停止
人工局部候选：六代表各最多2版，共12；余24态各最多2版，共48；另小锦基底/眼镜清理最多2版，合计上限62个人工局部候选，任一态至多2轮修正（含跨工具尝试）。首批生成式调用预设0；如六样证明手绘局部不足、且用户已批准本方案允许ROI辅助，仍最多6次调用、每次一个候选，总候选不超过68，具体使用须先经Art/Tech同批预签记录。费用与GPU时未知，不宣称节省比例。计划人工制作上限40工时（源核/六样12h、余24态20h、验证与修订8h）；此为停工复核额度，不是已发生耗时。达到任何候选/调用/工时上限、同一缺陷两轮失败、身份或冻结区域漂移、镜片污染未清，立即停该支线，交差异、已用额度和最小下一步给Master；不得换提示词重置计数。每次制作记录起止、工具版本、输入/输出hash、候选数、差异与预算余额。预算拦截当前是人工约束。

## 对照与客观检查
以获批图作身份/服装/成长锚点，局部修改区以新获批目标判断；ROI外经统一RGBA解码、ICC/alpha/缩放设置后可见像素差异目标0，alpha另核。实际修复区不能要求和旧图零差。重组核实际输出切片、图层可见性、裁切边、透明边、遮挡顺序、前发/镜片透光；源、PSD、导出、重组逐层保留hash与坐标。静态通过不替代接入后的运行截图和适用正式QA。
