# 六店长表情修正具体制作方案 v0.2｜Gate1 待用户审批

## 批次与目标
首批仅 MT_S2、AT_S0、AC_S0、AJ_S2、AD_S0、XJ_S0，每阶段 happy / surprised / sad / smile / angry 五态，共30态。余12阶段60态在首批视觉、可编辑性与预算复核后另提扩批，不由本方案直接开工。原18份 PSD、获批人形源图及当前90脸片均冻结只读，源身份与坐标详见 `SOURCE_PSD_AUDIT.json`。本方案继承 `rules/visual_fidelity_compute_contract.md` v0.1。方案批准后仍须首图前 Art/Tech 同批预签；具体切片与同尺度效果另行 Gate2 用户批准，Client 才能接入。

## 实际制作路线
1. 从每阶段旧 PSD 复制新版本，保留锁定的获批原图、旧基底、旧表情和遮挡层；以 `SOURCE_PSD_AUDIT.json` 的实际源路径、哈希及1024×1536坐标为基准。每阶段一份工作母版，旧层可回退但不参与新输出。
2. 当前 Agent 可执行主路线为内置 `image_gen` **逐态面部 ROI 编辑**：30个情绪各单独一次首候选，不拼五态板后裁切。输入为获批源/旧版可见图与必要局部上下文；工具每次只产生一个独立态候选。若工具返回可访问本地路径则读取；否则依实际返回的图像及可保存能力获取，记录真实引用和落地路径，无法落地则停该候选。将选中候选复制到项目工作目录并记录哈希、实际尺寸和 alpha。工具不保证原尺寸、精确蒙版、像素配准或原生PSD层；先核头向、脸型、眼鼻嘴锚点，漂移即拒用，不能靠缩放眼睛、固定几何嘴或眉旋转掩盖。
3. 对可配准候选，仅在预先登记的脸部ROI及必要阴影边缘取像素，确定性回填到**现行PSD实际可见层/旧切片重组**的坐标；ROI外像素与alpha以这套现行显示基准冻结，保留已有清边，不把清边前原始立绘的软晕alpha拷回。获批原立绘用于身份、视觉锚点和缺失内容参考，不能替代现行切片保真基准。眉、眼、嘴用可核遮罩拆为语义栅格层，必要时增加 `FACE_{STATE}_SKIN/SHADING` 支持层并记补洞来源；这些支持层须合并进最终 **oneface** 导出，客户端仍只接 `base + oneface + front` 三层。若皮肤、笔触与五官无法精确分离，须登记局部合并范围及编辑限制，不伪称眉眼嘴完全独立或恢复原生笔触。脸底缺口先用旧PSD现有层和邻域确定性修补，确实缺信息时才用该阶段一次独立局部候选。不得改身体、衣装、发型、道具或整脸。
4. 小锦 S0 保留获批的**圈纹高度近视眼镜**设计。先对照获批原图核镜框/镜片及透光只显示一次，再清 base、eyes、front 中重复/错位污染；选 `FRONT_OCCLUSION` 为唯一显示镜框/镜片的层，必要的旧 base 透光/圈纹像素先确定性转移，不简单丢弃。镜后眼形按原透视修正。圈纹本身是身份特征，S2戴镜、S3不戴镜的规则保留。若剥离破坏镜片透光或前发边缘，停用候选并复核原图。
5. 合成固定 `base -> one face state -> front`。源画布1024×1536；MT/AT/AC/AJ脸源及导出256×256、旧映射缩放1.0；AD/XJ脸源256×256、导出192×192、缩放0.75。沿用旧source rect、offset、pivot、稳定ID与客户端契约。每阶段输出1份新版PSD，每态导出脸片与实际可分的语义源层、同尺度重组，登记哈希及可编辑边界。若需 `bggg-creator-image2psd assemble`，只组装已验证透明栅格层，不能用 `split-colors` 冒充语义拆层；脚本如不支持旧PSD `visible:false`，使用经验证的隐藏层adapter或受控补足，核五态互斥可见，否则停PSD交付，禁止全开叠五态或参考整图盖顶。

## 样张与扩批门槛
预签后先做 MT_S2 surprised、AT_S0 sad、AC_S0 angry、AJ_S2 happy、AD_S0 happy、XJ_S0 happy 六张独立代表样张，并核小锦脸底/镜片仅一次显示。六样须通过候选配准、ROI外零差、PSD互斥层、Art视觉与Master独立看图、Tech兼容性检查，才扩余24态。其后逐人五态隐藏标签盲辨；每态在同背景、1280×720视窗、实际显示缩放下比较获批源、旧版、新版，记录判错对。哈希/重组零差不证明表情自然。

## 有界预算与停止
内置imagegen主路线：30情绪各1次首候选；六阶段脸底/遮挡若确有缺口各最多1次首候选；全批最多12次定向返修调用。**总调用与候选上限48**，每次一个候选。任一态或同一问题累计最多2次返修，仍受全批12返修与48总额限制；失败、结果未知均保守计预算，先查原结果，不盲目重发。先六样和小锦基础验证，门槛不过不扩批。记录调用真实路径、输入/输出哈希、工具返回ID（如有）、起止时间、状态、返修原因与余额。首六样含基础核验预估90分钟、全批预估6小时墙钟，均为停工复核额度而非SLA或已发生耗时；费用/GPU时间未知。达到额度、身份/脸型/头向漂移、ROI外差异、镜片污染、PSD互斥失败或同问题两次返修仍不达标，停该支线交差异和最小下一步给Master；不能换提示或任务重置计数。

## 对照与客观检查
以获批原立绘作身份/服装/成长和缺失内容参考；ROI外保真以现行PSD实际可见层及旧切片重组为比较对象，经统一RGBA解码、ICC/alpha/缩放设置后可见像素差异目标0，alpha另核，尤须保留旧版清边结果。实际修复区不能要求和旧图零差。重组核实际输出切片、图层可见性、裁切边、透明边、遮挡顺序、前发/镜片透光；源、PSD、导出、重组逐层保留hash与坐标。静态通过不替代接入后的运行截图和适用正式QA。
