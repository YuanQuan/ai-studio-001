# 首图方法复用入口（孟桃 0 魂已实测）

这些脚本保留本批首图的可复核制作步骤，**不是可对另外 17 阶段原样运行的通用坐标**。运行环境为 Python 3 + Pillow + NumPy，工作目录为本游戏仓库根目录。它们仅写本任务 `v0.1/` 路径；支持批次必须先复制到各自独立交付目录，改路径与每阶段坐标，不能直接覆写孟桃成果。

1. 批准源、旧五官位置、可信肤色采样和前发遮挡先逐张观察；脸底语义蒙版生成示例在 `deliverables/art/U04-DIALOGUE-FACE-SUPPORT-001/v0.1/build_face_candidate.py`，其 `PROCESS_NOTES.md` 记录改动像素与失败条件。孟桃脸区/前发坐标只适用于 MT_S0。保留旧源字节副本，改区外 RGB、alpha 核对。
2. `mt_s0_five_expressions.py`：按批准五官色与局部透明层生成五态眉/眼/嘴以及 256×256同支点表达片。须先修改 `parts`、五态 `settings`、嘴部定位及脸画布 `F`；各源的眼型、前发与肤色需人工校准。微笑要以该阶段批准脸为身份基准，高兴与微笑必须目标尺度可辨。眼白/睫毛应保留，不能带矩形肤色补片或旧眉。
3. `mt_s0_integrate_face.py`：将候选脸底语义蒙版 RGB 叠到保留原图像素的清边 alpha，再叠单一表情及前发；批次另写 stage-specific 路径。复合顺序固定 base→一组表情→前发。
4. `mt_s0_u00_scene.py`：以 `current_shops_on_v03_scene.png` 的实际像素制作 1280×720 横屏静态同尺度对照。这个画幅是视觉候选，不能声称当前 Cocos 720×1280 设计分辨率已具横屏运行布局。名字/文字/选择项仅在 review 叠层，不进入伸缩面板 PNG；脚本使用本机系统字仅供审图，不交付字体文件。
5. `mt_s0_sample_checks.py`：生成首样张图层/像素映射与 PSD、九宫格静态校验；其它阶段要更新组别及真实文件，不得伪造像素0差。PSD 的隐藏层保留通过本任务 `source/image2psd_hidden_adapter.patch` 对 `bggg-creator-image2psd` 原脚本临时适配；原 skill 不改。PSD 初始只显示微笑，另四态与批准源参考仍是真实含 alpha 的隐藏层。
6. `nine_slice_panel.py` 仅供统一面板生成；所有阶段复用同一份 512×256 九宫格，不要逐人重制。Insets 四边均 48，固定云纹另作节点。

半身导出裁剪与表达片实际尺寸由每阶段源图包围盒和五官跨度决定；建议人物基底不超过 768×1024、局部表达不超过 256×256，超出须记录原因并请 Tech 复估。所有正式图需先通过Art/Tech同批预签门禁；首批通过不自动批准其他阶段图。
