# 六店长人形立绘定向修订 Brief v0.3

本轮依据用户 2026-10-10 最新明确要求，回到旧 v0.1 人形版本。仅修阿角、阿炭各 0／2／3 魂共六幅全身图；孟桃、阿棠、阿灯、小锦直接引用旧 v0.1，不重画。用户本次已经明确授权这六幅定向修图；具体新图仍须再由用户审阅批准后方能正式接入。

阿角改为男性，三阶段均保留短弯牛角、蓝紫与暖铜主色、绳饰、腰侧剪理工具及造型铺身份。0魂油腻邋遢，2魂干净但仍是过渡，3魂干净时髦；不得用单纯换表情替代发型、衣领、衣面和姿态的连续变化。阿炭保留炭黑乱短发与暖橙发梢、炭灰围挡及单支烤串。0魂应明显瘦弱、凹脸、驼背，2魂体态和面容改善，3魂挺拔且肌肉发达；仍是同一人，不转换职业或主衣装。

输入为每幅对应的 v0.1 PNG。使用内置 imagegen 逐张编辑，锁定旧版的平滑二维可爱中式夜市画风、近正面全身构图、主配色、身份物和角色辨识；除上述用户指定变化，避免重设计。目标为每幅 1024×1536 透明 PNG，实际工具输出尺寸与 alpha 逐图核实。旧源及所有生成候选保留，新版只存 v0.3。若编辑使衣装或身份物明显漂移，应退修该幅。

两人各制作一张 0／2／3 魂同尺度对照板及一份 PSD。PSD 有中性审阅背景与三个完整阶段人物图层，可替换／移动整个阶段，不能承诺头发、五官、衣片等身体部件独立编辑。板和 PSD 由六幅审过的透明 PNG 组装，不借转换重绘。首张阿角 0 魂，待本批 Art／Tech 同版预签后开工；Art 实图自审、Master 独立复核、Tech 样张复核及全量方法复签后扩余五张。无新 Sprite、动画、UI 或 Client 接入。

设计理由：阿角的整理过程和阿炭的体能恢复需在店前缩小显示时仍可由发型／体态大轮廓读出；同人衣装、职业物和主色保持一致，让魂成长表现为人物状态变化，而非换角色。
