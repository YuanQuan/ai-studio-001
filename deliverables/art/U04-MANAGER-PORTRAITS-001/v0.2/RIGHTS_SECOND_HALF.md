# 阿角、阿灯、小锦九图来源与权利初筛

- 产出方式：Codex 内置 `image_gen`，每幅单独生成。阿角/阿灯/小锦各自的 0 魂依据已批准文字方案全新原创起稿；各人 2/3 魂只以本角色已核新 0 魂本地图作身份、画风、比例参考。阿角2与小锦0另有定向修订，原候选均留在 `source_images/`。生成路径、完整提示词、选中映射见 `PROMPT_LOG_SECOND_HALF.md`。
- 项目内参考：`deliverables/art/U04-MANAGER-CONCEPT-PLAN-001/v0.3/ART_PRODUCTION_PLAN.md`、`VISUAL_ANCHORS.md`，以及 `deliverables/product/U04-MANAGER-PERSONALITY-001/v0.3/PRD.md`。孟桃0新非人样张只用于人工查看同批二维色块/线条语言，未作为阿角、阿灯、小锦 0 魂的图像输入。
- 外部来源：未抓取、下载、输入外部图片、商标、现有角色图或字体；三人图内无烘字、品牌/Logo。通用牛怪、纸灯笼妖、鲤鱼精及职业物由项目文字锚点组合成各自形体，未指定模仿任何可识别第三方角色。
- 外观相似风险初筛：逐张实看未见直接复制已知 IP/品牌的独特造型。牛角装饰、花灯花瓣、鲤鱼配色和镜片仍属泛用视觉词汇；这项初筛不是法律上的排他性/版权保证。若后续识别出具体高风险近似，须暂停该图正式资源化并交 Art 进一步核查。
- 资产状态：九图及原源为新批次候选，alpha 含软晕，非正式 Sprite、正式切片或 Client 可接入资产。须与同批其余九图、六板、六 PSD 一同接受确切版本用户审批，后续门禁另行履行。
