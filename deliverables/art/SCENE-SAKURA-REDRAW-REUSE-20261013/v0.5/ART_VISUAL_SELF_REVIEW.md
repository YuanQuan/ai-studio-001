# v0.5 桥局部实图视觉自检

比较使用同一个 `[1160,520,1912,868)`、752×348 原坐标裁框：用户原参考、v0.4 实产、v0.5 真实 21 PNG 重组；详见 `review/reference_before_after_bridge.png`，全画幅见 `review/reassembled_from_exports.png`。候选未引入参考两侧店和空中精灵；v0.5 仍是现景无六店环境。

| 锚点 | 结论 | 实图观察 |
|---|---|---|
| 中央桥形 | PASS | 一座连续圆拱，拱冠高于 v0.4、洞口收窄；无双拱或水平断桥。 |
| 石纹与桥脚 | PASS | 券石不再是整齐重复楔砖；两侧不规则苔石自然接入岸边，旧大直脚未残留。 |
| 暖灯与栏杆 | PASS | 四盏暖灯，外灯明显低于内灯，石座短厚；没有原 v0.4 细长流苏柄。栏杆独立 front，桥体留 body。 |
| 中央标章 | PASS | 同中线只有一个卷涡圆章，无旧花/面图；左右输出直接邻接，未镜像复制圆章。 |
| 局部接缝 | PASS（静态） | 清掉旧上灯后沿原背景露天空，旧低栏露底用同候选局部补；曾出现的断圆帽和两侧蓝楔经本地遮罩修正，最终同尺度实图不见明显断面。 |
| 未改区与运行 | 静态 PASS；运行 NOT_TESTED | ROI 外 RGBA 逐像素 0 差，17 非桥 PNG 字节 SHA 不变。真实游客/店脚遮挡、Cocos 缩放与目标机性能仍待正式接入后验证。 |

限制：手工语义遮罩和一次生成候选只能保证当前静态 1:1 场景的视觉与层级审阅；前景栏杆移开后全部隐藏桥面不可由旧平面图推得。审阅图中的彩色实体是**几何遮挡占位**，不代表正式游客或店铺。用户 Gate2 尚未批准。
