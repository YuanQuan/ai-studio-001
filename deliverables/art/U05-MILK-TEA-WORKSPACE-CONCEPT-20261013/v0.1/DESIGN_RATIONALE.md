# 三版构图与审阅要点

三版共用困难档第 2/3 杯、01:48、同一订单和五项当前选择，比较的是**玩家工作区怎样组织**，不是三套新玩法。木材、浅纸、暖灯、圆润二维造型继承现行美术方向；奶茶杯始终为画面中心。

| 版本 | 工作区结构 | 审阅价值 |
|---|---|
| A | 制作者正面微俯视的横向内侧木台，五组容器围绕杯子 | 最像“站在自己柜台里做一杯”，容器与操作区直观。 |
| B | 桌面俯视，五个圆形原料站环绕中央杯 | 五维动线最容易扫读，空间感更偏工作桌。 |
| C | 后层茶奶架、前层小料／糖／冰抽屉与中央高台 | 店内纵深最强，表现上下两层工位。 |

三张均为独立竖屏概念图，不含生产母版、热区、正式文字资源或运行效果。A 初稿误出现未获批选项，已定向修正并保留历史。B 的未标小碗与 C 右下重复小料只是陈设，不定义新选项；C “去冰”选项的图标仍有冰块，后续 UI 设计需澄清。图中文字与选中态在实际 UI 中要依据已批准配置重新精确实现，不能据效果图反向改产品规则。
