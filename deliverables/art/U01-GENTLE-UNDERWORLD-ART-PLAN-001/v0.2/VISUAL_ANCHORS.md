# U01 温和地府挂件视觉锚点 v0.2

本表是待用户批准的**制作基线**，没有新图片通过结论。比较源为已批四层原 PSD/重组图、旧 Client v0.2 手机截图；被退回的 GU v0.2 仅作返工历史，不能作绘制源。

| 锚点 | 必须保持 | 本轮允许 | 越界须重新审/另批 |
|---|---|---|---|
| 构图和尺度 | 2172×724 平视横幅、中心石桥/河、右牌楼、柳树、月夜；手机初始仍以桥为焦点 | 只在候选位置安置六件低密度挂件，局部可移 | 整景重画、移动桥/月/牌楼、改像素风或扩大场景边界 |
| 桥与通行空间 | 拱洞、栏杆、桥灯、左右步道和纸船仍清晰 | 桥栏挂短牌“奈何桥”，街边矮指示牌“黄泉路→” | 挡满桥洞、堵路、箭头含糊或变成可点击 UI |
| 身份和文字 | 民俗地点提示，三处文字精确为“酆都城”“奈何桥”“黄泉路”并向右箭头 | 原创手绘字形，暖米金/低对比色；右字片覆现有空匾 | 字误、未许可字库、把字烙进旧层、外观近似特定作品招牌 |
| 情绪和材质 | 冷蓝夜景、暖橙灯光、圆润二维笔触、安静友好 | 小型暖纸灯、月白软布幡、木路牌及桥牌，少量柔和反光 | 鬼怪/血痕/刑具/骷髅/丧葬人物、强光大火、巨型旗面 |
| 独立可移位 | 四旧场景层逐像素保留；原 L04 外缘不变 | 六件一件一组，字/牌/幡布等主要部件可再分层，每件透明图+坐标/pivot | 把挂件全烘进 L03/L04、缺少单件源、移位后无法独立关闭 |
| 空间遮挡 | 天空 .3、远山 .8、街道/桥 1.0 现行语义，前景定镜头安全 | 灯参照远景，幡/路牌随街道，桥牌随桥，右字随牌楼 | 新件造成前景露底、挡悬浮控制、错层漂浮或需改镜头最大范围 |
| 手机阅读 | 中心桥牌、右端匾字、左移途中路牌与幡分别可读，整体不拥挤 | 灯可作为某些视窗的气氛点，不强求全范围常驻 | 文字仅靠放大细节板才读得出；关键线索被裁/控件长期遮住 |

实图阶段逐项在原画幅、手机同尺度与单件移位测试中记 `PASS / REVISE / NOT_TESTED`，保存旧/新证据。方案审核只能判约束是否明确，不能提前给视觉 `PASS`。
